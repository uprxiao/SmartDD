# SmartDD M6 独立交互原型

这是已审阅的步骤 1、2 设计参考，保持独立演示数据，不替换已安装应用，也不接生产后端。2026-10-16 用户已授权正式接入；生产实现与验收见 [M6 实施与验收记录](../../docs/M6_实施与验收记录.md)。

本地预览：<http://127.0.0.1:4176/>。开发服务器已在本轮启动。

## 页面

- `#home`：Codex 截图对应的项目侧栏、欢迎区与底部任务输入框。
- `#settings/general`：设置框架、搜索、分类与分组卡片。
- `#settings/ai`：示例工具检测、添加 Codex、完整配置编辑（路径、参数、环境变量、敏感标记、颜色、默认）、测试状态与 `.zshrc` 导入预览。
- `#project/ais`、`#project/smartdd`：完整项目设置，含概览、代码目录、数据库、服务器、Skill 与 MCP、项目任务六项；编辑、归档、资源测试及删除确认均有对应入口。
- `#settings/skills`：内置能力版本与演示升级、按 AI 配置扫描及筛选；项目页另保留数据库／SSH／MCP 开关。
- `#settings/appearance`、`#settings/terminal`：主题、侧栏宽度、字体名称、10–24 字号及重置。
- `#scheduled`：定时任务入口及规划占位页；F16 实际功能不在本轮实现。
- 从首页创建示例任务后进入终端；支持演示输入 `help`、`pwd`、`status`、`clear`，以及停止／恢复。

项目“更多”打开详情浮层，点击“编辑项目”进入完整设置。项目旁的写字图标是新建任务。任务右键或“更多”打开重命名、归档／恢复和删除菜单。菜单支持点击外部、Esc 关闭；任务／项目菜单支持方向键选择。归档任务、归档项目及未关联任务有对应列表。

任务区有多标签、停止／配置切换恢复、信息与上下文面板。首页齿轮可选择代码目录、AI 配置并预览能力。搜索支持标题、首条消息、项目及配置名；可按项目筛选并回车打开。

## 数据边界

项目、配置、检测与调用结果均为示例，保存在页面内存中，刷新后重置。没有读取本机密钥、运行真实 CLI、连接数据库／服务器、创建调度计划或调用模型。添加配置和终端交互的检查只证明原型流程。

资源表单只保存凭据是否存在的示例标志，不保存敏感值。文件浏览填示例路径；系统目录、诊断、加密存储及持久化留待正式接入。语言入口保留，但完整英文页面尚未实现。当前终端在后台 Safari 中出现绘制暂停，前台彩色输出／输入／标签切换需复验，详见 QA；不要把前一版本的截图当作当前代码全部通过。

保持 SmartDD 蚂蚁 Logo。空间入口已移除；定时任务入口保留，暂不开放新建。

## 开发与检查

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4176 --strictPort
npm run test:parity
npm run build
```
