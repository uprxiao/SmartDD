# SmartDD M7 语音输入交互原型

这是已审阅的步骤 1、2 设计参考，保持独立演示数据，不替换已安装应用，也不接生产后端。2026-10-16 用户已授权正式接入；生产实现与验收见 [M6 实施与验收记录](../../docs/M6_实施与验收记录.md)。

当前在上述 M6 基线上增加 M7 / F17-A 语音入口。M7 本轮只做调研、原型和需求方案，正式语音功能未接入。

本地预览：<http://127.0.0.1:4176/#home>。开发服务器已在本轮启动；语音设置为 <http://127.0.0.1:4176/#settings/voice>。

## M7 怎么看

1. 首页输入框右侧点击麦克风，再点顶部预览控件中的“演示文字回填”（正常唤起不弹提示卡）；已有选区会替换，未选中时从光标插入，不自动发送。
2. 打开运行中的 AIS 任务，由左侧会话切换，顶部只有当前标题。更多菜单中的“演示终端快捷键（模拟）”与“演示文字回填”用于查看输入落点（需先在语音设置开启全局唤起）；正式 App 直接用快捷键，无终端语音按钮。
3. 设置 → 语音输入：检测示例、启用、听写键、权限指引、全局键录制／保存、手工覆盖和试用。快捷键页可跳转到此处。
4. 顶部“M7 · 语音预览”可切换就绪、冷启动、未安装、权限不足、未知听写键、启动失败和平台不支持。开启并保存全局键后，可在此演示外部输入框的回填。

这些步骤不录音、不启动 Typeless、不注册系统快捷键。原型状态内存保存，刷新重置。它展示后续桌面版的交互，不证明真实语音已可用。

## 页面

- `#home`：Codex 截图对应的项目侧栏、欢迎区与底部任务输入框。
- `#settings/voice`：M7 语音工具、全局唤起键及试用；`#settings/shortcuts` 保留现有快捷键并关联语音设置。
- `#settings/general`：设置框架、搜索、分类与分组卡片。
- `#settings/ai`：示例工具检测、添加 Codex、完整配置编辑（路径、参数、环境变量、敏感标记、颜色、默认）、测试状态与 `.zshrc` 导入预览。
- `#project/ais`、`#project/smartdd`：完整项目设置，含概览、代码目录、数据库、服务器、Skill 与 MCP、项目任务六项；编辑、归档、资源测试及删除确认均有对应入口。
- `#settings/skills`：内置能力版本与演示升级、按 AI 配置扫描及筛选；项目页另保留数据库／SSH／MCP 开关。
- `#settings/appearance`、`#settings/terminal`：主题、侧栏宽度、字体名称、10–24 字号及重置。
- `#scheduled`：定时任务入口及规划占位页；F16 实际功能不在本轮实现。
- 从首页创建示例任务后进入终端；支持演示输入 `help`、`pwd`、`status`、`clear`，以及停止／恢复。

项目“更多”打开详情浮层，点击“编辑项目”进入完整设置。项目旁的写字图标是新建任务。任务右键或“更多”打开重命名、归档／取消归档菜单（会话不提供删除）。菜单支持点击外部、Esc 关闭；任务／项目菜单支持方向键选择。归档任务、归档项目及未关联任务有对应列表。运行中的会话先确认“结束并归档”；归档支持查看和撤销，取消归档回到原项目且保持停止。

任务区有多标签、停止／配置切换恢复、信息与上下文面板。首页齿轮可选择代码目录、AI 配置并预览能力。搜索支持标题、首条消息、项目及配置名；可按项目筛选并回车打开。

## 数据边界

项目、配置、检测与调用结果均为示例，保存在页面内存中，刷新后重置。没有读取本机密钥、运行真实 CLI、连接数据库／服务器、创建调度计划或调用模型。添加配置和终端交互的检查只证明原型流程。

资源表单只保存凭据是否存在的示例标志，不保存敏感值。文件浏览填示例路径；系统目录、诊断、加密存储及持久化留待正式接入。语言入口保留，但完整英文页面尚未实现。此前在前台 Chrome 验证了终端显示、语音示例回填、停止禁用和路由切换；最新无标签布局的复验另见验收记录；修复了终端销毁后异步绘制回调报错。历史 Safari 后台绘制现象及其余 M6 未覆盖项见历史 QA，不由本次局部复验自动关闭。

保持 SmartDD 蚂蚁 Logo。空间入口已移除；定时任务入口保留，暂不开放新建。
