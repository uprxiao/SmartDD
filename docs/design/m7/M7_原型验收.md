## 4. 发现、修正和复验

1. **原型终端销毁后回调报错**：控制台观察到 xterm 读取 dimensions 的错误，定位为异步 write 回调在页面卸载后继续刷新。增加 disposed 标记，保护 fit／refresh，并在清理前置位。重新加载终端、触发 Mic、进入设置、返回终端，未再观察到同类异常。
2. **试用禁用提示不准确**：未保存时原本沿用“任务停止”的通用提示，已改成“请先保存语音设置，再试用”，实际 AX 状态复验正确。
3. **使用准备缺入口**：补充权限／安装说明弹窗。已点验权限弹窗；它只展示说明，不给假授权成功状态。

复验控制台仍有浏览器扩展 chrome-extension://invalid/ 资源错误；不是原型来源。DevTools 另有表单改进提示，未做全站辅助功能审计。不宣称整个浏览器零错误，也不把本次有限观察当作长期无异常证明。
