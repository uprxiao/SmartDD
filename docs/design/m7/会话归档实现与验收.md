# 会话归档实现与验收

日期：2026-10-16。分支：`feature/0.0.1`。应用版本：`0.0.4`。本轮为 M7 开发期间追加的会话管理优化，未提交、推送或发布新版本。

## 需求与参考

用户要求参考本机 Codex，把 SmartDD 会话菜单的删除入口移除，以可恢复的归档整理会话。归档后必须能找到，取消归档回到原项目；中央仍使用终端。

本机参考为 `/Applications/ChatGPT.app`，bundle id `com.openai.codex`，版本 `26.1007.30912`、build `20156`。只读检查其随包前端资源，使用 REA 辅助梳理模块；未读取用户聊天正文、令牌或账户数据，也未操作真实 Codex 会话的归档／删除。

确认的参考行为：

- 运行中归档先确认停止工作，文案为 “Stop and archive this chat?”。
- 归档操作对应 `thread/archive`，取消归档对应 `thread/unarchive`；界面提供归档反馈、撤销与查看入口。
- Codex 存在永久删除能力，不能表述成“Codex 完全没有删除”。本次按用户取舍，仅在 SmartDD 会话菜单中保留重命名、归档／取消归档。
- 官方说明确认归档会话保留，可从设置中的 Archived chats 找回：[Codex 归档说明](https://help.openai.com/en/articles/20001333)。普通 ChatGPT 的归档会话仍可通过历史搜索找到：[历史搜索说明](https://help.openai.com/en/articles/10056348-how-do-i-search-my-chat-history-in-chatgpt)。

静态资源中的文案及调用是实现参考，不等于对 Codex 后端行为的动态验证。未把其 worktree 清理、计划任务删除等行为移植到 SmartDD，未把原应用的打包 JavaScript 加入产品。

## SmartDD 实现

| 场景 | 行为 |
| --- | --- |
| 会话右键／更多菜单 | 重命名、归档；已归档会话显示取消归档；不显示删除 |
| 归档已停止会话 | 保存归档标记，移出常用项目列表，保留记录及关联 |
| 归档运行中会话 | 确认“结束并归档此会话？”；只结束该任务的 PTY，确认退出后才保存归档 |
| 退出失败／超时 | 5 秒内未确认退出则报错，任务不隐藏；可重试，不影响其他会话 |
| 查找归档 | 侧栏“已归档”分组、任务搜索均能找到；搜索标记归档状态 |
| 打开归档 | 只读查看，禁用终端输入，不自动启动 CLI，不提供启动／恢复操作 |
| 取消归档／撤销 | 回到原项目，不自动启动 CLI；需要时再显式启动或恢复 |
| 切换会话期间归档完成 | 不抢走用户已切换到的其他会话 |

主进程负责归档期间的互斥、目标 PTY 退出确认、超时与退出清理；渲染进程等待主进程成功再更新界面。归档反馈提供“撤销”和“查看”。项目、AI 配置等其他对象的删除规则未改。

保留内容包括会话 ID、标题、项目、配置、目录、首次问题与 CLI 会话标识；不会删除 CLI 原生会话文件。同次应用运行中保留现有终端回滚缓冲；退出应用后，SmartDD 不持久化整段终端输出，此时归档页显示会话信息，完整历史仍由对应 CLI 管理。取消归档后可按已有恢复流程继续。不能将本次实现描述为新增了完整终端历史存储。

## 安装后实际界面验收

使用 CUA 操作已安装 QA 的真实页面。项目为“M7 语音验收”，配置为“M7 隔离终端验收”，运行本地输入 fixture；无模型、数据库或 SSH 调用。下面的界面结果与单元测试分别记录，不以脚本结果代替页面验收。

| 操作 | 观察结果 |
| --- | --- |
| 打开右键及更多菜单 | 只有重命名、归档／取消归档，无会话删除 |
| 运行会话 A 归档后取消确认 | 两个终端仍运行，待提交输入保留 |
| 确认归档 A | 返回原项目首页，已归档分组出现，运行数从 2 变为 1 |
| 打开会话 B | `archive-b-draft` 保留，B 继续运行 |
| Cmd+K 搜索“停止与恢复” | 命中归档 A，显示归档标记 |
| 打开归档 A | 同次运行的 `archive-a-draft` 回滚仍可见，输入不可编辑，显示取消归档入口；顶栏没有启动／恢复 |
| 取消归档 A | 回到原项目，运行数仍为 1，没有自动启动 |
| 已停止 A 再归档并点撤销 | 原项目列表恢复 A；重命名和已有信息保留 |
| 正常退出并重启 QA | 归档标记保留；打开归档 A 显示只读信息，运行数为 0 |
| 重启后菜单取消归档，再显式启动 | A 回原项目；显式启动后本地终端可用 |
| 主题 | 深色确认框、浅色归档提示与取消归档入口已实际查看 |
