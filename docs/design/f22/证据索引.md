## 5. 后续如何复查

1. 先核对 Info.plist、package 与整个 ASAR 哈希；版本变化时原偏移、压缩函数名和 Evidence 不再作为新版本事实。
2. 同版本可以按清单的 ASAR 绝对 byte offset 和 bytes 提取选定成员，验证 sha256；不要直接执行 bundle。
3. 文件附录的前端模块及 app-initial 的 L 行号使用 `file-formatted/` 下 esbuild `0.19.12 --format=esm` 副本；其中明确写为主进程 main 的行号例外，使用 `formatted/` 下 Babel 副本。浏览器迁移方案／浏览器附录的 main、app-initial 均使用 `formatted/` 下 Babel parser `7.29.9`、generator `7.29.8`，`sourceType: 'unambiguous'`、`comments: true`、`compact: false`。同一 app-initial 有两份格式化结果，不得混用。类型路由补查 FR1 使用已有 file-formatted，FR2–FR15 使用 esbuild 0.19.12 的 file-route-formatted，FR16 使用 Babel formatted；以各条 formatted_sha256 为准。工具版本变化会改变行号，以原始字节锚点为准。
4. 需要重跑 REA 时，保留原目录布局、明示裁剪范围，使用 `analyze_javascript_application`；精确 module seed 比单独关键词更可靠。只有当工具返回 retained 引用后，才将该原样 ID 传入同一连接的 trace。
5. 大型共享模块由具体导出映射和函数体核对；若需要扩展为完整依赖闭包，另建分析范围，不能沿用旧证据声称新覆盖。
6. 后续运行探针使用隔离项目、可调试实例和自有浏览器 partition；记录实际版本、动作、截图和失败分支，再解决 B4 的 runtime unknown。

同版本最小原始成员恢复示例（在仓库根执行，只向新的本地研究目录写入）：

```python
from pathlib import Path
import hashlib, json

src = Path('/Applications/ChatGPT.app/Contents/Resources/app.asar')
expected = '75e397e2280dde93b70a85aa926f4282c728eacc84dfeb15ba7fb6ddd84628af'
with src.open('rb') as stream:
    assert hashlib.file_digest(stream, 'sha256').hexdigest() == expected
out = Path('release/f22-recheck')
out.mkdir(exist_ok=False)
members = {}
for name in ('file-source-locations.json', 'browser-source-locations.json',
             'file-type-routing-source-locations.json'):
    metadata = json.loads((Path('docs/design/f22') / name).read_text())
    members.update({entry['path']: entry for entry in metadata['files']})
with src.open('rb') as stream:
    for name, entry in members.items():
        relative = Path(name)
        assert not relative.is_absolute() and '..' not in relative.parts
        stream.seek(entry['asar_offset'])
        raw = stream.read(entry['bytes'])
        assert hashlib.sha256(raw).hexdigest() == entry['sha256']
        target = out / relative
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_bytes(raw)
```

该示例恢复已定位成员，不重建完整应用，也不启动应用。四个 host 切片可再按 browser-host-slices 的 member-relative byte offset 提取；辅助 DOM class 的补分号变换需单独遵守，不可混入原文哈希。
