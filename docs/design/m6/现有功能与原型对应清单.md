> 2026-10-16 更新：正式 M6 已接入并完成本机验收，结果在第五节逐项回填。第一至四节保留原型阶段记录，其中“本轮／尚未／未接入”均指 2026-10-15 的原型，不代表当前生产状态。

原型记录日期：2026-10-15。核对基线为当前生产源码（提交 `d5921e2`，应用版本 v0.0.3），不是仅按 PRD 推测。对象为 [独立原型](../../../prototypes/m6-codex/README.md)，本轮没有修改生产 `src/`。

**结论：此前原型没有覆盖齐现有功能。** 项目编辑虽然有入口，但表单简化为名称和路径，缺少完整资源配置；AI 高级配置、导入、能力管理和任务上下文也不完整。本轮已补入对应页面和主要演示操作。页面覆盖不等于真实功能接入或所有状态验收通过；剩余差异见第四节。

## 4. 原型阶段缺口（历史记录）

1. **完整英文、异常状态和快捷键**：已有对应入口，但英文翻译、真实失败详情、恢复失败／不可恢复、配置变化提醒等未完整演示。不能把“有按钮”记为这些状态已通过。
2. **终端当前版本视觉复验**：诊断时 `document.visibilityState` 为 `hidden`，动画帧回调未触发；xterm 缓冲区有输出而显示行未绘制。移除了临时诊断文案，保留按任务缓存输出。需在前台确认彩色文本、输入、字体调整及切换标签后的输出仍正常，不能沿用前轮截图证明新代码通过。
3. **浏览器与正式应用的边界**：目录选择、诊断、连接测试、导入、密钥清理和持久化均为示例。运行历史、点击历史任务自动恢复、应用重启恢复、系统菜单及全部快捷键，须接现有 Electron 逻辑后验证。
4. **视觉**：图标、顶栏控件、同视口逐页对比、浅色、英文、窄窗口与长文本仍按 QA 清单推进；尚未达到全页面完全复刻验收。

F12 自动更新与 F16 实际调度是后续新增能力，不属于被改版删掉的既有能力。正式 M6-A07 验收必须按本表回填每项结果与证据；复用现有业务层，不能用本原型的示例状态替换真实实现。
