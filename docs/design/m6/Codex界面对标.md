# M6 Codex 界面对标与原型说明

日期：2026-10-15。当前交付为界面分析和独立原型，正式 SmartDD 接入须在用户审阅后进行。产品范围见 [M6 文档](../../M6_页面与AI配置体验优化.md) 与 [PRD](../../SmartDD_V0.2_PRD.md)。

## 1. 用户确认的标准

- 按 Codex 的实际布局、视觉和微交互复刻，功能使用 SmartDD 自己的，保留已确认的蚂蚁 Logo。
- 首页的欢迎区和底部任务输入框也要复刻；启动任务后，中央继续显示原生终端，不接聊天消息或工具调用卡片。
- 设置页采用窄应用导航、设置分类、内容区三部分，不额外叠加项目侧栏。
- 项目行悬停按钮、详情浮层、任务右键菜单、分隔线、选中反馈与关闭方式都属于对标范围。
- 去掉“空间”入口；保留定时任务的时钟入口与样式。实际定时执行列入 F16 后续需求，本轮仅占位。
- 当前 SmartDD 的功能、字段与操作必须保留。项目编辑不能缩成名称／路径；逐项映射到原型并记录未完成的状态。

## 4. SmartDD 功能映射

| Codex 视觉区域 | SmartDD 对应功能 |
| --- | --- |
| 项目列表与详情浮层 | 项目、任务数量、代码目录、编辑项目；进入概览／代码目录／数据库／服务器／Skill 与 MCP／项目任务六项完整设置 |
| 任务右键及更多菜单 | 重命名、归档／取消归档、删除；不把分享、分叉等截图菜单视作新增需求 |
| 首页项目／环境栏 | 选择 SmartDD 项目、本机环境、进入任务配置 |
| 首页 AI 选择 | 选择已有 AI 配置；新添加的 Codex 配置立即可选 |
| 设置分类与卡片 | 常规、外观、AI 配置、终端、快捷键、Skill 与 MCP、关于 |
| 任务工作区 | 保留终端和停止／恢复；外层导航、信息和配色使用统一规则 |
| 定时任务 | 时钟入口及规划占位页；PRD F16 后续实施，不建立调度器 |

正式接入优先沿用 `src/renderer/lib/layout/sidebar-tasks.tsx` 的现有任务动作，以及既有项目、AI 配置和终端实现。独立原型中的 React 状态、演示检测和假终端响应不搬成生产业务逻辑。

实际字段、操作、来源及检查结果见 [现有功能与原型对应清单](现有功能与原型对应清单.md)。该清单用于防止视觉改版遗漏功能，作为正式 M6-A07 的逐项回归依据。
