# SmartDD App Logo 风格调研与六版候选

调研日期：2026-10-16。产物为视觉候选，供选择；现有应用图标保持当前已选版本。

## 1. 你偏好的风格叫什么

可以概括为：**极简具象图形标志 + 圆角几何语言 + 单色表达**。如果放在白色底板上再加柔和阴影，则另叠加了“轻浮雕／柔和拟物”的应用图标呈现方式。这是根据用户所给图片和连续反馈作出的设计判断，不是某个官方风格名称。

需要区分三个层面：

| 层面 | 本项目对应 |
| --- | --- |
| Logo 类型 | 以可识别的蚂蚁和杠铃表达含义，属于图形标志（Pictorial Mark） |
| 标志表现手法 | 剪影、线描、负形、几何、可爱吉祥物等，可交叉组合 |
| App 图标包装 | 平面底、圆角底板、轻浮雕、材质或玻璃效果等 |

Adobe 将图形标志与文字标、字母标、图文组合标等区分，并强调简洁、辨识、尺寸适应及品牌含义。[Adobe：Types of logos](https://www.adobe.com/learn/express/web/logo-design?learnIn=1&locale=en)

用户提供的 ChatGPT 图标截图可作为“深色标志 + 浅色底板 + 轻微立体层次”的视觉参考。这里不把它归为唯一的官方风格，也不复制其结绳图案。

## 2. App 图标中常见的视觉方向

以下按设计交流整理，并非互斥、穷尽的标准分类。同一个图标可以同时是“几何、单色、线描”。

| 方向 | 主要特点 | 用在 SmartDD 上的判断 |
| --- | --- | --- |
| 扁平剪影／实心图形 | 用少量填充轮廓表达主体，内部细节少 | 能直接突出小蚂蚁与大重量 |
| 线描／等线宽 | 以轮廓线、圆角和留白构形 | 轻盈克制，需要处理小尺寸线宽 |
| 几何构成 | 用圆、椭圆、矩形等基础形状组合 | 易于形成稳定比例和独特符号 |
| 负形／正负形 | 通过留白形成另一层图形或含义 | 可以表达巧劲；需避免看不出蚂蚁 |
| 极简吉祥物 | 用最少表情和肢体保留角色性格 | 与用户喜欢的初版可爱感一致 |
| 轻浮雕／柔和拟物 | 用浅层起伏、柔和光影给简洁图形增加触感 | 可用在 App 底板和大尺寸展示 |
| 完整 3D／材质拟物 | 体积、反射、材质和光影更充分 | 用户已反馈偏繁重，本次收敛使用 |
| 渐变／双色 | 通过颜色层次建立识别和深度 | 后续可试低饱和色；本轮统一黑白灰 |
| 玻璃／半透明材质 | 通过透明、折射和叠层形成质感 | 需另外验证对比度，不优先用于核心标志 |

Google 的 Material Symbols 提供填充、笔画粗细和光学尺寸等调节，说明这些视觉属性可以分别控制。[Google：Material Symbols](https://developers.google.com/fonts/docs/material_symbols)

系统功能图标与品牌启动图标用途不同，不能直接套用所有规则；但小尺寸时减少细节、检查可读性的原则可作为本项目参考。微软 Fluent 的产品启动图标规范也要求在小于 48 像素时简化细节。[Microsoft：Iconography](https://fluent2.microsoft.design/iconography)

## 3. 这次六版的共同约束

- 核心语义一致：一个原本弱小的个体，借助软件获得远超自身的能力。
- 蚂蚁要能被认出：触角、小头、细腰及分段身体。
- 动作要明确：前肢接触并支撑杠铃，杠铃位于头顶。
- 体量反差要明显：杠铃的宽度和配重显著大于蚂蚁身体。
- 保留低调和亲和感，避免机械昆虫、肌肉人物和复杂金属雕塑。
- 统一黑白灰，先选图形方向，再细化配色和应用图标包装。
- 六版由内置 image_gen 分别生成；无新模型或 API 付费通道切换。

| 编号 | 方向 | 选择时关注 |
| --- | --- | --- |
| 01 | [极简剪影](./01-silhouette.png) | 最直接的力量反差；略带侧身的小蚂蚁，更有动作感。 |
| 02 | [圆角线描](./02-rounded-monoline.png) | 空心轮廓，轻盈克制；小尺寸时需关注线宽。 |
| 03 | [负形巧构](./03-negative-space.png) | 用留白形成蚂蚁，巧思更强；辨识需要多看一眼。 |
| 04 | [几何构成](./04-geometric.png) | 圆形配重与几何身体，规整简洁；气质更偏符号。 |
| 05 | [极简可爱](./05-minimal-mascot.png) | 保留两点眼睛和小笑脸，在简洁与可爱之间取平衡。 |
| 06 | [轻浮雕图标](./06-soft-relief.png) | 极简标志放在浅浮雕底板上，接近完整桌面 App 图标。 |

[打开六版对比页](./index.html)：可查看大图，以及 32／64／128 像素的展示尺寸。小尺寸是浏览器缩放预览，不代表已经完成对应尺寸的人工光学校正。

建议优先比较 01 与 05：01 更强调标志感和动作，05 更兼顾可爱与亲和。若偏爱 06 的底板，可在选定的其他标志上应用同类包装，不必把标志和底板绑定选择。

## 5. 评审方式

1. 第一眼能否看出“蚂蚁举杠铃”。
2. 小蚂蚁与大重量的反差是否明显。
3. 64／32 像素下，触角、身体和动作是否仍有辨识度。
4. 作为每天看到的开发工具，是否耐看、克制。
5. 是否保留用户希望的可爱感，而非只剩健身图标。

本轮是方向选择，尚未将新候选接入代码、导出矢量或重新发布。选定后再修正比例、线宽、细节与各平台图标规格。
