## 4. 共用业务规则候选

第1、2项的连接组织方式已获用户认可；其余细化规则及后文原型中的候选交互仍待评审：

1. 连接保存来源、账号／服务与凭据引用；项目显式选用，任务仅获得本次所需能力。
2. 本地邮箱读取与发信可采用不同适配器。读取不改变 Foxmail 原数据；不会为接入擅自更改服务器删信策略或迁移用户邮箱。
3. 读取、总结／草稿、发送与禅道回写分开。对外操作能审阅目标和内容；逐次确认或范围预授权待用户决定。
4. 外部对象用连接实例与稳定 ID 关联，重抓不重复建任务。Foxmail 的实际 ID／线程／附件关系须以格式验证为准。
5. 写操作超时先核实结果再重试，不能把本地请求 ID 当作远端幂等保证；客户端投递与实际发出分别记录。
6. 本地缓存、正文／附件索引和保留策略需评审。凭据沿用加密存储，调研与日志不保存密钥或不必要的原邮件内容。
