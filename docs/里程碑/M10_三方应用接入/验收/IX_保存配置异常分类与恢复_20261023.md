# IX 保存配置异常分类与恢复

依据：M10 R1.6＋§12.21，R10-15／R08-05，T59。2026-10-23，feature/0.0.2 未提交工作区。

原六项故障矩阵有三项失败：未知认证方式、缺少账号、额外安全字段在持久化读取时返回 INVALID_INPUT。根因是保存配置读取复用表单解析，误报为表单错误；原始失败日志保留。

修复只在 decodeRow 的配置读取边界，将 JSON 语法错误及字段解析 INVALID_INPUT 转成 CONFIG_INCOMPATIBLE；不吞其他异常，不改变新表单校验或身份校验，不改写保存数据。

验证：连接与扩展调用两个文件完整回归 60/60；随后新增损坏 JSON／缺失配置字段两项定向 2/2，确认 authentication 不读取秘密、数据库记录不变、恢复原数据后可继续。完整 pnpm typecheck 通过。六种故障均覆盖读写拒绝、其他应用继续、同一固定 run 恢复，保留工具列表及包字节。

证据：[日志、源快照与哈希](证据/config-errors-ix-20261023/manifest.json)。扩展提供者为编译测试夹具，不能计作真实远端或打包界面验收。生产输入已变，IU 包不含修复；需新构建及受影响打包复验。正式用例仍 16/72，不增加整条通过数。
