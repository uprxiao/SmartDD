## 原证据与边界

M4的RuntimeSnapshot保存Skill版本／hash／投影路径和原MCP名，configHash表示当时的项目资源配置；它并不保存原运行代码hash。`LegacyTaskEvidenceReader`以可信调用方给定的C、HOME、任务／项目／runner和原快照为范围，读取原受管run目录及manifest，不根据当前runtimeIdentity或活动Skill版本猜旧版。原manifest缺失时返回LEGACY_MANIFEST_MISSING；格式、归属或原件不符时明确失败，不补文件或覆盖历史。

核验原快照与run／project／config元数据、固定manifest／audit位置、schema1完整归属标记；从原manifest唯一确定原runtime目录，核对旧legacy-tree-v1完整树及清单全部文件hash。对每个标准Skill核对原版本表、源包、完整投影及实际frontmatter name；不将Codex目录smartdd-<id>-<hash16>当作原生Skill名。Claude同时保留原T/plugin路径及smartdd插件namespace；上下文桥保留原MCP名，Claude实际mcp.json必须使用相同原代码和上下文路径。禁用的原版本仍核对，不物化新投影。

读取拒绝链接、硬链接、特殊文件、增加的执行权限、越界路径、未声明的插件／运行文件和改变的配置／依赖契约；有文件／字节／深度预算，并通过有界fd读取及读前后stat核对。legacy-tree-v1算法和旧标记不改写，不给旧标记补造storeId。证明对象只在本实例RAM中受品牌保护、冻结必要字段；verify重开原件并核对文件身份、内容、模式及原Skill版本记录，复制对象不被承认。

原始依据是**既有受管C/run内清单＋原快照／版本表**，不是外部签名证明。核验结果不能单独作为原CLI已退出、H独占所有者、MCP认证或业务许可；不会授予M10应用。verify不代替迁移事务对tasks.runtime_snapshot摘要、当前身份及资源引用的SQL复查。
