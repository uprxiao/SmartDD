2026-10-21 P07增量：共享原型增加明确标模拟的已有Agent冻结意图审阅／确认等待状态，保留原人工模拟。无窗口浅／深色4个局部检查点及build通过；不是打包App或原生Agent验收。见[阶段记录](../../docs/里程碑/M10_三方应用接入/技研/已有Agent发送意图审阅衔接检查点_20261021.md)。

依据[需求§12.21](../../docs/里程碑/M10_三方应用接入/需求.md)及已确认的固定版本／故障恢复原则，补齐以下合成交互。此节优先于下方历史批次的“多账号待评审／故障状态待补”描述。生产业务开发、真实后台和真实Agent验收没有由此完成。

- 每项目最多一个本地邮件读取来源、一个SMTP发件账号，两组独立单选且均可不选。应用启用状态独立持久化，清空最后一个槽不关闭应用；纯草稿仍可用。旧的同组多选会被提示重新选择，不采用首个账号；坏连接不兜底换账号。未配置SMTP仍可保存草稿。未选读取来源明确显示“未选用读取来源”，不启动模拟检查；已选但离线与完整空结果分别显示。
- 草稿保留原发件账号和项目邮件绑定修订。来源或发件账号变化后拒绝原发送意图，显示原账号／当前账号；用户明确采用当前设置后更新草稿修订，再核对发送。已提交操作的回执仍归属原草稿／项目／修订／账号，不自动重发或转发至新账号。
- Foxmail首版直接只读本机来源，无标准导出导入后备。格式不支持、权限不足、占用／有限重试失败、部分内容缺失分别说明；完整空结果与读取失败区分，查询天数不扩张。草稿与Agent可继续使用。
- 会话应用面板可选择固定包缺失、包损坏、当前配置不兼容、能力桥可原地恢复或需下次启动六种故障（含下述用户能力名称冲突）。修复支持成功／条件未满足失败演示；失败保持不可用，成功保持原版本，默认新版本和任务不变。缺失／损坏只允许同内容标识可信包恢复，配置不兼容不回退密码。桥需下次启动时不提供运行中重连或自动停止入口。
- 本轮真实Agent预检发现用户能力同名冲突，因此增加 `AGENT_CAPABILITY_NAME_CONFLICT`：插件namespace、完整Skill名称或MCP键冲突时应用整体不注入，保留用户能力；“查看冲突”展示明确标注的合成项，“重新检查冲突”默认仍失败。只有显式选择“用户已处理冲突 · 模拟重新检查通过”后才解除演示阻断，工具不替用户改配置、重命名或覆盖能力。配置不兼容错误码统一为运行时契约的 `CONFIG_INCOMPATIBLE`，不维护另一套语义。
- 诊断的“继续使用Agent”关闭会话应用弹窗，回到原终端；不修改任务、快照或后台故障；不阻塞任务，也不伪造真实发现／调用成功。故障开关只属页面演示状态，关闭后不声称持久保存故障诊断；真实状态恢复由后台实现。
