# BA：公共原生能力冲突时的独立加载

依据 M10 R1.6＋§12.21；本批对应 R07-01／02／11、R10-10／17，仍为 AGENTS 第5步开发。父提交 `9d38ee044ac425961a7fa54bdb123429f07626cf`，独立 `feature/0.0.2`。

## 实现

原先项目上下文 MCP、标准 Skill 或 Claude 用户插件同名时，preflight 的全局拒绝使无关能力也被撤下。现在先只读归因：项目 MCP 冲突仅省略该 MCP；单一标准 Skill 冲突／Codex 明确禁用只省略该原 Skill；Claude `smartdd-session` 用户插件冲突则省略全部受管 Skill 和应用桥，保留原项目上下文 MCP。用户文件、原用户启动参数、项目开关和完整 S 不变，不自动改名、覆盖或禁用用户能力。

标准 Skill 使用原 S 中有序的原路径子集。Codex 对完整真实 H 清单生成显式选择，其余原路径 false；Claude 通过现有实际原目录交付协调器生成没有被排除 Skill 的真实目录，沿用原路径与独立占用，不能只改参数而让插件继续发现隐藏的 Skill。全无受管 Skill 时不注入 WillYou plugin flag，用户自己的 plugin flag 保留；独立项目 MCP 仍沿原名注入。

新增 Claude 静态视图 metadata format2，仅用于明确的标准 Skill 子集；format1 继续要求全部原标准 Skill。新格式核对原任务／完整选择 hash、完整 App Skill 组、标准 Skill 原路径及完整物理清单，拒绝外来／重复路径、隐含旧格式省略和额外隐藏目录。实际交付源、原目录 hash 与本轮原根占用凭据相同；加载计划若与实际目录不符会拒绝。未修改不可变 Agent adapter 1.0.0／1.1.0、原 S 或旧 scope／slot 格式。标准 Skill 子集只缩小加载，不授予应用业务权限；原资源长引用／保守占用继续保留。

停止前不因用户消除冲突扩大已启动的加载范围；停止并恢复时重查原 S、同一 native ID 和当前用户配置，再恢复健康原能力。没有新会话替换、后台重发、真实外部操作或发布。
