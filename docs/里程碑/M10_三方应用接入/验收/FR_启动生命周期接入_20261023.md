# FR 启动生命周期接入

macOS main入口改为异步openManagedDatabase：服务创建前取得维护占用，旧宿主预检、日志／备份／迁移协调，关闭业务连接后释放维护，再取得共享占用、重开并重新验证完整迁移水位。返回的close幂等关闭业务库并释放共享占用；沿用probe与will-quit关闭路径。维护到共享的间隙无业务连接或服务，重开时必须复核水位，不沿用旧检查。
