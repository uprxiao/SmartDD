# GA 应用升级启动恢复接线

openManagedDatabase在独占维护阶段发现当前store的application-activation pending操作，要求宿主schema已经匹配且具备恢复入口，再于业务服务启动前执行；恢复后继续核验schema／日志和共享启动条件。main绑定recoverBuiltinActivation，按当前分发index验证buildId、目标hash及可信包身份；不匹配保留原数据并停止维护，不能以不同宿主重跑任意迁移。

7项集成与类型通过。新增测试真实复制失败→关闭数据库／释放lease→无恢复入口启动被拒绝→新启动在maintenance下调用真实升级协调器→ready及默认提交后返回共享客户端。此测试使用本地可信回调和合成包，生产分发resolver已编译类型通过但尚未通过新包验证；不将回调测试冒充真实分发升级全链。
