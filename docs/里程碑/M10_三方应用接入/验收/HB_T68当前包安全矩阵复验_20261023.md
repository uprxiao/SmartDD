# HB T68 当前包安全矩阵复验

依据R1.6及T68原十步，feature/0.0.2当前生产GT包、macOS arm64、固定Codex0.162.1。复用隔离userData/HOME、合成loopback模型，不访问外部业务、不发信，正式TaskService IPC启动真实Codex/MCP；属于服务集成，不是UI输入验收。

当前源码private-broker＋bridge-supervisor共38项通过；production Data API连接授权1项通过；HA同一未变源码broker-scope1项通过。实际读取断言覆盖单票据并发抢占、撤销发生在异步身份核验/诊断期间、迟到握手、旧generation、run撤销、并发恢复同一Promise及有限代次、不得业务重放。

GT宿主关闭重开链13检查通过：实际读取生产Skill的同cwd独立进程无授权请求被拒绝；宿主退出code0，原任务新run与原包／原生身份保留，新端点拒绝旧token，随后真实Codex读取原草稿且不重复创建；四条拒绝响应与持久脱敏审计对应，含重启前记录。

第一次双项目调用漏开SHARED_PROJECT总开关，驱动只运行单项目8检查，不能计为双项目证据。保留原结果，补三个参数依赖断言避免静默降级。完整参数重跑11检查通过：同App两个项目真实Codex/MCP同时active，B读取A草稿NOT_FOUND且没有A正文，B草稿列表为空，A原包／草稿保持。
