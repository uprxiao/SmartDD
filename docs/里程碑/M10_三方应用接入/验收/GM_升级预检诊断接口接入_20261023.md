# GM 升级预检诊断接口接入

R10-16要求升级预检说明受影响版本和原因。源码核对发现启动预检失败只写console，版本页面无法取得这份报告，属于现有范围开发缺口。

已抽出只读builtinActivationReport，同时复用到启动判定与真实ApplicationService.listVersions。主启动传入可信分发目录。报告包含目标应用／版本／内容hash、预检问题及相关taskId／connectionId；不包含配置正文、密码或原始异常。分发读取失败返回unavailable，不伪造成功；未改变旧默认或会话。sender仍先鉴权，随后返回真实版本库存及报告。

真实分发只读报告测试和原升级回归通过，生产node类型通过。[源码及结果](证据/upgrade-report-gm-20261023/manifest.json)。UI尚未接入，原型增量及版本页面展示／测试为下一项；此接口不是R10-16完整交付。GL包不包含本轮生产变更，需后续新包复验。正式15/72不变。
