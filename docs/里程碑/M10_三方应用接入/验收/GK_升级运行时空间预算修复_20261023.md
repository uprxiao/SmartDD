# GK 升级运行时空间预算修复

R1.6＋§12.21范围内缺陷：升级预检仅算目标应用文件、数据库备份与余量，没有计入运行时物化文件，可能错误放行剩余空间不足的升级。新增32MiB运行时预算边界先红测复现，再修复。

预检新增非负安全整数的额外物化预算，并对所有prospective应用按hash去重计入（物化过程会检查完整分发集合）。当前分发、恢复入口及只读升级判断均从可信运行时manifest计算文件字节，传递给协调器。物化后的检查只计算后续所需空间，避免重复计入已经写出的运行时。报告沿原机制持久化且带planHash。

定向回归退出0，生产node类型退出0。完整原始红测、绿测及源码见[证据](证据/runtime-capacity-gk-20261023/manifest.json)。正在重新编译；GH包不包含本修复，后续需新包复验。T60未关闭，正式15/72不变。

后续：GL已完成编译／打包与两版升级、原生复验，见[GL结果](GL_空间预算修复新包复验_20261023.md)。
