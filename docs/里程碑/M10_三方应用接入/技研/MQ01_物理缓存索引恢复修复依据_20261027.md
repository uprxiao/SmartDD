# M10-MQ-01 · 物理缓存索引恢复修复依据

2026-10-27，R1.6＋§12.21、原T17步骤2／4，已授权范围内缺陷修复，**未实现／未复验通过**。依据[实际红测与两个损坏子集](../验收/MQ_T17缓存损坏重建与索引恢复红测_20261027.md)。本文区分已证实、候选和未知；不是已批准的新产品范围或已经完成的技术选型。

## 已证实

原ML包在无Agent、原App正常退出后，本次自有缓存index.sqlite前16字节等长损坏：普通App查询和原清理入口均RESOURCE_RECOVERY_REQUIRED，源／持久草稿正文／业务表保持，两个失败动作的read／C占用均已结束。原坏cache全文件inode／字节保持，原cold副本仅留本机，未用于替换制造绿测。实际根为`/private/tmp/willyou-m10-mail-index-app-icfuFb/damage-header`。

`ApplicationService.clearMailCache`先调用`mailCache()`，后者必须`MailCache.open`成功才可`clear`。原constructor检查并打开同一index，pragma读失败被转换为RESOURCE_RECOVERY_REQUIRED；失败opening promise虽正确清除，后续明确清理仍重复同一路径。现有UI在统计错误时仍保留清理按钮，因此当前证据不要求新按钮／页面；0实际UI输入，不能宣称该错误状态已实测视觉。

原`mail-cache.test.ts`验证对象内容／metadata payload损坏，后者仍是可读SQLite。MQ实际这两个case原入口清理与重建分别6组通过，不能代替物理index损坏。新增`mail-read-data.test.ts`回归精确复现原header损坏、先检测错误、再要求原clear后真实重建并保留草稿；单目标1红／38未选中，原恢复预期未改。

## 已核对的现有协调边界

- MailCache的cache_sessions／cache_leases／cache_writes均在损坏index内，不能依赖读取这些记录来证明没有其他活cache宿主或在途读写。
- Application contexts／C程序lease在独立smartdd.db，可证明已登记动作及内核出生身份；它们不等于全部空闲cache句柄的跨进程生命周期清单。
- 现有`database-access-gate.ts`是独立、持久SQLite inode：普通受管host保留shared事务，迁移／激活维护使用EXCLUSIVE；`openManagedDatabase`在schema／activation需要时交接维护lease。当前接口只暴露assertHeld/release，没有在线shared→exclusive升级接口；不能先释放shared后当作没有窗口，或unlink门闩。
- `withCoordinatorLock`保护C/H资源操作与发布，不自动冻结已经打开的cache句柄。仅拿C lock不能证明其他App不会继续使用其旧cache DB／对象路径。

## 下一项技研与候选，不预填实现

优先验证如何在不丢当前host生命周期保护的条件下独占缓存恢复：研究独立DB access gate的同句柄保锁升级机制，或受控的退出后／启动维护路径；用真实独立子进程证明另一个活host及unknown边界不会被越过。不得把当前一次无Agent现场推广成多App安全。

损坏index无法证明旧树每个文件原登记归属，不能直接递归删除。候选需保留原坏index及未知内容，使用有登记、同卷、可中断恢复的隔离／迁移；但隔离旧缓存仍计入500MB总预算，不能移出统计再复制出第二套完整缓存。要验证源／根／marker／inode／hardlink／symlink变化、未知文件、完整字节预算、并发清理、取消及宿主中断，避免为了修复损坏而破坏原T17保护。

选定方案后在原clear范围实现，不新增自动清理日常数据、不提升原Agent权限；若研究确实改变已确认业务／原型，再形成具体可评审变更，继续不依赖它的工作。当前还不需要用户即时决定。

## 修复与验收门槛

保留现有实际失败根及源码／原包、原cold副本hash和1项软件红测，不靠换DB／手动重建目录／删用例变绿。修复后须在同一原红业务数据上执行新App的真实入口恢复，再核对来源／草稿正文inode、主业务记录、原版本引用及无重复／伪造覆盖；新鲜损坏case也沿用原期望。覆盖活host拒绝、停止后恢复、未知归属／未知身份保留、占用与500MB预算、恢复中断幂等。生产变化重新类型／必要软件／构建六原生及受影响实包回归，不沿用ML旧包宣称修复成功。T17与M10保持未完成；不恢复M9、不发布。
