# MY 来源锁定有界重试修复与复验计划

2026-10-27，R1.6＋§12.21、T16／R05-03／R08-04–06，修复[MX原始发现M10-MX-01](../验收/MX_T16实际来源故障恢复与锁定重试缺陷_20261027.md)。沿用既有开发／测试授权；feature/0.0.2，同HEAD＋工作区，未发布。

原包真实Codex遇BEGIN EXCLUSIVE＋未提交journal，仅attempt1／nonretryable，违反原T16“锁定有界重试”。保留MX源1249、回执、故障快照hash及原用例，不改预期。

复用共用ApplicationToolService原safe-read执行器及三次／总deadline预算，把RESOURCE_BUSY纳入已授权安全读取的有限重试。仍在每次执行前检查当前run及连接授权，取消立即停止等待；trusted retry=never及所有写操作不重放。来源锁定错误码保持RESOURCE_BUSY，耗尽明确attemptCount／retryExhausted；SOURCE_UNAVAILABLE／UNSUPPORTED_FORMAT／权限／认证错误仍直接结束。不会增加层间重试、换包／换账号／重启Agent。

先运行新的恢复成功／耗尽／撤权／取消／不重放红测，再实施并运行tool-service、retry-after、Foxmail及受影响授权／预算回归与完整类型。生产输入变化后新打包、检查Mac arm64原生模块，不能沿用旧MT包作为修复证据。真实原路径复验原MX九组及MT10／共用8；锁持有期间必须同一调用三次后明确耗尽，另补释放锁后同一次调用自动恢复（一个operation、当前原N/S/run、完整120），不以发第二个显式请求替代。普通源消失／格式／半写入与业务继续、原来源bytes／inode／mode恢复、进程／cache账全部复核。

本轮已执行，75软件／类型／6原生及28组实际服务检查通过，原MX红测保留；0UI／Foxmail客户端／macOS TCC／Claude证明。正式仍31/72，T16部分，其他层级与完整十步不因此缩减，目标active。
