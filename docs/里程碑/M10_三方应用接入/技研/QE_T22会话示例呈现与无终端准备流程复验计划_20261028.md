# QE：会话示例呈现与无终端准备流程

2026-10-28，R1.6＋§12.21、原T22/P09与T45已有示例插入/无运行准备输入边界。QD有代码、软件与实包证据，属于进展；正式36/72，T71保持通过，目标active。

当前P09原型用全宽示例，但无运行/不可用时把入口禁用；实际App使用已有ApplicationTerminalButton，在无显式目标时准备本项目输入，不创建/提交Task，而呈现为分离提示和普通按钮。按既有功能与已确认P09全宽示例样式对齐，不新增执行能力：给共用组件增加仅P09使用的可选呈现，复用原typed source/捕获Task-PTY/回执/失效及焦点恢复逻辑，其它页面/compact默认入口保持。有效原目标只追加、不Enter；无目标或原能力不可用仅显示明确“准备新任务”并带入本项目可编辑输入，原会话保留。原型同步同一语义，所有运行/来源仍明确合成。

先留有价值的P无运行/不可用与App新呈现业务保持红测，再实现；不写CSS镜像测试。更新受影响UI定位到实际动作语义，不放松原断言。软件/类型、P构建、独立标准包及六native后，复用原P/A批量窗口与状态，补示例默认/悬停/焦点及准备输入UI。真实Codex沿既有允许的detail-skill隔离分支，扩展P09入口，复用原绑定/投递/输入保持/不Enter/停止后准备输入断言；不启用legacy replyDraft/import分支、不重开SSH/系统剪贴板/钥匙串，也不调用SMTP或真实禅道写。

原T45的旧“同会话同步换版”不恢复；新任务仍按项目当前设置，在用户明确启动时才执行。所有证据按P/U/I/A/native分层，子组和多次执行不增加原72计数；当前范围缺陷修复和必要复验直接推进，不发版。
