# RM：无密保存中与关闭保护

依据需求R1.6＋§12.21／P03／T22-V11；继续用户已授权的用例补验和范围内缺陷修复。沿用RL／RK包及本地来源，原72核心步骤不变，正式48＋1＋23保持。

当前App ConnectionForm在原saveConnection等待时为saving，锁定字段、保存／测试／取消、X／Escape／背景关闭；原型同步提交后立即关闭，缺少可操作的saving对照。先在旧原型保存操作上留下未观察到saving红，再补明确合成的等待／暂存／交回状态，保留原合成身份与存储边界。不得把P人工等待当真实事务或加密存储证据。

为connection-status-ui增加默认关闭的保存模式；旧RL默认模式不改业务流程。A仅允许原自建无密候选保存，暂存**原事务已完成后的成功回执**以观察真实渲染层等待；保存动作必须UI触发，读取数据库／原IPC仅做核验。P用显式合成保存门闩，在合成提交前暂停；两者注入点分别标注，不混同。

浅深×1400×900／700×500，每组合检查保存中字段及三底栏禁用、取消／Escape／X／背景均不能关闭、重复保存不重入；交回后表单关闭且仅保存一次，记录身份／天数及非敏感持久值。正常默认合成保存及RL测试／取消流程做受影响回归。新增组件测试验证保护和清理，复用已有测试而不镜像实现。

生产源码不变则复用RK19pin／ASAR32e9b214…，仅P构建；若发现生产缺陷另新包。保存前后的事务边界、红绿、原值／截图／数据、源／P静态基线和资源清理归档。安全存储、账号及系统项目留后，Claude用户免验保持。当前执行完成；红绿、回归及剩余边界见[报告](../验收/RM_T22保存中关闭保护原型补齐与双端复验_20261029.md)。
