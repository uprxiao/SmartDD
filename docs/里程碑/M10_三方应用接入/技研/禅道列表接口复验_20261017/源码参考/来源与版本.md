## 2. 下载位置、许可与摘录方式

- 官方仓库：`https://github.com/easysoft/zentaopms.git`。通过禁止 credential helper 的公开 HTTPS shallow sparse clone 取得，只读研究副本位于仓库忽略目录 `release/m10-research/里程碑列表复验-source/zentaopms-22.0/`。它不是 SmartDD 的子模块或生产依赖。
- clone 固定为上述 tag；本次核对 `git rev-parse HEAD` 等于固定 commit，副本工作区无修改。
- 根目录 [LICENSE.EN](https://github.com/easysoft/zentaopms/blob/88d6de983014956235e3bf735d225106e38be551/LICENSE.EN)、[LICENSE.CN](https://github.com/easysoft/zentaopms/blob/88d6de983014956235e3bf735d225106e38be551/LICENSE.CN)、[COPYING](https://github.com/easysoft/zentaopms/blob/88d6de983014956235e3bf735d225106e38be551/COPYING) 声明 ZPL 1.2／AGPL 3.0 双许可。原文分别保存在本目录 `.upstream` 文件中，未经修改；PHP 文件自己的版权／许可头也保留在摘录中。
- 本目录只保留调用链所需的小段**公开代码原文**，扩展名 `.php.txt` 表示研究摘录，分段边界清楚，不是可直接运行的 PHP 文件。源码中的中文／英文注释和上游版权不改写；不复制企业版专有代码。
- 本轮仅研究 API 行为；没有把上游服务端 PHP 合入 WillYou。后续选择 API 客户端独立实现或复制源码时，应按实际选用方式处理来源与许可，不以“开源”视为无许可限制。
