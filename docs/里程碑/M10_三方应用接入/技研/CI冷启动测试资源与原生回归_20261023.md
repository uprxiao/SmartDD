## 可复用的冷启动准备

在项目根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm test:prepare
pnpm typecheck
pnpm test
```

`test:prepare`构建当前平台原生文件Broker、内核进程探针、MCP运行时及完整受信资源索引，并实际校验新探针协议／自身PID的就绪；不下载Office／TeX资源、不启动App、不授应用权限，也不生成安装包。测试仍由Electron自带Node执行，以匹配原生ABI。应在一批测试开始前准备，不在另一批读取`out/`时重建。

需要独立空目录验证可运行`node scripts/prepare-test-resources.mjs <本次独立输出目录>`；默认输出是`out`。只有构建就绪不能证明任何正式用例通过。App验收仍按公共流程构建完整应用，使用本次包及其哈希。

Markdown两种原生集成来源分别留证，不能混写为App界面验收。仓库中的未签名构建与包内经过签名处理的原生文件具有不同二进制摘要，各记各的实际hash；不能因源码相同沿用旧原生hash。

正式M10目标继续；Claude Code真实分支按既有跨机交接补验，钥匙串、可见App及真实外部资源缺项保持原边界，未发布。
