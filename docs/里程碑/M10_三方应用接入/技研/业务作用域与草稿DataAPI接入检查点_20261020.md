## 实际接入范围

主进程现在装配真实连接、项目选用、草稿、业务附件、作用域和资源服务，并注册受信主窗口的 `applications` RPC。目录／配置、连接测试后保存、启停／断开、项目选用及草稿／正文读取已有明确端点。页面和真实Agent启动器尚未接入这些端点；不能据此宣称已从App完成业务。

原包纯CJS通过固定路由实际执行六个Data API：`mail.draft.list/get/create/update/copy`和`mail.resource.read`。草稿创建不依赖Foxmail／SMTP，SQLite保存原修订和CAS结果；UI、Claude与Codex逻辑运行可读同项目对象。新回复来源必须由宿主核实，尚未接入验证时返回明确不可用，不凭模型提供的引用伪造回复。查询、邮件原文、回复／附件导入、发件意图及发送方法的生产Data API仍待接入。

## 宿主身份与授权

| 入口 | 身份依据 | 本批边界 |
| --- | --- | --- |
| 页面业务 | 实际Electron sender／mainFrame、宿主签发operationId、真实项目及当前默认包 | 不编造taskId／runId；查看器、子frame和销毁sender不能调用 |
| 连接管理 | 同一受信sender，限定配置动作，记录connection-management scope | 项目未启用也可配置；不能借管理scope读邮件、改草稿或发信 |
| Agent | 当前实际RunRegistry与固定快照／package／工具契约 | 不接受模型自报项目、任务、包或approved；本批集成使用受控原生身份，没有真实CLI模型路径结果 |
| 使用触发的索引子任务 | 有效父操作及独立jobId／C占用、父operationId | 只读；单父操作结构已实现，共享刷新协调及多等待者取消仍待实现 |

上下文和MailActor以宿主WeakMap身份为凭据；序列化再还原、展开复制、结束后的对象均没有权限。0016记录角色、项目／运行／父子关系、固定包、动作、scope摘要、目标修订与最终状态，不保存秘密或正文；数据库约束同时阻止UI冒用任务、索引冒用项目scope或外部写语义。该记录是宿主业务操作账，与工具调用账、发送意图及SMTP执行账各自关联，不混淆实际执行和结果交付。

全局及项目启用策略与各来源槽修订分开。停用再启用使旧操作和旧工具回执失效；只换Foxmail／SMTP槽不阻塞独立本地草稿。业务实际读取某连接时登记原身份、配置、策略和槽修订，变更或清空再选的ABA不能交付旧结果。同身份仅秘密轮换可读取当前秘密，不把秘密值、secretRef写入作用域账。缓存回执也重新核对授权代次及登记目标，并保留原operationId、执行次数和effectState，不靠新建写操作恢复旧回执。

关闭时先停止本实例任务与PTY，再等业务作用域收口。实际回调尚未结束时，其UI／索引C占用保留；排队尚未进入业务的操作在取得协调后再次核对关闭／取消，不能在关闭之后启动provider。连接测试的父取消也在登记凭据前、调用provider前及接受验证结果前核对。协议等待有界与底层Worker／子进程真实退出属于不同层，完整provider、运行及跨进程恢复仍需后续验收。

## 稳定业务资源

`application_data_resources`只存业务引用元数据，正文仍在草稿修订，附件仍在 `U/app-data/mail` 的持久副本。引用由项目、应用、数据契约、对象、修订与字段共同标识；不以创建它的Agent、包版本或当前默认包作为业务数据寿命。原包hash和operationId保留来源，不作为旧代码永久占用，也不添加会阻止项目删除的外键。来源缓存不借此表在500MB预算之外保存正文。

返回的正文ResourceRef使用固定包1.0.0 DTO；读取核对项目、契约、权限、原hash／字节数／类型，再核对实际原修订内容。每块最大256KiB，按字节偏移，分裂UTF-8或二进制使用base64以保证无损；超出原末尾报错，末尾返回明确EOF。更新草稿、由另一Agent读取、业务服务重建均保留原修订引用。当前读取会校验完整业务对象；并未将它当成邮件缓存、增量索引或性能验收。

## 验证边界与接续

新增集成覆盖真实SQLite、原包／CJS路由、固定Session／Run／ToolService、草稿／附件文件及RPC注册；加密器、内核进程身份和连接身份测试明确使用私有夹具。两个受支持Agent指两种固定会话runner参与同一后端链路，不是已运行真实Claude／Codex。没有日常账号、邮箱、原生会话、模型调用或真实发信。

保留红测：项目级停止的第二项目夹具重名；关闭期间排队操作仍启动一次；新增连接取消测试的锁父目录缺失和对既有候选失败记录状态的误判。分别修正独立项目数据、生产启动前守卫、私有目录前置及按原有failed／CANCELED记录核实，未放宽隔离、无迟启动或凭据清理断言。最终结果以结构化证据为准，重复执行不累加用例数。
