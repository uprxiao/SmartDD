## 3. 需要补齐的部分

1. **Story 本人列表**：复用认证身份，核对产品／项目范围、本人指派关系、分页／去重与 UI 一致性；Task／Ticket 不混入。

3. **Agent 能力**：以按需列表、详情和资源引用为主，将 Bug 与 Story 的原始类型／ID／来源保留；按用户选择关联 WillYou 项目，不强制执行旧 SVN 修复流程。
4. **动作**：在读取验证后分别核对 Bug 与 Story 的动作、必填数据、权限和结果回读；本轮没有解决、关闭、评论或改变指派。

## 4. 开源复用候选

已实际打开禅道官方维护的 [easysoft/zentao-api](https://github.com/easysoft/zentao-api) 与 [zentao-cli](https://github.com/easysoft/zentao-cli)。SDK 为 TypeScript／JavaScript、MIT，动作定义带不同产品系列的最低版本；`biz13.0` 与 `biz13.5` 有区别，不能直接把最新注册表中的全部动作当成本实例可用。已完成固定提交的[接口提取](../技研/禅道13.0接口复用清单.md)；其中本人工作清单两条接口最低biz13.5，不作为本机13.0默认方案。

本轮不安装 SDK，不运行其会创建／修改／清理数据的真实环境测试，不因 README 的覆盖声明而宣称本实例已调用通过。实际纳入生产前仍须核对来源声明、版本锁定、主进程凭据存储、站点子路径及现有兼容经验。
