# M10 原型说明与变更 · V2

2026-10-17，依据[需求R1.3](../需求.md)，M10-R01–R09／P01–P09。状态：**可操作原型已形成，待用户评审；不是正式App业务实现**。用户认可连接组织并授权制作，尚无原型批准commit；恢复快照及哈希见下文。

## 1. 访问与数据边界

[打开原型](http://127.0.0.1:4176/?preview=m10#apps)。现有共享Vite服务在127.0.0.1:4176；页面内场景控制在顶部标题栏，可切初次、加载／空／错误、权限／认证、邮件锁定／格式、禅道部分页／详情缺失和长文案；右上按钮切换主题。

仅合成数据；不连接真实禅道、邮件或Jenkins，不读取Foxmail源，不运行模型／真实CLI。单独localStorage键 `willyou-m10-prototype-v2`；保存公开示例配置、凭据存在标志、绑定和脱敏记录，不保存秘密输入／真实正文。草稿按钮只记录草稿状态，正文不保证刷新恢复。清除该键或选择初次／已连接示例可重置；场景本身是本次内存状态，不当作真实权限／网络证据。
