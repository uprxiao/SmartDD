R1.3 开发评审稿，2026-11-24。来源为 F34。2026-11-23 用户确认阶段顺序。2026-11-24 用户明确本阶段的两个交付重点，并授权完成变更后的开发前工作。正式开发由用户另行确认。目标平台为 macOS arm64 打包 App，浏览器身份、权限和右侧任务区分别接续 M12 和 M14。 [需求池](../../需求池.md) · [M12](../M12_浏览器自动化/需求.md) · [M14](../M14_统一Agent工作区/需求.md)

## 用户目标与范围

在 WillYou 右侧内置浏览器完成两类任务。Agent 可以观察当前页、执行本次操作并根据更新后的页面继续判断。已有测试流程可以交给 WillYou，在任务指定的标签执行用户现有 Skill 生成的 CDP 测试包，并返回可核对的结果。

开页、复用、登录接力和结果核对是两条路径共用的基础。首版兼容以 `source-driven-ui-test` 的冻结测试包和 Node.js 直接 CDP 运行方式为验收基线。用例设计、数据准备及脚本生成由外部 Skill 负责。独立端到端测试助手、任意第三方脚本、Playwright 直连和定时任务另行评估。 [调研](调研/README.md) · [M16 定时任务](../M16_定时任务/README.md)

## R01 复用标签并及时显示

- 一次开页可按目标匹配或新建，并处理展示意图。目标为网址或指定标签，使用任务选用的浏览器身份。按当前任务、同一身份和完整网址匹配，保留路径、查询参数和锚点。指定标签要核对归属和身份。没有合适页或明确要求另开时创建。并发复用请求共用同一待加载页。相同请求编号只返回原回执，改动目标、身份或开页意图须用新的请求。
- 用户明确要求打开或展示时，当前任务右侧先选中目标标签，新页先显示加载状态，再在同一标签更新就绪或失败。纯后台取资料时保留当前视角。发出展示意图后，用户切任务、面板或标签会使旧展示失效，即使随后切回原处。迟到结果留在原任务，可通过「查看网页标签」进入原页。
- 区分已接收、加载中、可操作、失败和取消。页面可操作以原标签的主文档已打开且约定的业务条件可核验为准。停止任务、撤销授权、关页或用户在同一标签改址使旧导航失效，迟到结果不得恢复旧页。失败后可在未关闭的原标签重试。

## R02 登录接力和继续执行

- 优先使用任务为该页选定的身份。同身份已有会话可直接开始。遇到首登、过期或站点要求本人验证时，提示在原页或该页的认证弹窗处理，并保留当前任务、标签、登录身份及已确认进度。依赖该页的步骤持续暂停，原运行结束后也保持等待。
- 本人从任务卡点击「已登录，继续」后，核对原任务页已回到业务范围且具备可读的业务标记。弹窗已登录时仍需核验原业务页。过早确认保留同一张卡和确认版本，并说明原因。原执行轮结束时，核验通过后绑定可接手的运行，同一确认只继续一次。密码、验证码等由本人在站点表单或现有认证框输入。
- 用户取消、停止、关页、换身份或撤销授权后，此次继续入口失效。App 重启时，仍待确认的请求保留等待状态。已确认且能证明尚未派发的请求，在重新核对原任务绑定、标签、身份和业务状态后可自动继续一次。若只是认证过期，原卡进入新版本并请本人重确认。用户已停止的任务保持停止。派发结果不确定时转入 R03 的只读核对。

## R03 Agent 观察、操作和再观察

- Agent 可读取任务当前获准页面的结构化状态，包含页面身份、URL、可访问控件及后续操作引用。结构信息不足时，可在同页截图补证。Agent 根据观察选择路径，能用被允许的帮助入口、同身份弹窗或替代菜单完成任务。真实模型验收提供任务目的和正常入口，具体操作路径由模型判断。
- 常见点击、填写、选择和导航可在同一次工具调用中选择返回操作结果及更新后的结构化页面状态，减少单独读页的往返。等待以相应页面或业务条件为准。新状态须来自本次动作后所在的已授权页面。发生导航、控件引用失效、歧义或观察超时时，分别反馈动作与观察状态，允许在当前页重新观察。旧页面引用不得在新页面继续使用。
- 分别反馈页面观察、工具动作和业务结果。业务完成须通过状态、记录编号、页面内容或实际下载文件核实。下载场景至少核对文件存在和用例规定的内容。失败、取消和结果未决均能定位到原步骤及已留存的回执。
- 写入可能已派发时，按原编号和任务归属只读查询原回执或业务结果，后续运行沿用同一检查点。网站响应丢失和工具回执丢失分别核对。无法判定时显示「结果待核对」，暂停依赖操作并保留原步骤。旧回执过期或详情找不到时仍保持未决。这次操作不得被再次派发。

## R04 在任务标签执行既有 CDP 测试

- 接收由用户现有 Skill 生成并冻结的兼容测试包，使用宿主认可的直接 CDP 运行方式。受支持的测试可包含读取真实页面结构、真实点击和键盘输入、等待、断言、截图及下载。任务区展示原标签入口、用例及步骤状态、失败位置和可核对产物。下载由 WillYou 按标签归属管理。
- 使用本任务已有的真实网页标签和登录身份。提交时核对测试包可读、格式和版本兼容、摘要有效、目标标签属于任务且当前身份与授权相符。授权绑定测试包版本、目标标签、身份和获准访问范围。脚本只能操作该目标及明确允许的页面范围。其他任务标签、全局浏览器调试及会影响其他标签的浏览器设置不向脚本开放。
- 执行只在有效授权及同一标签、身份和业务站点范围内推进。直接指定越界目标在派发前拒绝。站点触发的越界顶层跳转使后续脚本动作停止。合法认证转移交给 R02，本人核验通过后按可确认的原检查点继续。脚本暂停、取消、超时、权限撤销或原页关闭时，停止派发后续动作。正常结束或停止仅释放本次运行权限和连接，任务原页与会话仍可使用。用户主动关闭原页时不复建该页。
- 审批展示目标与可读摘要。运行记录关联提交的测试包摘要、执行编号、用例或步骤状态和证据引用，不保存凭据及完整敏感表单值。相同执行编号查询或重复提交均返回原执行记录，同编号换包、换身份或换页时报冲突。一次新的有意复跑使用新编号并核对授权。
- 写入效果未明时以 R03 的原回执和只读核对处理。重启后保留已知结果及未决记录，停止的任务保持停止。有可信检查点且能证明下一动作未派发时才允许继续。未知写入不得自动重发。

## 交付与验收

R01、R02 以同页加载、登录、首次接续和重启恢复取证。R03 用入口会改变的合成站点和真实 Agent 验证观察、操作、再观察及独立结果核对。R04 复用 `source-driven-ui-test` 自带的 `CATALOG-CHOICE` 和本地站点，在 WillYou 真实任务标签中复验读取结构、下拉选择、回读和截图。另覆盖下载归属、取消与重启、旧引用失效、越界、收尾留页及未决写入。所有候选验证都标明实包、平台、运行入口、当前标签与对照数据。

一次工具调用可开页并按意图展示。既有手动链接、CLI、MCP 入口及权限按实际运行计划验证。记录开页授权就绪至右侧可见、同口径站点请求至业务标记可读、操作至可用新状态或业务核对结果、整轮任务。显示顺序实验和配对测速使用各自约定的响应条件。真实性、作用域、同一确认只续接一次和未决写入防重均为硬性判据。正式登录站点由对应验收在执行前确认。 [技术方案](技研/技术方案.md) · [原型状态说明](原型/原型说明与变更.md) · [验收用例](验收/测试用例.md)
