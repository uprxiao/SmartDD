# M15 内置浏览器任务自动化优化

R0.1，2026-11-23。来源为 [需求池 F34](../../../需求池.md)。本阶段接续 [M12](../../M12_浏览器自动化/需求.md) 的浏览器和登录身份，并使用 [M14](../../M14_统一Agent工作区/需求.md) 的任务工作区。用户确认阶段优先级和四项范围。交互、执行契约和验收用例待评审。

## 目标

用户提供站点和业务测试目标后，Agent 在 WillYou 内置浏览器中完成开页、登录接续、功能定位、操作和结果验证。重复测试可以在原标签和登录身份下通过脚本复跑。首轮真实 App 验收在 macOS arm64 进行，其他平台范围随阶段评审确定。

| 编号 | 需求 | 验收目标 |
| --- | --- | --- |
| M15-R01 | 复用与显示 | 按当前任务、访问目标和浏览器身份选择合适的标签。明确另开或没有匹配标签时创建。要求展示时，右侧显示同一页的加载、可操作或失败状态。纯后台查阅和用户主动切换任务按经评审的展示规则执行。 |
| M15-R02 | 登录接续 | 使用任务选定的浏览器身份复用登录态。遇到需要用户完成的登录或验证时，保留当前标签和操作进度，经用户完成后核对实际业务页并继续。验收覆盖首次登录、登录过期和身份隔离。 |
| M15-R03 | 探索与验证 | 根据页面状态查找入口，必要时查询有权访问的站内帮助或公开资料。操作后观察结果，遇到页面变化、弹窗或路径失效时核对状态后继续。以页面状态或实际产物确认业务结果，并记录失败所在步骤。 |
| M15-R04 | CDP 脚本复跑 | Agent 可以编写多步脚本，在任务指定的标签和登录身份内执行。脚本复用任务授权、暂停和回执语义，返回步骤、断言或产物。现成 Playwright 脚本的可移植范围待兼容性实验决定。 |

## 交付顺序

第一批验证 R01–R03，使用同一条需要登录、能换入口且有可核对结果的站内用例。第二批交付 R04，用该用例对照模型逐步操作与脚本复跑，核对取消、超时、标签关闭以及结果不明时的恢复。

记录批准到右侧出现、导航到可操作、操作到可判定结果和整轮任务时延。性能目标由打包 App 基准与用例评审确定。隔离实验范围和结果见 [调研](../调研/README.md)。定时调度由 [M16](../../M16_定时任务/README.md)评审。
