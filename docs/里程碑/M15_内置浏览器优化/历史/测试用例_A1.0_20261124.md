# M15 内置浏览器验收用例

A1.0 评审版，2026-11-24。共 28 条。依据 R1.0、T1.0、P1.0。表内的实际结果、状态和证据是正式执行栏，待候选包验证。 [需求](需求_R1.0_20261124.md) · [技术方案](技术方案_T1.0_20261124.md) · [原型状态](原型说明与变更_P1.0_20261124.md)

## 环境与准备

- U 为单元，I 为主进程、浏览器服务或真实 Electron 组件集成，A 为 macOS arm64 隔离打包 App。每条须完成标注的全部层级。A 层从任务区和右侧界面走真实交互，使用当前隔离包 UI 驱动。允许读取服务回执、数据库副本与证据文件作断言。
- 使用统一的合成本机「报表站点」。账号 A 的业务页有「报表中心」标记，B 身份独立。登录后可使会话过期，首页的旧报表入口可调换或失效，替代入口在业务页面和站内帮助中可找到。提交十一月报表会生成唯一记录号与 CSV。每条或每组使用独立记录标识。站点能保持响应、按约定截短回包、返回错误、开启站内弹窗并统计真实提交及下载次数。
- R01–R03 与 R04 分两批执行。先把 S1 开页、S2 登录接力、S3 探路和核对组成连续流程，再跑 S4 脚本。同一候选包内可批跑正常用例，权限、重启、故障注入使用独立任务与身份。界面状态覆盖浅／深色、窄窗、长网址与键盘可达性，截图记录包版本和尺寸。
- 完整流程由启用内置浏览器的任务执行。确定性场景可用受控执行器触发真工具，Agent 自主探路和整轮延迟使用实际支持的执行器，记录 CLI/MCP 入口、Agent/模型与输入。真实站点使用用户授权的独立验收账号，由用户完成需本人处理的登录或认证。验收前记录站点、登录流程、成功标记与可操作范围。
- 用例通过需要观察到规定的状态和结果。网络、操作超时必须有条件观察和上限。截图、下载摘要、操作回执、服务端计数和性能事件在执行时入账。现有基线回归和独立实验见 [合并后复验](../技研/实验/合并后复验_20261124.md)。
