# M15 内置浏览器任务自动化优化

R1.1 开发前评审稿，2026-11-24。来源为 F34。2026-11-23 用户已确认阶段顺序和四项范围。2026-11-24 用户授权完成开发前工作。本版根据旧包与隔离实验确定标签匹配及展示、登录接续、首版脚本和验收判据，提交评审。目标平台为 macOS arm64 打包 App，登录、身份管理和右侧任务区分别接续 M12 和 M14。 [需求池](../../需求池.md) · [M12](../M12_浏览器自动化/需求.md) · [M14](../M14_统一Agent工作区/需求.md)

## 用户目标

用户给出站点和业务目标后，Agent 在 WillYou 右侧浏览器中找页、操作和核对结果。有可复用的标签就继续在同一页做，明确要求另开或没有合适标签时新建。需要本人登录时保留原页，完成后接着走。重复测试可以将同样的业务步骤写成脚本执行，并核对页面或产物。

## R01 复用标签并及时显示

- 开页意图包含目标网址或指定标签、是否另开、是否展示，以及任务选用的浏览器身份。按当前任务、同一身份和目标网址匹配，保留有业务意义的查询参数和锚点。用户指定的标签要核对归属和身份。没有合适页或明确要求另开时创建。并发请求复用同一待加载页。
- 用户明确要求打开或展示时，当前任务的右侧先出现选中的标签和加载状态，网页就绪或失败后更新原标签。纯后台取资料时保持用户正在看的面板。用户换任务或主动选了其他面板／标签后，迟到的浏览器结果保存在原任务，可从结果进入原页。
- 能区分已创建、页面加载、可操作和失败。停止、重试、关闭围绕原标签处理。关闭后的迟到结果不能恢复该页。页面可操作以目标页已打开且约定的业务条件可核验为准。

## R02 登录接力和继续执行

- 优先使用任务为该页选定的身份。同身份已有会话可直接开始。遇到首登、过期或站点要求本人验证时，提示在原页或该页的认证弹窗处理，并保留当前任务、标签、登录身份及已确认进度。
- 用户点击「已登录，继续」后，核对已回到原业务范围且满足可读的业务标记，再继续下一步。过早确认时保留原请求和等待状态，并说明缺少的条件。原执行轮已结束时，等待新运行绑定，同一个确认只恢复一次。密码、验证码等仅由用户在站点表单或现有认证框中输入。
- 用户取消、停止任务或关闭目标页后，此次继续入口失效。重启后的旧请求须重新核对原绑定、原标签和业务状态。不得以切换账号、身份或已派发操作的重新执行来恢复。

## R03 探路和核对业务结果

- 通过页面结构、可访问名称等信息在已授权范围内寻找入口。路径失效、跳转、弹窗或元素变化时，重新读取现场，再选替代路径。必要时可参考用户允许访问的帮助资料。关键能力覆盖实际页面变化和从备选路径完成任务。
- 完成操作后，用状态、记录编号、页面内容或实际下载文件证明结果。中止、失败和结果未决均能定位到具体步骤及原回执。发生可能已经派发的写入时，先只读查询原回执或业务结果。没有可核验结果时保留未决状态，暂停后续依赖操作。
- 已读到页面、页面动作结束和业务结果已核验分别反馈。下载场景至少核对文件存在和用例规定的内容。

## R04 对当前页执行可复跑脚本

- Agent 可写版本化、多步骤的浏览器脚本，在任务获准的一个标签和身份内执行。首版用结构化步骤调用已有页面操作，支持由读页和等待、表单填写或选择、点击、断言、下载、记录组成的流程。步骤、失败点、断言和产物可追查。
- 沿用浏览器授权、任务暂停、停止、超时和回执。每一步都核对执行身份与当前页。已派发写入结果未知时，脚本在该步骤停下，后续从可核验的检查点接续。重复提交同一执行请求可查原结果。
- 通用 Playwright 脚本直连要等独立适配能够证明兼容性和任务隔离，首版评审范围以受控的步骤脚本为准。定时触发另见 [M16](../M16_定时任务/README.md)。

## 交付与验收

第一批用同一条需要登录、入口可调整且结果可核对的站内流程验证 R01–R03。第二批用这条流程复验 R04，比较 Agent 逐步操作和脚本复跑。记录开页授权就绪至右侧可见、发起导航至可操作、业务操作至确认、整轮任务四段时延。受控等待下的显示顺序、跨任务隔离和写入只发生一次是硬性判据。性能对照、测试站点与正式登录准备见技术方案及用例。 [技术方案](技研/技术方案.md) · [原型状态说明](原型/原型说明与变更.md) · [验收用例](验收/测试用例.md)
