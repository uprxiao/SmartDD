# M15 旧包开页基线

2026-11-24。功能基线 `60e7f65452e96f2f76c9fa82725f972822d2091a`，macOS 26.6.1 arm64，Electron 42.11.14。采用之前留存的 WillYou 0.1.7 包。包启动记录的提交及 `app.asar` SHA-256 与本轮核对一致，实验前后摘要相同。SHA-256 为 `dd479fc4cf868a50e59b5f2bfb3f6c88ec95e190cdeb55651cba5838377c2e3f`。 [脱敏记录和逐次数据](证据/60e7f6545-旧包开页基线.json)

## 方法与判据

- 用仓库 Electron 驱动启动独立包，核对 PID、可执行程序、HOME、userData、页面及窗口位置。点击聊天链接、批准和结果卡都用 CDP 输入。读取右侧实际呈现的地址与加载状态，并在挂载的 WebContents 验证同页的可操作标记。用事件条件轮询，间隔 20 ms。
- 网页和模型响应均走两个独立回环服务。实际 Claude 2.1.329 按旧包的真实 MCP 工具流程调用开页和切换。本地模型夹具提供确定性响应，消除公网和生成内容波动。旧 Agent 开页控制组在站点收到请求后记录右侧状态，再放行响应；出现结果卡后驱动立即点击查看。已打开页控制组先收起面板，再实际批准 `tab switch` 的 `focus` 路径。
- 从批准按钮释放计到右侧选中实际地址，中间另外记录请求到达、结果卡和页面可操作。手动链路从点击释放计时。网页不缓存，受控阶段由测试放行。每轮使用新目标，无目标和已有目标在同次实验配对；CPU 16 核，平均负载与尺寸随结果保存。该数据描述同一进程的缺页与已有页。正式性能对照另采 App 冷启动。

## 结果

| 现有入口 | 样本与结果 | 中位数（最小–最大） |
| --- | --- | --- |
| 点击聊天链接，新地址 | 5/5 先显示标签，网页发布响应后在同一页可操作。实际访问一次。 | 点击到右侧可见 25.9 ms（24.1–28.5），点击到可操作 72.8 ms（71.5–185.0） |
| 再次点击同一聊天链接 | 5/5 新建另一标签，均增加一次页面请求。 | 点击到可操作 71.0 ms（71.0–72.6） |
| Agent 新开，审批模式 | 5/5 到达站点时右侧未展示目标。完成后均由驱动点击结果卡才展示。各实际访问一次。 | 提交批准到请求到达 766.6 ms（759.9–779.6），到结果卡 964.8 ms（952.2–987.3），到驱动点击后右侧可见 991.4 ms（978.5–1013.6） |
| Agent 明确显示已打开页 | 5/5 使用原标签，额外站点请求为零。 | 提交批准到右侧可见 901.1 ms（851.2–933.4），到可操作 908.7 ms（855.0–942.2） |

两轮各有 20 个样本，全部完成对应界面和站点动作，包正常退出。上表为固定驱动及夹具摘要后的最终一轮。两轮的显示顺序及是否复用一致。时间已含旧版控制链和观察间隔。新页旧流程的大段时间在批准后、网页首次收到请求之前。加速研发先保证发起开页的一次工具调用直接提交可见标签，再继续分段测量宿主调度和网页加载。这里测量的是旧版；新版的成对样本、真实站点速度和公网模型时延需用候选包另测。 [测量驱动](../../../../../scripts/browser/m15/baseline-app.mjs)
