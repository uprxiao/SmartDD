# E07 · Skill 用例接入内置页面

2026-11-24，macOS arm64，Electron 42.11.14，Chromium 148.0.7778.280。WillYou 浏览器源码取自 `60e7f6545`。实验在独立 HOME、userData、Node 子进程和回环站点中运行，浏览器视图实际挂载到实验窗口的内容区，窗口未激活。使用已安装 App 内已校验摘要的 helper 文件。 [结构化证据](证据/60e7f6545-Skill接入CDP与页面观察.json)

## 做法与证据

先沿用 Skill 生成的封存基线。独立 Chrome 的原生运行器已跑通 `CATALOG-CHOICE` 和 `TEAMS-CHOICE`，随后取 `CATALOG-CHOICE` 的冻结用例、页面准备、控件定义、用例处理器和断言。复用 CDP 驱动的读取、输入、等待和截图实现，实验只替换连接初始化，使独立 Node 子进程经私有 IPC 把命令发给原生视图对应的 `BrowserCdpProxy`。正式 WillYou 运行模式所需的套件预检、运行回执、业务清理和权限审批由候选 App 验证。 [实验启动器](../../../../../scripts/browser/m15/run-skill-cdp-study.mjs) · [Electron 驱动](../../../../../scripts/browser/m15/skill-cdp-study.ts) · [Node 驱动](../../../../../scripts/browser/m15/skill-cdp-study-worker.mjs)

| 场景 | 实际结果 | 设计影响 |
| --- | --- | --- |
| 运行既有用例 | 提交夹具登录表单后，原页显示合成登录标记。冻结用例发送真实键鼠事件，断言 `Option 1` 通过，独立读取页面也获得同值。连接释放后，选中视图仍是同一个原生 WebContents，登录标记仍在。获得 2560 × 1640 PNG，夹具业务写入计数为零。 | 可以从 Skill 的连接初始化处适配宿主，保留原用例、控件方法、断言和关键运行证据。 [截图](证据/E07-目录下拉选择.png) |
| 操作后观察 | 同一页 DOM 标题从 `catalog` 开始。发送一次实际点击切换模块，随后读取 DOM 标题和完整无障碍树，二者均观察到 `teams`。未接入模型。 | 动作与新页面观察可以由同一个任务入口协调。模型自行选择路径和动作后观察的产品返回结构留给候选验收。 |
| 标签隔离与取消 | 另一任务拥有独立浏览器分区，仍显示 `catalog`，未出现登录标记。在实验连接查询其他目标时遭拒绝。等待不可达状态时撤销连接，Node 收到断开并退出，后续无键鼠派发，原视图保留。 | 任务页会话可以独立于标签释放，并将取消传到驱动。范围校验、权限变化、重复请求和候选包接线继续按用例取证。 |

首次实验的 Skill 断言已经通过，实验追加的独立 DOM 读回只匹配了部分 AntD 类名，返回空数组。同页截图可见 `Option 1`。校正独立读回方式后复跑通过，冻结用例和判据的摘要均未变化。 [首次现场](证据/E07-首次读回定位失败.png)

另在独立 Chrome 中运行 Skill 自带的 `--business-checkpoint` 反例。它预期 `Option 7`，界面实际选中 `Option 1`。报告将原断言记为失败，后继回读标记未执行，保留页面截图。另一条自带用例正常通过。WillYou 候选包用同一反例验证它的任务卡、回执和截图归属。 [反例截图](证据/E07-Skill独立反例截图.png) · [反例结果摘要](证据/60e7f6545-Skill接入CDP与页面观察.json)

## 复跑

从仓库根目录执行。使用本地已安装的组件依赖和任一符合当前 Skill 清单的本机合成冻结基线。没有已有基线时，先跑 Skill 自带示例，取回执中的 `baseline` 目录。检查 helper 摘要与实验环境记录。

```sh
node "$m15_skill_root/scripts/run-component-demo.mjs" --frontend-root "$m15_fixture_dependencies"
node scripts/browser/m15/run-skill-cdp-study.mjs \
  "$m15_skill_root" "$m15_skill_frozen_demo" "$m15_fixture_dependencies" \
  "$m15_packaged_helper" "$m15_packaged_helper_sha256"
```

启动器打印独立运行目录，保留 `result.json`、`evidence.json` 和截图。复跑应看到冻结用例断言通过、原视图与夹具身份标记保留、返回新页面结构、撤销等待时无新输入，以及同页文件内容核对通过。实验仅证明隔离场景下的接入可行性。实际 App 的任务授权、全套 `run-suite` 接入、正式取消通知、真实业务登录、用户可见效果和速度对照，以候选包验收为准。 [技术方案](../技术方案.md) · [正式用例](../../验收/测试用例.md)
