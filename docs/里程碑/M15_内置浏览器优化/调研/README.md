历史实验中 201.87 ms 与 85.66 ms 是合成站点业务页已经就绪后的执行段，路径与等待方式也不同。当前实验补证了先回加载中标签、后置页面就绪的顺序。整轮体验、用户见到右侧的时间和模型走错路径后的恢复，仍由同包、同夹具、同结果的正式用例测量。 [性能设计与判据](../技研/技术方案.md#性能与实施顺序)

## 2026-11-24 开发前补验结论

- R01 已取得旧包的手动开页、Agent 审批开页、Agent 显示已有页的实际对照。现有「查看网页标签」和 `tab switch --focus` 可以复用。新入口的改动集中在宿主开页与展示事件联动。 [实包开页基线](../技研/实验/旧包开页基线_20261124.md)
- R02 实验验证了过早确认保留请求、原页核验、跨轮绑定一次、撤销和因会话再次失效而停止。普通宿主校验会按失败退休，登录等待期需只校验归属，用户确认和新运行绑定时才核验业务状态。 [登录接续实验](../技研/实验/登录接续与报表夹具_20261124.md)
- R03/R04 已从共享报表夹具复验两次实际提交、第二次回包中断、原结果回读和 CSV 内容。加上原单页 CDP 技术实验，现有受控步骤所需的页面、身份、操作和证据能力已核到。通用 Playwright 适配、真实站点登录和候选包的脚本执行仍按各自的验收边界处理。 [报表实验](../技研/实验/登录接续与报表夹具_20261124.md) · [CDP 实验](../技研/实验/合并后复验_20261124.md)
