| 隔离 Node 在执行前退出 | 运行器未派发 CDP 命令，原页及另一页未改变。 | 确认为 macOS 动态加载器初始化缺少对根目录项的访问。沿用已有文件查看器的根目录项规则后，在相同冻结输入及隔离条件下复跑，实际页面断言通过。 [原失败](证据/20261124-source-runner/startup-failure.json) |
| 原开页请求重放时审计行与原标签不匹配 | 相同请求可能被审计层误拒绝。 | 审计行重放继续使用原已绑定标签。专项回归核对同号回执、不同指纹拒绝和同网址只安排一次导航。 |
