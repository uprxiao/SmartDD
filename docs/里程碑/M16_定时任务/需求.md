## 1. F16 目标与范围

用户为项目任务指定执行时间或周期，系统按计划选择项目、代码目录和 AI 配置运行任务，并提供可追溯的结果。复用届时已交付的任务运行、Skill、历史和交互能力，以及已有项目和 AI 配置体系；与 M14 新运行入口的具体联动在本阶段设计时明确。

## 2. F16 需求项

| 编号 | 需求 | 已记录行为与需要展开的规则 |
| --- | --- | --- |
| M16-R01 | 创建和编辑计划 | 名称、项目／目录、AI 配置、任务说明、执行时间／周期和时区；字段校验和周期类型待设计 |
| M16-R02 | 管理计划 | 查看计划及下一次执行时间，暂停、恢复、删除；变更对已开始执行的影响需明确 |
| M16-R03 | 调度与执行 | 到时使用正确的项目及配置发起真实任务；避免错误归属和重复触发 |
| M16-R04 | 运行记录 | 展示触发时间、运行状态、对应任务入口、结果或失败原因；每次运行与计划关联 |
| M16-R05 | 异常与恢复 | 应用退出、电脑睡眠、错过时间、配置不可用、重叠执行、失败重试和时区变化有明确策略 |
| M16-R06 | 提示与操作边界 | 无人值守时允许的行为、需用户处理的情况及通知方式在评审前定案 |

核心流程：配置计划 → 校验并保存 → 展示下次执行时间 → 到时触发 → 关联实际任务 → 查看结果／失败原因 → 按规则继续、暂停或重试。

计划状态与运行状态分开：计划的启用／暂停不等于某次运行的等待／运行／成功／失败。具体状态枚举、取消语义和恢复机制在技研后与需求同步定稿。

## 3. F16 待定业务规则

- 首版时间规则：一次性与重复周期支持哪些，时区与夏令时如何解释。
- 应用关闭、睡眠及错过执行时是补跑、跳过还是等待确认；当前未承诺应用退出后仍执行。
- 同计划前次未结束、多个计划同时触发、配置被改动／删除时的处理。
- 自动重试次数、重复执行防护、记录保留与通知；计划删除是否保留历史。
- CLI、凭据和外部操作的可用条件；M10 的禅道／邮件能力按最终联动规则调用；Jenkins 不作为本阶段前置要求。

## 4. F16 验收目标

按最终规则验证准确触发、项目／配置归属、下一次时间、暂停／恢复／删除、重启、睡眠／错过时间、重叠与重试，以及记录与实际任务对应。正常和异常用例均需明确前置时间、操作及可判定结果，不能只检查计划列表能显示。

## 6. F36 内置浏览器单窗口承载重构（新增）

**需求版本：F36-R0.1（2026-11-25 范围与架构方向已确认，详细方案、实验及用例待评审）。** 父依据：F25／M12 浏览器自动化、F34／M15 内置浏览器优化，详见 [M12 需求](../M12_浏览器自动化/需求.md) 与 [M15 需求](../M15_内置浏览器优化/需求.md)。本节是 F36 需求的唯一维护位置。

### 6.1 背景、目标与边界

- 当前反馈一：普通内置浏览器创建独立透明后台窗口，macOS 调度中心／全屏空间可能显示黑色缩略图并占用位置。
- 当前反馈二：关闭旧标签后再次请求打开网页，出现继续使用已关闭标签、开页参数冲突；后来后台新页成功但右侧未及时显示。展示事件被忽略的具体阶段仍待隔离复现。
- 用户确认：产品处于前期开发，应优先建立可长期维护的浏览器承载层；保留 Electron WebContentsView，采用 BaseWindow＋多个 WebContentsView 的单主窗口组合，借鉴 Orca 的稳定页面生命周期及按需绘制思想。不直接迁移到 Electron WebView，也不以仅隐藏独立窗口作为 F36 的完成条件。
- 目标：普通网页在主窗口内承载，前后台切换、重开、并行任务及主窗口隐藏时均有明确定义的行为，现有浏览器业务能力、数据与安全边界不退化。
- 包含：主窗口承载适配、网页生命周期和原生层级、后台绘制保活、标签重开和 Agent 展示链路、现有接口与数据兼容、相关回归及系统层验证。首个实测开发平台为本机 macOS arm64；其余平台沿用 M12／M15 的已确认范围，未验证平台不外推，正式交付边界需评审确认。
- 不包含：重做浏览器全部 UI、替换 agent-browser／CDP／应用能力框架、修改外部网站或放宽登录／权限规则、浏览器插件市场或 Computer Use；不因 F36 更改 F16 的调度、无人值守授权和外部操作策略。合法的用户可见登录子窗、系统对话框等不是本次禁止的背景黑窗。

### 6.2 需求项（沿用 M16-R01–R06 为 F16）

| 编号 | 需求 | 规则与验收边界 |
| --- | --- | --- |
| M16-R07 | 单窗口浏览器承载 | 普通网页不再创建独立透明系统窗口、Dock 或调度中心额外条目、独立全屏 Space。主窗口正常、隐藏／恢复、最小化、全屏、跨桌面／显示器时保持既有外观、窗口操作与任务体验。显式登录子窗按原规则保留。 |
| M16-R08 | 标签与页面生命周期分离 | 任务、面板、标签切换或主窗口隐藏不得等同关闭网页；已加载页的浏览器身份、文档、导航历史、未提交表单及在途合法操作保持。显式关页、删除任务／身份或真实退出按原规则释放对应资源；恢复保存标签时建立新原生页面身份，旧文档引用不得复用。 |
| M16-R09 | 后台绘制与执行 | 页面可在主界面后方按需绘制，当前查看页正常显示。后台闲置不作无必要持续绘制，Agent 命令／截图等需要绘制时恢复，操作结束释放相应占用；不能使页面状态丢失、后台任务意外暂停、截图空白／过期、输入未实际送达、抢系统焦点或截获用户操作。对主窗口未显示、隐藏、最小化及多窗口层级分别验证；性能、资源阈值沿用适用的 M12 验收契约。 |
| M16-R10 | 保留工作区交互 | 右侧浏览器标签、地址栏、导航、查找、下载、设置、权限、认证、弹窗、快捷键、拖动／缩放、浅深色等既有行为继续可用；浏览器与文件／MCP 预览、差异、终端、菜单、弹层正确分层。不得用背景页覆盖或拦截当前界面。 |
| M16-R11 | 关闭后重新开页 | 用户明确再次要求打开网址时，只匹配当前任务、同一可用身份及完整目标网址的仍存在标签；无匹配时创建新标签并返回新 ID。旧关闭 ID 和旧页面引用失效，明确指定失效 ID 的操作不得自动恢复、替换成其他页面或重放旧动作。开页工具将网址与已有标签 ID 的互斥关系明确表达给 Agent，提供标签不存在／参数冲突的可执行恢复提示。 |
| M16-R12 | 新开页展示与用户选择 | 用户明确要求展示时，右侧先呈现新页／加载状态，成功或失败在同一目标标签更新；关闭最后一个标签后重新发出的展示意图有效。只做后台访问不抢当前界面；新请求发出后的真实用户切换／关闭仍优先，迟到旧回执不得重新打开已关闭页或覆盖用户选择。未自动展示的成功结果提供查看对应标签入口。 |
| M16-R13 | 兼容业务与安全边界 | 保留项目／任务与 profile 隔离、现有标签与历史、持久 Cookie、下载、权限、证书、登录接力、关联弹窗，以及 MCP／CLI、Agent 自动化、脚本／操作回执契约；原数据结构及身份分区优先不变。可信 UI 与网页内容隔离，不因更换承载方式放宽网页、业务授权或用户本人确认。 |
| M16-R14 | 宿主异常恢复与资源收尾 | 冷启动的单窗口宿主、组件挂载、初始化失败、关闭中导航、渲染进程重载／退出、页面崩溃、删除身份及应用真实退出须有可核验的状态与清理结果。不得遗留无主原生视图、后台窗口、页级 helper 或重复派发；不确定效果的动作按现有回执规则查证而非盲重试。 |

### 6.3 联动及验收

- F36 与 F16 在同一 M16 内独立跟踪。先证明浏览器宿主能力再接 F16 涉及浏览器的集成；F16 既有 R01–R06 及待定策略不变，调度授权继续由 F16 决定。F36 不承诺 App 真实退出后仍能调度或访问网页。
- [技术方案](技研/技术方案.md)明确现状、目标宿主、迁移步骤、接口／数据与异常；[实验计划](技研/浏览器单窗口承载实验计划.md)包含风险门槛和已归档的初步证据。
- [原型说明](原型/原型说明与变更.md)继承 M12／M15 浏览器界面，记录 F36 受影响状态；[测试用例](验收/测试用例.md)按 R07–R14 关联验收草案。BE00 小实验只证明特定本机合成页的初步可行性，不代表真实 App、Mission Control、多平台或完整业务验收通过。
- 进入正式开发前：实验门槛、详细方案、受影响原型状态和用例完成评审；本次用户授权为纳入 M16 并准备需求、设计和实验，未启动生产改造。
