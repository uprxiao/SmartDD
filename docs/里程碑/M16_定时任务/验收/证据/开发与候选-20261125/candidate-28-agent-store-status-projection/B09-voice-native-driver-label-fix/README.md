# M16 B09.5 真实语音快捷键录制、取消及自动复位

此驱动只执行 B09.5 的原生录制与菜单快捷键子项，使用已有 C28 精确隔离启动和 AppKit 前台观察器。其它工作区系统快捷键、真实后台浏览器操作和 B09 的余项独立验收。无录音、设备采集、实际全局快捷键注册或用户数据读取。

B11 资源长测结束、共享系统前台释放后，可启动：

```sh
node release/m16-qa-support/b09-voice-recovery/driver.mjs --coordinator-authorized-b09-voice-native
```

仅选择输出标明的「WillYou · M16 B09 语音快捷键测试 <尾号>」测试窗。初始已进入语音设置，打开的全局唤起为未保存的临时草稿，保留正式持久关闭状态。连续保持该窗口前台。驱动根据真实状态自动开始三次录制。

1. 第一轮出现“按下组合键…”时，按 ⌘B 一次。按钮恢复“录制”后等约2秒，再按 ⌘B 一次。第一次应录入为临时 `Command+B`，不触发原菜单。第二次应真实触发菜单。
2. 第二轮录制自动出现时按 Esc。恢复“录制”后等约2秒，再按 ⌘B 一次，核原快捷键恢复。
3. 第三轮录制自动出现后保持测试窗前台，约60秒内不输入、不切窗。看到“录制已超时”提示后按 ⌘B 一次，继续停留直到测试版自动退出。

退出前驱动通过真实界面撤销临时草稿，核实际原持久语音配置相同。原 AppKit 前台和 native shell 聚焦均须稳定。失焦、窗口变化或按键结果未知即停止依赖动作。人机系统键由本人输入，驱动不通过 CDP 模拟系统键。全程只记录测试窗前台布尔与本轮界面结果，没有全局按键采集。
