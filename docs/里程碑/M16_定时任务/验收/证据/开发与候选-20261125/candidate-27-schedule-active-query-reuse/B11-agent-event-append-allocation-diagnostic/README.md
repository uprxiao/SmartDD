原 C27 已正常关闭的独立合成库实际 864 个 `agent_events`，仅取了数量、平均长度139.3字符等聚合，未读取正文。`AgentStore.appendIn()` 每事件重复编译两条固定 SQL。用当前真实 Electron Node ABI、原事件表DDL、最小合成父表、7个虚构任务、新建独立内存SQLite、864次真实事务，六新进程交替对照；每次 seq 与全部实际行数正确。未启动应用／模型、未强制GC、未改生产。原实际数据及脚本见[短诊断](actual.json)、[脚本](control.cjs)。
