### 变更与需求/用例映射

| 状态 | 对应需求与 A 组 | P0.1 → P1.0 当前表现 |
| --- | --- | --- |
| P01 列表／导航 | R02 R04；A01 A37–A42 A50 A52 | 保留时钟侧栏，显示计划名称、项目/无项目、频率、Agent＋Provider/模型/档位、下次、最近状态、启停；增加已结束和需确认等筛选、通用任务合成分组及通知入口，不增加普通项目。 |
| P02 新建/编辑日程 | R01 R03 R05；A01–A08 | 原 5 类型增每月（29–31 缺日跳过／最后一天）与 Cron；保留间隔、日历周期和仅一次；支持跟随/固定/其他 IANA 区，显示前三次时间和错误；保存后 interval/once 锚定。 |
| P03 项目/目录/任务配置 | R01 R03 R06；A09–A23 A43–A49 | 从必选项目改为可选，系统分配独立/本机目录；3 工作区及任务去向组合，选择绑定任务显示实际目录且普通配置跟随；支持原三 Agent/Provider、模型档位、适用权限、委派与完成通知偏好。不同执行器权限选项不同；新 full 或修改已保存计划权限时先明确确认，取消保留原权限。 |
| P04 详情及管理操作 | R02 R04；A36–A42 | 独立计划状态与运行状态；编辑/暂停/恢复/立即运行/删除，忙碌提示，删除记录可查；一次性结束后仍可手动或改日期。 |
| P05 运行及工作区历史 | R03 R04；A09–A22 A34–A42 A49 | 展示每次计划时间与实际时间、耗时、实际配置快照、任务/回合/工作区及 base/branch、原因/尝试；停止独立于计划暂停，失败可新记录重试；精确任务/回合定位预览。 |
| P06 异常/恢复 | R03 R05；A24–A35 A40 A48 | 准时、仅最新补跑、宽限跳过、同计划/同目标占用；安全启动重试同记录、未知先核对不能盲重试、绑定关键变化需明确确认/失效需修正；复用模型跟随和已改期单次不被旧运行终结。 |
| P07 审批及通知 | R04 R06；A43–A52 | 使用普通权限语义，取消一律禁写；插件审批、邮件需本人逐次确认、本人网页登录等合成等待，未处理前不能伪造完成；通知演示去重、点击精确记录，成功通知可选。未实现真实业务工具/OS 通知。 |

P1.0 演示中的通用任务分组、不关联项目字段和精确定位卡反映真实 UI 的业务状态；正式接线时在现有任务侧栏与统一任务区实现真实 task/turn 跳转，不复制另一个对话 UI。实际系统文件选择器、原生浏览器、窗口、权限与通知不在浏览器原型实现。其他里程碑入口和已确认视觉不更改。
