## F36 受影响界面及状态（2026-11-25 初稿）

F36 属底层承载重构，R0.2 评审范围沿用 [M12 原型说明](../../M12_浏览器自动化/原型/原型说明与变更.md) 和 [M15 原型说明](../../M15_内置浏览器优化/原型/原型说明与变更.md) 中既有浏览器与右侧面板，以原布局、字体、颜色、主题、入口及正常交互为视觉基线。无需为 F36 重画整套页面或新增独立 UI 原型；必要增量仅限缺陷状态及行为核对。本次未修改共享原型或确认新视觉版本。隔离实际旧／新开发构建的等尺寸 AppShell、网页和 HTML 预览对照作为现有页面复用的技术证据，见 [BE01–BE08 记录](../技研/实验/BE01_BE08_20261125/README.md)；非新原型或正式系统视觉验收。[Ultra 实际自有窗全屏合成与壳重载修正证据](../技研/实验/BE01_BE08_ULTRA_20261125/README.md)补充既有界面保持及故障状态对照，未引入新的视觉页面、未替代真实系统/用户体验验收。

| 需求 | 对应原型／真实 App 待评审状态 | 预期变化 |
| --- | --- | --- |
| R07、R10 | 主窗、右侧网页/文件/MCP/终端/差异、窗口和各浮层 | 外观及入口保持，后台页不在系统独立窗口占位；几何、遮挡、焦点等真实 App 验收 |
| R08–R09 | 同任务多页、跨任务切换、收起／恢复右侧、后台执行标记 | 可见状态变化不销毁网页，后台可执行、不抢用户位置 |
| R11–R12 | 关闭最后标签、空面板、再次请求打开、加载、失败、成功结果及查看入口 | 新请求显示目标页；自动空面板清理不得撤销更新展示，显式关页／切换撤销旧意图；旧事件不恢复关闭页，页面身份与回执一致 |
| R13–R14 | 现有身份/权限/认证、弹窗、重启/关闭状态 | 保留交互规则与持久数据；异常与恢复用例由候选验证 |

在设计评审前标明哪些既有原型状态直接复用、哪些缺陷状态需对应调整；以相同主题、窗口尺寸和缩放比较旧包与候选包的实际界面，不为凑阶段流程新做无 UI 变化的页面。系统空间/窗口、原生层级和后台绘制必须取真实 App/系统证据，不能用静态原型冒充验证。本子项与 F16 的定时任务原型独立评审。
