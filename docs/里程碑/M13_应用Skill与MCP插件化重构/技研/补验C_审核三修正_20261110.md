## C1　G01 参数控制／数据分离（`c1-emit-v3.mjs`、`wy-mcp-launch.sh` v3、`c1-test.mjs`）

做法：按审核方式把生成器返回的全部槽放进父进程环境（模拟 Claude 目标共用槽环境），再执行生成出的包装命令。

| 用例 | 结果 |
| --- | --- |
| 旧红：B 目录 v2 生成器＋v2 包装器，beta 字面参数 `@WYARG:WY_MCPV_1` | beta 实收 `["decoy-alpha-key"]`，复现审核 |
| beta 字面参数分别为 alpha 的新槽名、旧式槽名、未知标记、`--arg` | 四例 beta 均原样收到该字面参数、无 Key、无槽残留；alpha 自有 Key 正常 |
| 两个 MCP 不同 Key、各带模板参数 | 各自只得到自己的值，模型 Key 被清除 |
| 含 `${HOME}`、`$5` 的字面参数 | 走槽并原样到达（防 Claude 展开） |
| 同名自有 Key（B2 回归） | 保留自有值，槽清除 |
| 来源缺失／非私有槽来源／索引越界 | 分别退出 65／64／64 |
| 缺变量整台不生成、带凭据 URL 拒绝（B3 回归） | 通过，无孤儿槽 |
| Codex 目标生成形态 | `--arg` 位于 `--` 之前，`env_vars` 只列本服务器槽，形似标记的参数原样写入 |

第一次运行 `--arg` 用例判失败：测试命令为 `node -e <脚本> --arg`，`node` 把 `--arg` 当成自己的选项报错（包装器已原样传递）。改为 `node -e <脚本> -- <参数>` 后通过；原结果保留为 `c1-result-attempt1-test-error.json`。

## C2　G02 不静默覆盖的还原落盘（`c2-restore-swap.mjs`）

文本层沿用 B4 v2（解析、单行定点编辑、整份比对）不变，只替换落盘：

1. 读取并计算新内容，写同目录临时文件（保留权限位）；
2. `rename(原文件 → 捕获文件)`，原子取得此刻真实内容；
3. 捕获内容哈希须等于第 1 步读到的哈希，否则用 `link` 放回并放弃；
4. `link(临时文件 → 原路径)` 仅在原路径不存在时成功，期间若有程序新建或写入则 `EEXIST`，保留对方内容并放弃；
5. 成功后删除临时与捕获文件。

| 注入点 | 结果 |
| --- | --- |
| N1 无并发 | 逐字还原，权限 600，无残留 |
| W1 校验后、挪走前写入（审核注入点） | 放弃，外部内容在原路径，无残留 |
| W2 挪走后，外部以原子 rename 新建 | 放弃，外部内容保留，无残留 |
| W3 挪走后，外部直接写文件 | 放弃，外部内容保留，无残留 |
| W4 挪走前改过且挪走后又新建 | 放弃，两份都保留并在结果中报告路径 |
| W5 期间文件被删除 | 放弃，不重建 |

代价：第 2 至第 4 步之间（微秒级）原路径不存在，此刻读取配置的程序会看到“无配置”。已写入需求补记和技术方案。

## 更正（2026-11-10，第四轮审核后追加）

[第四轮审核](../../../review/review-20261110-1753.md)补出 C2 未覆盖的三个反例：外部程序在捕获前已打开文件、捕获后经旧句柄写入，结果返回成功但修改丢失；挪走后进程中断，原路径持续缺失；硬链接不可用时回退同样依赖 `link`，原文件未放回。因此上文“任何并发写入都不会被静默覆盖”“缺失仅微秒级”的结论过宽，C2 不成立。用户决定改为只读检测＋提醒＋还原指引，WillYou 不自动写回全局配置；C2 仅作为实验记录保留。C1（G01）与 G03 结论不变，已被第四轮审核关闭。
