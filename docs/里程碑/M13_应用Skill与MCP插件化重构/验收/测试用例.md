**共用夹具**（开发阶段建立，路径在执行计划中登记）

| 代号 | 内容 |
| --- | --- |
| F-PLUG | 合成插件包：`demo-tracker`（合法，文件夹与 .zip 两份，含 1 个 Skill、2 个能力、声明式列表）；`report-kit`（`hostApi` 为 `^2.0`）；`native-helper`（含 `runtime/helper.node`）；`broken`（缺 `.willyou-plugin/plugin.json`）；`mail` 同名包；`demo-tracker 0.2.0`（升级）与 `0.2.0-bad`（激活时初始化失败）；`crashy`（启动后 1 秒退出）；`slow`（不响应 `execute`）；`flood`（单帧超限、输出超限、并发与子进程超限各一种能力）；`bad-ui`（声明式界面引用不存在的字段）；`escape`（尝试读写 WillYou 数据目录、数据库、其他插件私有目录、钥匙串测试条目，含子进程与符号链接两种绕过） |
| F-ZT | M10 禅道本地模拟服务＋上一版本 WillYou 的禅道数据快照（2 条连接、3 个项目授权、含旧工具名调用记录的历史会话） |
| F-MOCK | 本机模拟模型端点（Anthropic Messages、OpenAI Responses 各一，可按令牌返回成功／401／5xx，并记录收到的认证头与请求体标记）；拒绝并记录所有外连的代理 |
| F-MCP | 探针 MCP：stdio 与 http 各一，记录启动 argv、环境变量白名单子集、请求头和工具调用；含只读工具 `wy_echo` 与写工具 `wy_write` |
| F-SKILL | Skill 来源：Claude 用户级、Codex 用户级、项目级（`.claude/skills`、`.agents/skills`）各若干，含相对脚本与 `VERSION` 标记，可改为 v2 或删除 |
| F-PROJ | 项目 P1、P2（Git 仓库）、P3（非 Git 目录）、P4（P1 的 git worktree）；P1 内放项目 `CLAUDE.md`、项目 `.claude/settings.json` 与 `.claude/settings.local.json` 的恶意样本（改地址、改 Key、`apiKeyHelper`） |
| F-LEGACY | 旧 AI 配置快照：CC-work（原生登录）、CC-deepseek（BASE_URL＋单一认证变量＋已知模型映射）、CC-rj（含未知变量）、Codex（仅已知选项），以及引用它们的历史任务 |
| F-CFG | 用于全局模型提醒的合成 `config.toml`：单引号、行尾注释、原无 `model` 键、多行字符串四种 |

**环境约束**：不读写用户日常 `~/.claude`、`~/.codex`、钥匙串真实条目或日常 WillYou 数据。涉及保存 Provider Key 等安全存储的打包 App 用例，按 AGENTS“安全存储”规则不把 `HOME` 指向临时目录，登记为 S 层或用户实测；其余用例使用独立 `userData` 与发现根目录。真实 Provider 只用用户授权的 Key 与最小调用。

**统计规则**：按唯一用例编号统计。多次执行、多主题、回归不重复计数。`待执行`、`失败`、`阻塞`、`跳过` 都不计通过。
