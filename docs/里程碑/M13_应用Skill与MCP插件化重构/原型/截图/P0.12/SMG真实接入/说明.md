# SMG 真实接入（原型 P0.12 补充，2026-11-11）

用户提供 SMG 内网网关地址 `http://<SMG 内网地址>` 和一个 Key，要求在原型上真实接入看效果。这是原型“只用合成数据、不发网络请求”规则的**唯一例外**，只适用于目录中的 SMG。

- **怎么接的**：浏览器直接请求局域网地址会被跨域拦截，所以由原型开发服务器只转发 `/__m13-live/smg/*` 到这一个地址（`prototypes/m6-codex/vite.config.mjs`）。真实请求的代码在 `src/m13-live.mjs`。
- **Key 的处理**：用户在页面里填写，只保存在本页内存，刷新即丢失；只随请求头发出，不写入任何文件。走查驱动从环境变量读取 Key，不打印；结果文件和截图中没有完整 Key，截图里只有脱敏后四位，这是界面本身的脱敏方式。
- **无 Key 探测**（命令行，2026-11-11）：`/health` 200；`/v1/models`、`/v1/chat/completions` 返回 401（缺 Key）；`/v1/messages` 返回 Anthropic 格式的 401；`/v1/responses`、`/anthropic/v1/messages` 返回 404（网关不支持）。结论：SMG 有 Anthropic 和 OpenAI 兼容接口，没有 Responses 接口，所以只适用 Claude Code。
- **带 Key 核对**（命令行，只读模型列表加一次最小工具调用）：模型列表为 Anthropic 格式（`data[].id`、`display_name`，名称前缀“云”“私”），共 13 个，ID 带版本后缀（如 `deepseek-v4-pro-0813`），和用户截图里的列表不完全一致。`deepseek-v4-pro-0813` 流式加强制工具调用返回 `tool_use`，`stop_reason: tool_use`。
- **页面走查**（`p12-smg-live.mjs`，结果 `smg-live-result.json`，6/6，零错误）：
  - 错误 Key 显示网关返回的 401。
  - 真实 Key 获取到 13 个模型。
  - 接入时探测到 Anthropic、OpenAI 兼容，没有 Responses；推荐模型按前缀匹配为 `deepseek-v4-pro-0813`，工具调用测试通过（约 2 秒）；只生成“Claude Code · SMG”。
  - 详情中 Codex 列为“—”；`glm-5` 单个真实测试通过并写回。
  - 编辑下拉列出全部模型，并标出可用、未测试、推荐。
  - 页面中没有出现完整 Key。
- **回归**：接入 SMG 后 P0.12 走查 28/28（`p12-result-SMG接入后回归.json`），单测 30/30。
