3. 委派：`delegation-service.ts`、`directory-queue.ts`、`git-workspaces.ts`、`owned-command.ts`；核重叠根、空闲 owner、停止／取消排空、返工范围、宿主 Git 意图及进程退出前不交槽。
4. 业务：`host-business-requests.ts`、`business-browser.ts`、`applications/agent-business-tools.ts`、`run-registry.ts`、`task-capability-launcher.ts`；核等待与执行期限分离、原 run 已退出时的有限宿主作用域、批准重验、待绑定／停止竞态、原资源与实际执行租约、未知效果不重放。邮件与插件继续使用原 M13 执行与来源账。
