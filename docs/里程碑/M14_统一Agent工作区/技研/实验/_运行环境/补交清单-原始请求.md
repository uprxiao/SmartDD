## 4. 收集脚本

在那台电脑上，把 `REPO` 改成 SmartDD 仓库的实际路径，然后运行。脚本只读取 `/private/tmp`，把文件写入仓库目录，不会提交：

```bash
REPO=/Users/hx/projects/SmartDD   # ← 改成那台电脑上的仓库路径
DST="$REPO/docs/里程碑/M14_统一Agent工作区/技研/实验/_运行环境"
mkdir -p "$DST/bin" "$DST/tmp" "$DST/deps"
cd /private/tmp || exit 1

for d in willyou-m14-* willyou-m10-config-fix-9_31ogou; do
  [ -d "$d" ] || continue
  # 脚本与配置原样复制；排除依赖、数据库、运行输出、隔离 HOME 及任何凭据目录
  rsync -a \
    --exclude node_modules --exclude '*.sqlite*' --exclude 'attempt-*' --exclude 'recovery-*' \
    --exclude 'home' --exclude '*-home' --exclude '.codex' --exclude '.claude' --exclude 'auth.json' \
    --exclude '*.tar.gz' --exclude 'process-identity' \
    "$d/" "$DST/tmp/$d/"
  # 依赖清单
  if [ -d "$d/node_modules" ] || [ -f "$d/package.json" ]; then
    mkdir -p "$DST/deps/$d"
    for f in package.json package-lock.json pnpm-lock.yaml; do [ -f "$d/$f" ] && cp "$d/$f" "$DST/deps/$d/"; done
    (cd "$d" && npm ls --all --json > "$DST/deps/$d/npm-ls.json" 2>/dev/null)
  fi
done
for d in willyou-m14-browser-cli-probe/dependencies; do
  [ -d "$d" ] || continue
  mkdir -p "$DST/deps/$d"
  for f in package.json package-lock.json; do [ -f "$d/$f" ] && cp "$d/$f" "$DST/deps/$d/"; done
  (cd "$d" && npm ls --all --json > "$DST/deps/$d/npm-ls.json" 2>/dev/null)
done

# 进程身份助手
[ -f willyou-m14-owner-probe/process-identity ] && cp willyou-m14-owner-probe/process-identity "$DST/bin/"

# 环境信息
{
  echo "collected_at: $(date -u +%Y-%m-%dT%H:%M:%SZ)"
  echo "homebrew_node: $(/opt/homebrew/bin/node --version 2>/dev/null) ($(ls -l /opt/homebrew/bin/node 2>/dev/null | awk '{print $NF}'))"
  echo "path_node: $(node --version) ($(which node))"
  echo "hxWork_SmartDD_commit: $(cd /Users/hx/hx/hxWork/SmartDD 2>/dev/null && git rev-parse HEAD)"
  echo "projects_SmartDD_commit: $(cd /Users/hx/projects/SmartDD 2>/dev/null && git rev-parse HEAD)"
  echo "process_identity_sha256: $(shasum -a 256 "$DST/bin/process-identity" 2>/dev/null | awk '{print $1}')"
  echo "better_sqlite3_build_target: <请手工填写：按哪个 Node 或 Electron 版本编译>"
  echo "process_identity_build: <请手工填写：哪个提交、什么命令编译（不记得可留空）>"
} > "$DST/env.txt"

du -sh "$DST"; find "$DST" -type f | wc -l
```

## 5. 提交前检查

1. **查凭据**（必须执行，输出应为空）：

   ```bash
   grep -rlE 'sk-[A-Za-z0-9]{20,}|"access_token"|"refresh_token"|ANTHROPIC_AUTH_TOKEN=[^"$ ]{8,}|Bearer [A-Za-z0-9._-]{20,}' "$DST"
   ```

   有输出的话，先删掉或脱敏这些文件，再继续。
2. **看大小**：`du -sh "$DST"`。
   - 几十 MB 以内：正常提交。
   - 明显很大：多半是混进了运行输出。先用 `du -sh "$DST"/tmp/* | sort -h | tail` 找出大目录并删掉；或者不提交，直接把整个目录打包传给这台电脑。
3. **补全 `env.txt` 里的两处手工字段**，不记得可以留空。
