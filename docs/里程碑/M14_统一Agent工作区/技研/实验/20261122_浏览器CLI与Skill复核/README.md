1. 在 WillYou 启动 Codex 时核对实际可用的接口。CLI 文件变化后重新探测，在本轮工具列表确认为就绪时才提供浏览器指引。原生 Shell 权限及依赖特定版本的字段继续按其实际支持范围核对。
