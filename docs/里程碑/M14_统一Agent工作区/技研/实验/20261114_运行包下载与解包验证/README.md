# 运行包下载、离线缓存与解包边界

2026-11-14；R02／08／10／11，Q01／03／48／51／52／53／54；技术方案 §12.1、验证账 §4.51。技术研究与隔离验证，无产品／共享原型变更。

## 真实执行路径

本机 HTTP 服务提供临时 tar.gz 包，Node fetch 流式下载到独立 partial 目录，校验压缩大小／SHA256 后才发布内容寻址缓存；允许的重定向来源由调用方显式给定。本机离线命中仍校验缓存，缺失或损坏不触发网络兜底。

解包由捕获的 Python 子进程执行实验 helper：同一已打开 archive 文件先校验压缩摘要，再按固定文件清单检查 tar 成员路径、种类、重复、大小及内容摘要；仅生成规定的普通文件／必要目录，不跟随包内软链接、硬链接或稀疏文件。失败删除本次私有解包目录，旧资源不受影响。再次经过上一批流式资源准备／实际 ResourceStore 发布后，才从内容路径执行版本检查。

Python 仅是隔离验证工具，没有决定向产品引入 Python 依赖。正式实现还需选择与各目标平台发行方式匹配的解包器，并验证其边界；这里不把一种 helper 的成功等同所有恶意 tar／压缩炸弹处理已完备。

完整场景的压缩包为 156152756 字节，由此前缓存的实际 Codex 0.167.1 文件临时制作；解包 41 文件／366515155 字节，包含辅助程序和 voice 资源，发布后 --version 成功。不是从公开上游服务器取得的原始发行 archive，不证明公网 TLS、代理、上游布局或来源信任链已验证。

## 与 T3 的关系及设计边界

T3 CodexInstallation 先流式校验 archive 的大小／摘要，列出 tar 成员和类型、拒绝不安全路径／非普通文件目录，再解包和检查版本；平台包使用版本目录和独立激活指针。WillYou 沿用“准备后才发布”的原则，并与自己的固定资源清单、ResourceStore 和后续真实租约连接，不直接拷贝安装 UI 或默认更新行为。

本批验证 URL 来源约束、固定包完整性、缓存和常见解包异常；完整安装操作尚无持久 owner／阶段／恢复记录。下载缓存的有效性、解包完成、资源 ready、默认激活及运行使用仍分别核对。超时、取消与崩溃不是同一证据；本批正常清理不能替代进程被终止后的残留恢复。

仍缺公网 HTTPS／企业代理／证书故障、真实上游包来源与清单生成、其他 archive 变体和极端解包预算、下载重试／恢复持久化、并发安装、真实 run 租约／GC、平台安装签名与最终解包器选型。正式协议不得因为本地服务正常就默认接受任意 URL 或从下载内容本身取得可信的版本批准。
