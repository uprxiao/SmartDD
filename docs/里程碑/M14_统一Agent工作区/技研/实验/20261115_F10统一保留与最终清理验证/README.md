独立业务复用 F08 的实际只读方法及原状态判定。研究中的 MailBlobStore 仅用 prototype 载入只读附件元数据方法，避免构造函数初始化目录；合成 policy 只用于已授权研究读取。没有读取附件字节、建立真实业务连接、发信、签发新 grant。生产应提取共享只读查询或使用已经初始化的业务服务；不得将该研究对象构造方式照搬成权限入口。
