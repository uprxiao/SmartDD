# 全局收口复核与配置迁移保留验证

日期：2026-11-14。关联 R08／R10／R11／R12、Q42，兼及 D01–D08 的剩余决策整理。先核对 R0.2、T0.1、P0.4、全局账及 A42，再使用当前实际配置迁移服务验证发现；没有生产代码变更。

## 发现与修正

1. 原账 Q42、计划与 A42 笼统禁止复制新凭据，可能被实施者理解为删除既有加密迁移功能。实际项目包包含口令加密的 DB／SSH 等配置凭据；Agent 包默认不带 Key，但支持明确选择并确认口令后加密携带。设计应保留它们，禁止的是擅自复制运行票据、登录态、审批回执、业务授权和任务绑定。
2. A42 写“带新旧任务的项目包／导入保留历史”，超出了当前配置迁移格式。现有项目导入创建新项目与连接 ID，不迁移任务／原生历史。旧任务应在原项目保持不变；原生历史导入另按 A46 验证。
3. Agent 导入预览只读本机 toolInstalled。缺少 CLI 可以保存配置，不代表执行可用；M14 应分别显示配置、凭据、受管／外部运行资源及适配兼容性，不得以本机 CLI 缺失否定已就绪受管程序，也不能以导入成功承诺可运行。
4. 当前 D01–D08 表混合历史进展与下一步，若逐句照读，会重复已验证分支。已在原权威账重写每类的下一份决定性证据和产品后验收边界，不另建第二套需求或通过率。

## 四项实际服务检查

| 检查 | 证据 |
| --- | --- |
| T01 项目配置往返 | 实际 ProjectTransferService、ProjectService、SecretsStore 与 SQLite；密码加密文件保留合成 DB／SSH 凭据，接收方项目／连接 ID 重建，原项目不变，未创建任务历史 |
| T02 Agent 默认导出 | 实际 AgentTransferService 默认不读取密钥，配置包不带 Key、本机 executable 或 native binding；选中 Agent 的 Provider 只携带一次，模型检查重置为 untested |
| T03 明确携 Key | 缺确认口令拒绝；确认后实际加密／解密并导入新 Provider／Agent ID，不合并相同 URL 的旧 Provider、不泄露 Key 到预览；无本机 CLI 仍能保存，预览 toolInstalled=false，未继承登录态 |
| T04 不可移植内容 | 本机登录 Agent 拒绝导出；外来 login 声明跳过；包内擅加运行绑定字段或未知 driver 拒绝且数据库未变 |

四项通过，两份实际 SQLite 外键／完整性通过。文件密码加密为实际实现；系统 SecretCipher 使用每个库独立的合成后端，凭据均为公开合成值。没有系统 Keychain、DB／SSH 网络、Provider 认证、SDK 运行或新 UI 验证。此证据证明应保留的现有服务基线，不代表 M14 完整接线已完成；Q42 只从待集成调整为部分。

首次独立构建把 node-pty 一并打包，原生模块按临时 bundle 路径寻找 pty.node 而失败，未进入断言。改为外部加载实际已安装 node-pty 模块，正常加载后四项通过；未调用终端 spawn。原构建、错误摘要及修正来源保留。

## 全局结论

R01–R12 的目标与业务保留前提仍完整，不能据此宣布全量开发就绪。剩余重点转为同一研究 Schema 下的身份／资源／运行联合、业务结果与授权汇总、跨运行输入覆盖、主子完整回收、目录准入和支持／性能矩阵。现有证据足够的分支引用原实验，不重复累计；真实产品界面／安装验收仍留在后续 A 用例。具体待验内容只在验证账 §7.1 维护。
