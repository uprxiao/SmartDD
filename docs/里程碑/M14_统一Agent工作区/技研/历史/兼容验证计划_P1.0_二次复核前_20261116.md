## 2. 判定与顺序

先核原始输入和当前源码；协议／路由／目录候选验证与真实模型证据分别归账。变更的旧规则移入历史，适用部分按新的 Q 子范围继续追踪，范围外不算关闭或失败。每条关键结论标模拟模型、真实模型录制、真实服务或真实 App 层级。

本轮完成设计修订和独立研究；原型制作、用户评审、生产接线、统一打包及真实 UI 端到端随后按阶段流程执行。系统与本人前置见每条用例，自动化先自主完成。当前研究结果、失败和未验项唯一见[验证账](../全局设计验证账.md)；产品实际结果唯一见[执行记录](../../验收/执行与缺陷记录.md)。
