# M14 A24 服务和运输失联的集成补测

冻结候选 1c9022486 的实际 AgentStore、TaskService、RunService 与 DelegationService。子及原生回合用隔离内存 driver。MessagePort 只替代私有运输边界，服务正常读到结果后立即关闭客户端，先于运输写回。测试实际观察调用方未收到回复，待处理通知仍在，送达后只对应一个完成的通知。退休原 run 后，同一 RunContext 被真实宿主委派服务拒绝。新已登记 run 重读相同一子、修订与正文，UTF-8 字节偏移能读到预期的中文和 emoji。

[本轮测试](baseline.log)通过。两轮夹具失败保留。第一轮把运行中变化的回执状态也误当幂等字段，修正为比较委派与子身份。第二轮只等原 driver 实例，实际通知可能由逻辑父的新 driver 实例接收，更新为按确定的通知输入标识找对应实例。

真实 broker 的旧凭据入站校验另有原生 I 针脚。当前补测未对打包 App 的私有 Unix broker 套接字注入回包丢失，不能单独作为该 A 判据证据。
