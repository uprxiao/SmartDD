## 测试环境事故与处理（如实记录）

508、509 两次运行中，Skill 调用的系统 ssh 按 OpenSSH 设计读写**用户真实** `~/.ssh/known_hosts`（不看 `$HOME`），写入了一条测试服务器 `[127.0.0.1]:22342` 的主机密钥（第 194 行）。已核对指纹与第 508 次测试服务器主机密钥一致后，只删除这一行，其余内容逐字不变，`known_hosts.old` 未动。此后驱动在隔离 PATH 前放置只调用 `/usr/bin/ssh`、改用私有 known_hosts 与空配置的包装脚本，SSH 前先由任务 shell 核对 `ssh` 解析到包装脚本，否则不发起连接；并在首尾比对真实 `known_hosts` 哈希。这是测试环境隔离问题，不是产品缺陷（日常使用应使用用户自己的已知主机）。

另：smoke 测试初稿用了破坏性探测命令验证 ForceCommand，认证失败未送达；已改为无害命令，后续未再出现。
