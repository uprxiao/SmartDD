## 4. 发现的缺陷：M14-D06-54

- 现象（第 302–309 次截图和关系卡文字）：父任务委派共用目录写入子任务后，自己这一轮还没结束，子任务在排队；关系卡的“目录写入队列”却显示“当前无人持有写入权”。原型 `team` 场景这里显示“主任务 写入中 / 子任务 等待”。
- 原因：父任务在委派之前没有进入目录写入队列，队列视图只读队列表，看不到它。
- 修复：提交 `6160db370`，父任务在交出写入权之前，在队列视图中显示为“正在写入”。先补了失败测试（修复前 `activeCount` 为 0），修复后通过；`src/main/core/agent` 与 `src/renderer/features/agent-tasks` 回归 388 项通过、7 项跳过，类型检查通过。
- 新包 `6160db370`（`app.asar` `cd1a3327…41886`）复验：第 318–321 次 A81、A82、A84、A81 普通目录通过；子任务排队时，队列显示“父任务 正在写入 / 子任务 排队中”，不再出现“当前无人持有写入权”。M14-D06-54 关闭。

## 5. 发现的缺陷：M14-D06-55

- 现象（第 318 次截图）：父任务时间线里的子任务结果卡片，正文显示原始 JSON `{"text":"…","phase":null}`，标题显示英文状态 `completed`。
- 原因：生成结果摘要时直接拼接了条目的存储内容，没有取出消息文字；卡片标题直接输出了状态值。
- 修复：提交 `8f11304d9`，摘要改用消息文字，卡片状态显示中文（已完成／已取消／失败／结果未知）。主进程和渲染端各补一条测试，修复前分别失败（摘要为原始 JSON；找不到“· 已完成”），修复后通过；回归 389 项通过、7 项跳过，类型检查通过。
- 新包 `8f11304d9`（`app.asar` `54c65b04…8ee64`）复验：第 322–325 次 A81、A82、A84、A82 反向在合成模型下通过，同时断言写入队列显示和结果卡片文字；第 326 次真实 DeepSeek 的 A81 通过（18 次上游请求）。M14-D06-55 关闭。
