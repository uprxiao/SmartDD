## 0.1 时间线显示规则（照 T3，作为开发依据）

一轮 = 一条用户消息之后、到下一条用户消息之前的全部记录。记录种类：思考、读文件、改文件、命令、搜代码、搜网页、其他工具；以及会打断分组的独立行：中间正文、通知、错误、待办、待审批、子任务卡、创建子任务。

| 场合 | 显示 |
| --- | --- |
| 运行中 | 轮首“工作中 N 秒”（下方一条分隔线）；所有记录按时间顺序展开显示，不折叠 |
| 连续的工作记录 | 合成一组，直到遇到独立行为止。组内只有 1 条工具记录：直接显示该行（命令显示完整命令文本，等宽）；多条：显示汇总行，默认收起，点开逐条列出 |
| 汇总行文字 | 思考不计入；只有思考时写“思考”／“思考（×N）”。按优先级取最多两类动作（命令、修改最先，其他工具最后）：如“读取了 3 个文件，运行了 1 条命令”；超出部分写“以及其他 N 项操作”。修改按不同文件计数 |
| 末尾仍在进行的组 | “实时行”：显示最新一条，带流光；命令只写程序名（“正在运行 pnpm”）。组内有思考时，上方先显示思考的 **标题**（思考正文开头的粗体行，没有则取第一句） |
| 末尾既无实时行也无待审批 | 显示“思考中”（脑图标＋流光）；有子任务在跑时改为“等待 N 个子任务” |
| 正常结束 | 整轮折叠为“已工作 N 秒 ›”（同样带分隔线），只露出最终回答、本轮改动卡、通知、子任务卡、待办、错误；点开后与运行中相同 |
| 停止／失败 | 不折叠；轮首写“你在 N 秒后停止了”／“工作 N 秒后失败”；错误为独立行，可展开详情 |
| 最终回答流式输出中 | 不折叠，回答末尾显示光标 |
| 单条记录展开 | 思考：标签变为“思考”，下方显示思考全文；命令：显示命令、输出和退出码；读文件：显示读到的片段；修改：显示增删行数并指向本轮改动卡 |
| 时间 | 每行右侧显示时间，悬停时出现 |

## 0.2 本版其他改动（对应用户 P0.4 意见）

- **智能体与模型选择**（意见 1）：任务内和新任务页统一改为 T3 式选择器：左侧竖栏是智能体（收藏、Claude Code·订阅、Claude Code·DeepSeek、Codex·DeepSeek、CC-rj、OpenCode），中间是该智能体的模型列表（搜索、⌘1–⌘9 快捷键、“显示更多”），右侧是推理强度（标“默认”，执行器未公布则说明），底部说明生效时机与插话支持，并提供“管理智能体”。运行中切换在本轮结束后生效。权限档位仍是输入框里独立的“请求批准”按钮（M13 已确认），不放进选择器。
- **排队消息**（意见 5）：改为与 T3 相同：虚线气泡，下方“时间 · ↑ 立即发送 · 编辑 · 删除”。“立即发送”即插入当前这一轮（插话），只对已验证的执行器开放；未验证的灰显并说明原因。运行中停止键改为红色圆底白方块。
- **待处理请求**：按 T3，审批和提问出现在输入框位置。审批：时间线显示“命令审批”及命令、目录、原因；输入框顶部写“需要批准：运行命令”，右下为“更多（本会话总是允许／拒绝并停止）· 拒绝 · 批准”，直接输入文字即拒绝并说明原因。提问：选项列在输入框内，数字键可选，也可直接输入自己的回答。

## 0.25 多 Agent 协作界面（P0.6，对照 T3）

演示状态 `team`：主任务（Claude Code·订阅）同时派出三个子任务：Codex·DeepSeek 只读审查（运行中）、OpenCode 只读核对文档（等待批准）、Claude Code·DeepSeek 写测试（写入排队）。

| 位置 | 显示（T3 对应组件） |
| --- | --- |
| 主任务时间线 | 每次委派一行“创建子任务「…」· 目标 · 只读／写入”；随后一张子任务卡：叠放的执行器图标、“3 个子任务”、“1 个运行中 · 1 个等待你处理 · 1 个排队”、最长耗时，可展开（T3 subagent 事件行）。展开后每行：执行器、标题、读写标记、状态、当前动作（运行中的带流光，如“正在运行 rg”）、耗时；悬停出现“停止／取消排队／打开” |
| 时间线末行 | “等待 3 个子任务  审查构建脚本改动、核对打包文档、补 node-pty 架构测试  停止”，停止范围为主任务及全部子任务（T3 Waiting on N subagents） |
| 任务关系面板 | 右上浮卡（T3 ThreadDetailsCard 的 Lineage）：“任务关系 · N 个运行中”，主任务与各子任务（执行器、读写、状态、耗时），点击切换到该任务；下方“目录写入队列”列出当前持有写入权者和排队者，并注明只读不排队 |
| 子任务的请求 | 子任务需要批准时，卡片浮到主任务输入框上方：“子任务「…」需要批准”＋内容＋批准／拒绝／打开子任务（T3 ChildThreadApprovals）；在子任务里同样可处理 |
| 子任务视图 | 中间换成该子任务自己的时间线（同一套行规则），顶部面包屑“← 主任务 › 子任务 · 读写 · 执行器”与“任务关系”；底部输入框换成状态条：执行器、模型、状态与耗时、“独立运行”、停止、返回主任务（T3 ProviderSubagentBar）。写入排队的子任务显示“排队中，尚未启动”及原因 |
| 左侧栏 | 按 T3 不单独列出子任务，只显示主任务；子任务从时间线卡片或任务关系面板进入 |
