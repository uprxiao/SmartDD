## 0. 访问方式与参考

- 启动：在 `prototypes/m6-codex/` 运行 `npx vite`，打开 `http://localhost:5173/?preview=m14`（或工作台顶部“M14 · 统一任务区”）。`&m14=<状态 id>` 直达某个状态；页面右上角“演示状态 · 合成”可切换全部状态。
- T3 参考：固定提交 `fe59fa44d0` 的 `apps/web/src/components/chat/`（MessagesTimeline、TimelineUserMessageRow、TimelineWorkGroupRows／WorkEntryRow、TimelinePendingApprovalRow、ChangedFilesTree、ProviderSubagentBar、ThreadStatusLine、QueuedRunsControl、TimelineSystemDivider、UsageLimitRecoveryBanner）及仓库自带截图 `.github/readme/hero.webp`、`apps/marketing/src/assets/app-desktop.webp`。T3 需 Node 26／pnpm 12，本机未运行，尺寸取自其 Tailwind 类名：对话宽 46rem（736px）、用户气泡 max-w 80%／圆角 16px、工作折叠行 14px 次要色、状态行 12px。

### 0.1 本版已做的状态

| 演示状态 id | 对应 | 可操作内容 |
| --- | --- | --- |
| done | S02、S13 | 折叠“已工作 2 分 14 秒”可展开逐项；命令输出可展开；本轮改动卡片逐文件只读差异、二进制说明，无回退按钮 |
| running | S02、R01 | 实时工作行、流式回答、状态行“工作中 · 停止”；输入框上方排队消息（插话／编辑／删除）；Enter 排队、⌘Enter 插话；空输入时发送键变停止 |
| approval | S03 | 命令审批卡：批准一次／本会话允许／拒绝本步／拒绝并停止 |
| question | S03 | 结构化提问：单选＋其他、提交／跳过 |
| switch | S04/S05 | 时间线切换分隔，点开看交接方式（全量／增量）、覆盖与未包含内容；Codex 回答带来源标记 |
| multi | S06/S12 | 创建子任务记录；子任务卡（只读运行中、写入排队“等本轮结束”）；状态行“等待 2 个子任务 · 停止” |
| multi-done | S06 | 子任务完成通知回到主任务，主任务重新取得写入权后自动继续 |
| stopped／failed | S07 | “你在…后停止了”；失败详情可展开；发送后断线显示“无法确认是否收到”，不自动重发 |
| limited | S11 | 额度用完横幅（重置时间、到点提醒、不自动换账号）；输出长度上限保留部分回答＋继续 |
| links | S10 | 文件／行列／目录／file:// 在右侧打开或定位，网页开内置浏览器新标签；项目外、越界、已删除、未知协议提示原因；纯文件名不是链接；⌘ 点击为系统外部打开（模拟） |
| 标题栏终端按钮 | S14 | 手动终端抽屉（⌃` 切换），与 Agent 运行分离 |

未做／待评审：S01 新任务沿用现有首页未改；S08 草稿冲突、S09 本机程序缺失、S15 订阅扩展与托管隔离的说明页未单独制作；“关闭我的扩展”开关是否提供仍待评审；时间线小地图、查找、引用评论等 T3 功能不在本期需求内，未做。
