日期：2026-11-16。对照对象：原型 P0.6；**处理状态（P0.7）**：“补原型”24 项已全部画进原型 P0.7，位置见[原型说明 §0.27](原型说明与变更.md)；D11 已由用户确认为完整替换（需求 R10 补记）；“开发时做”13 项留待开发写进用例（`prototypes/m6-codex/?preview=m14`）。参考：T3 固定提交 `fe59fa44d0` 的 `apps/web/src/components/chat/` 全部组件、`components/sidebar/SidebarThreadRow.tsx`、`threadNotifications.ts`、`packages/contracts` 快捷键表；需求 R1.1（含 2026-11-16 R08 补记）、技术方案 T1.1 §3–§11、原型说明 S01–S15。

方法：逐个列出 T3 任务区组件及其界面文字，判断对应功能 ① 是否属于 M14 需求，② 原型有没有画。只记录缺口，已做的不重复列。

“建议”一栏的含义：
- **补原型**：属于本期需求，界面需要用户评审，应在下一版原型画出；
- **开发时做**：属于本期需求，但交互简单或没有视觉争议，写进用例即可；
- **不做**：需求已排除，或与 WillYou 无关。
