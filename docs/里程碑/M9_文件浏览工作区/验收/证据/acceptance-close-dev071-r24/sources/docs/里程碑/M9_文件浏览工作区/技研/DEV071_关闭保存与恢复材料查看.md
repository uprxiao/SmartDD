# DEV071 关闭保存与恢复材料查看

依据：M9 R3.4 / R3.4-P1，R07.9、R07.10、R07.17；H08、H27、H28。同范围开发与缺陷复验授权持续有效。本批不改需求、419 条本期用例范围或发布状态。

原实现的交换后 unknown/conflict 会保留原生恢复材料，但关闭文件后只有保留提示，没有查看入口。最后一个文件工作区组件卸载时释放监听，却没有立即保存及停止 buffer 的自动保存计时器。普通关闭在旧保存进行中调用 `save()`，也不会继续提交期间出现的较新输入。正常退出已存在主进程协调与 renderer 保存回执机制；本批接续该机制，没有用异步 beforeunload 冒充写盘完成。

## 实现与边界

- 原型先增加文件查看菜单的“保存恢复材料…”及只读窗口。生产使用既有文件菜单、Base UI Dialog，并与原型复用 `FileRecoveryView.tsx` 和 `file-recovery.css`。保留未决提示中的直达按钮。没有打开文件时菜单仍可达，关闭窗口不会删除记录。
- 后端新增 `inspectRecovery`：renderer 仅传 projectKey、记录 UUID、请求 UUID，严格 schema 拒绝任意路径。重新读取并验证私有日志、记录目录、草稿身份/hash、来源项目和根身份。来源已移除时仍可查看独立私有草稿，不依据日志中的绝对路径重新授予来源权限。
- 分别核对 current、displaced、draft、materialized；实际完整文件 revision/hash 配合最多 256 KiB 的 UTF-8 文本预览。截断不拆 UTF-8 字符，不可按文本解码的材料保留元数据，不当作空文件。版本已经改变时明确标识；查看不会写回、回滚、resolve 或清理。
- 原生 `stat` / `chunk` 增加可选的父目录身份核对。仍从可信根以 nofollow 路径读取，不创建较弱的临时绝对根；事务目录在验证后被替换时，不能读取替换物并冒充原恢复版本。私有草稿也核对原记录目录身份。
- 请求使用既有 owner 隔离的取消机制及并发预算。切换记录、关闭窗口会取消进行中的读取，迟到结果不能覆盖新选中记录；取消不把有效日志标成损坏。
- 最后一个 view 卸载时立即暂停文本、XLSX 和 PPTX 的计时器，释放监听，调用真实 `prepareClose('save')` 等待旧保存并提交当前快照。失败仍保留内存/持久草稿；不是调用 dispose 后推定成功。其他 view 仍在时不触发卸载保存。
- view 在旧保存尚未返回时重新挂载：旧 flush 结束后再恢复当前自动保存计时器，期间新输入保持 dirty 并可继续保存。重复 detach 不重复释放或让计数为负。普通关闭也改用 `prepareClose`；干净文本关闭/退出不会额外写源文件。
- 独立恢复窗口仅提供核对入口。恢复写回、清理、跨卷与所有坏记录处置仍按其独立用例验收；H27 的入口通过不代表整套恢复管理完成。

## 验证

新增 7 项真实原生集成、4 项窗口交互单测、3 项卸载/真实保存集成测试；相关选集 91 项通过。集成测试调用生产 store、FileService、FileRecoveryStore、监听服务和原生保存/交换/读取，控制延迟或 test 宏故障点，不伪造保存回执。

文件模块大批回归：沙箱内 792 通过，5 项 Git/原生监听失败，362 项未启用对应 opt-in 前置。五项所在的原生边界文件在实际系统环境复跑 54/54 通过，保留首轮原始结果，不改写为首轮全绿；合并两轮为 797 个唯一已执行测试通过。该选集不是历史全部代码用例重新执行。

r24 实际 App 已核对提交前失败后继续/明确丢弃、交换后 unknown/conflict 各版本不变及真实查看入口、组件卸载等待原生写盘、普通退出等待保存后 exit code 0 / 无信号。故障只作用于私有 COW 测试副本的固定合成文件；正常 App、ASAR 和原生保存算法不改。wrapper 转发原生实际输出，只有 test 宏暂停/错误注入；精确构建、哈希、截图及逐步结果在本批验收证据归档。

正常退出通过主进程 inspector 触发真实 `electron.app.quit()`，renderer 实际变 inert 并显示保存覆盖层，原生写盘受控延迟期间源文件仍为旧版；收到真实保存回执后才自然退出。没有伪造 close 协调回答，也不宣称验证了物理 CmdQ 按键。

原型使用本机合成数据，以隔离 Electron 浏览内容核对浅/深色、只读预览和可视窗口边界；电脑操作工具本次报告没有可用 App/浏览器，不以它作为系统输入证据。没有复验的语言、Codex 像素细节或物理焦点/IME 状态仍不计完成。最终正式用例与回归结果以验收台账及本批证据为准。
