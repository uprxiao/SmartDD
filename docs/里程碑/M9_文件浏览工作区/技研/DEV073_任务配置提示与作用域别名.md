# DEV073 任务配置提示与作用域别名

依据 M9 R3.4 / R3.4-P1 的 R02.1、R02.2、R04.1、R04.4，关联 A02/A03/A04。属于已授权范围内的缺陷修复及验收；419 条本期范围不变。

## 缺陷和实现

实际 r25 App 中，任务在 A 目录启动后，将项目默认目录改为 B，任务 cwd 和 PTY 正确保留 A，但任务信息没有显示已有的“项目配置在启动后有改动”提示。项目写操作更新项目查询，已加载的任务列表缓存并不随之更新；TaskInfo 只使用任务列表中的 projectConfigVersion，因而遗漏提示。

TaskInfo 复用 useProject 查询当前项目版本，与任务元数据中的已知版本取较大值。配置版本单调递增，较旧查询缓存不能暂时隐藏已知变化。任务 configVersion、cwd、PTY 及启动快照不变，不为刷新提示重启或结束任务。沿用既有提示文本、布局和图标；无新增页面或设计规则。

同真实根别名沿用现有 canonical identity / documentKey 去重，不修改目录唯一性约束。A04 通过既有任务的启动 cwd=A 和真实项目目录编辑为 aliasA→A，形成两个合法来源；没有绕过 F01 禁止重复项目目录的规则。目录来源菜单仍显示 aliasA / Alias A，已打开文件 breadcrumb 保留任务启动目录，来源可辨。

## 分层验证

- 新增 3 项组件测试：项目查询更新而任务缓存不变时提示实时变化、较旧项目缓存不隐藏任务已知变化、无项目任务不发起查询；核对 cwd/版本/PTY 快照及无 kill/resume。
- 新增 3 项真实集成：SQLite 迁移、ProjectService、FileSourceResolver、FileService、原生读写、私有草稿、renderer store。覆盖默认目录改变、项目/T1/T2 的 active 和草稿隔离、外作用域草稿 UNTRUSTED、同根别名共享 dirty buffer/EditorState/history 及唯一保存。
- 集成中的任务行是显式夹具，持久化布局关闭；不以它证明任务真实启动或尺寸恢复。延迟保存计时受控，原生返回没有伪造。
- 六个相关测试文件共 56 项通过，新增 6 项，类型检查通过。历史代码通过并集增至 1659，另外 2 项旧外部 CLI opt-in 未启用；不是本轮重跑整个历史测试集。

## 打包 App

r26 在独立 userData 和项目中真实操作：项目默认目录按钮、任务切换、信息弹层、根来源菜单、编辑目录弹窗、文件树/标签/编辑器、撤销/重做和保存。公开 IPC 仅用于合成项目/配置/任务前置、打开前的根身份核对及只读结果，不替代界面步骤。

A02：T1 实际启动于 A；项目改为 B 后，回 T1 仍读 A，配置版本 3→4 提示可见；进程真实 cwd=A，原 PTY 未变。A03：项目、T1、T2 来回切换各自保留 active；T1 的独立 durable 草稿不在 T2 的同物理文件中出现，T2 读取原盘，T1 修改不写入该源盘。A04：两个来源 canonicalPath/identity 相同；通过两入口打开后只保留一标签和同一份 dirty 内容，实际撤销回原文、重做回修改后，单次原生保存；两个路径最终字节、inode、mtime 一致，只有一个 saved operation。

三个输入接收 Python PTY 不执行输入，实际 cwd 分别 A/B/A，PID 各异；全过程接收 0 字节、执行 0 命令，PTY ID 不变。a.txt 只有预期的唯一保存，其他合成源文件的字节/inode/mtime 不变。旧 r4/r6 任务、57 字节待发送输入、AIS 与日常凭据未操作。另跑 16 个保存/关闭/编码/历史实际 App 场景全部通过，不重复增加旧用例数。

## 失败记录和边界

旧 r25 第一轮驱动没有通过任务启动按钮接入已存在的 PTY，不能作为功能红；补齐后同旧包真实复现缺少配置变化提示，独立只读 SQLite 审计确认项目版本已变、任务启动快照未变。新 r26 对应流程通过。

新包早轮在目录弹窗中的 Cmd+A 未触发 Chromium 原生输入框全选，路径被追加。补充 macOS CDP selectAll 编辑命令及保存前 selectionStart/selectionEnd/实际值断言；无 DOM value setter。原始错误路径及失败记录保留。另一轮错误要求 EditorView 对象不重建；切到加载中的别名标签会临时卸载视图，文档和历史存于原 buffer，这是既有生命周期。修正为真实撤销/重做及唯一原生保存验证，保留视图重建事实，不把它写为对象复用通过。组件首次查询更新断言未等待通知、运行文件比对首次误用普通 Node 读取 ASAR 的失败也保留；分别修正等待和使用 Electron 的 ASAR 文件系统后通过。

源码构建及最终验收快照共 918 文件；构建后仅外部测试驱动两文件变化，生产输入不变。包内六项原生 smoke 通过，81 项运行文件与当前构建产物一致。仅 macOS arm64，本地版本 0.0.5，未发布。没有新增原型页面、P/V 用例或 Codex 完整像素/字体/浅深色结论；A12 迟到结果、A13 最长匹配及其它尚欠项继续。
