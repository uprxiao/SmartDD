# DEV178 视频键盘与真实终端焦点

依据 R3.4-P1，R06.12/R09.6、P15、D09/D14 及已确认 D16 静态事实；仅推进原 T25。feature/0.0.1，复用 r105，未发布。原用例范围、步骤与预期不变。

生产代码和产品原型无修改。新增两条组件回归，验证两种键各自 play/pause、防默认、11 次连续 repeat 及旁侧输入隔离；解码与 IPC 明确隔离。真实 native I 使用原 Swift/FileService 完整读取四个既有合成源、校验字节和授权关闭，与真实 App 原媒体协议／解码证据分别记录。

真实 App 在浅／深色分别执行 Space 开／停、Enter 开／停，每次一次非 repeat 后连续 11 次 repeat，逐次验证状态及事件防默认。再在视频播放／暂停两种状态聚焦实际 xterm，按同样两种键，真实 Python input-only 接收器应得到每组 12 空格和 12 CR，另一任务零输入；接收器不执行命令、不连接模型。核对真实原始文件、PID／PTY 身份、源文件不变及退出。P 使用共享原 Media 的模拟播放和明确标记的独立 textarea，仅证明 P 控件和焦点，不称解码或终端。

外部脚本首次在 capture listener 的微任务内读取 defaultPrevented，早于 React bubble 处理；改为整个派发后的任务读取，原播放组件无需修复。一次完整 A 的 12 组已通过，但清理误用了另一个 driver 的 `__m5` 观察变量；改为本 driver 独立的只读 pty:exit 观察并完整复跑。P 的共用 textarea 清空前置未通过：补原生 Backspace 后仅删掉一个字符，Select All 仍未生效，原因未分类；这不是 T25 的视频缺陷。最终按原步骤给每组独立空白模拟输入，不再执行无关的清空动作，保留失败证据。

最终结果、包／源哈希、用例账和原始证据以[DEV178 验收报告](../验收/证据/m9-acceptance-media-keyboard-dev178-r105-20261020.json)为准。R 沿用静态 D16，没有新 Codex 动态或像素比对；CDP repeat 语义不冒称物理键盘系统重复时序。T27 overlay 对照和其他媒体用例未被本条覆盖，T32/T34/Y29 三项人工／环境阻塞不变。
