# DEV074 外层面板比例与尺寸恢复

依据 M9 R3.4 / R3.4-P1 的 R01.2、R01.5、R08.6，关联 A08/A11；外层比例及兼容旧像素值的参考来源为[生命周期 §4.7](../调研/M9_项目会话与文件生命周期.md)。属于既有范围修复，不改变419条用例。当前本地 `../yoda` 路径不存在，本批复用本项目现有导航、布局、SQLite工作区和终端生命周期。

## 缺陷与方案

r26 实际 App 的外层拖动范围、内树独立宽度及 PTY 连续性成立，但全局 `willyou-file-panel-width` 只保存像素值（实测673），不满足比例恢复及旧像素兼容要求。

新增共享纯布局模型，由正式 App 和合成原型复用。新偏好保存0–1比例，旧大于1的像素值先按实际可用区域解析，再迁移为比例。默认仍为0.57，原有外层最小420px/小区域70%、终端预留240px的约束不变；内树继续使用各作用域SQLite工作区里的独立 treeWidth。窗口变窄仅临时限制显示宽度，不把临时限制写回比例，重新变宽可以恢复原意图。

迁移只在真实文件作用域可见并获得实际容器尺寸时进行，不用初始化1000px或首页含侧栏时的宽度猜迁移基数。窄窗口文件视图隐藏侧栏时使用此时的真实尺寸。非法、无穷、非正偏好使用有限默认值，非法拖动/零区域不写存储。没有改变标签/草稿存储、任务启动或PTY生命周期。

共享原型先补外层分隔条、比例存储、实际容器测量与旧值兼容；独立使用 `willyou-m9-prototype-panel-width`，不接真实数据。现有内树与全屏控件保留。原型和生产的计算逻辑一致，完整视觉/全屏矩阵仍分开验收。

## 结果

新增4项导航/持久化测试，覆盖旧610px迁移后按比例重开、窄窗临时限制后恢复、非法偏好与测量、全局外层字段和其它布局字段隔离。相关5文件25项通过，含10项真实SQLite/原生文件/工作区持久化回归；类型检查通过。历史代码并集1663通过，另2项旧外部CLI opt-in未启用，不是本轮重跑全部历史用例。

r27实际 App 完整覆盖两条：

- A08：真实指针拖至外层最小420px/最大864px，再恢复；内树初始250px不随外层误写，单独改为300px时外层不变。窗口1600/1100/1400三种宽度均无负尺寸或越界，中央仍保留可见空间。独立输入接收进程PID/PTY保持，内核列数稳定实测83→26，心跳继续，0输入/0执行。
- A11：真实外层比例约0.61和内树300px分别持久化。正常退出，实际新App重新打开同任务/文件，恢复两者及固定标签；两次普通退出均code0/signal null。显式旧值610px为I层迁移前置，重新加载后在1100px窗口保持610px、内树300px，存为约0.584291；1600px窗口按比例得到约761.906px，内树仍300px。持久化布局不含lease/generation。源文件字节/inode/mtime完全不变。

普通退出前通过实际任务菜单停止本次合成任务。任务重新打开会按既有规则自动恢复，最终退出前也再次停止；不自动处理运行中任务的原生退出确认，不宣称该弹窗已验收。前后两次进程的0输入分别留证，跨App重启不宣称PTY不变。

原型通过真实主题按钮分别切浅/深色，再拖动、调整自有窗口并重新加载验证比例；仅合成布局验证。另跑A02/A03/A04三条实际App回归全部通过，不重复计数。没有扩大为A09的参考动态、A10完整缩放/P/V或其它原生确认验收。

## 失败、构建与边界

保留旧包及候选原始失败：首轮页面CDP不支持Browser窗口接口，改由本次App的BrowserWindow.setSize调整真实窗口，不发送假的resize事件。r26随后完整走过拖动，真实暴露像素存储。新包前两轮因运行中测试PTY触发已有同步原生退出确认，分别阻塞调试调用或等待退出；查明后按离席约定先经UI停止本次任务。第三轮重新加载后读取太早，把初始化250px当成结果，原DOM明确仍在加载；补等真实文档恢复后验证。第四轮所有布局检查已通过，但再次打开任务会自动恢复PTY，最终退出仍触发确认；统一每次退出前停止本次任务后，第五轮全通过。失败取证和清理等待已设短界限。

原型驱动的观察表达式语法、重新加载误读旧DOM均独立保留；早批直接设置文档主题属性只证明布局值，终端子组件主题未同步，不作为完整主题证据。最终改用实际主题按钮，浅深色均复验。常规原型build首次因PATH没有vite失败；使用现有electron-vite依赖解析出的Vite入口完成构建，没有下载新依赖。

本地r27为macOS arm64/0.0.5，ASAR `f6c4a0df965e265711941e1d2b36aa42c29b00e82c2a5a92958569228d80da53`。六项包内原生检查和81项当前运行文件一致通过；native broker未改。构建/最终源码快照922文件，构建后仅外部布局验收驱动调整，生产输入不变。仅macOS arm64；无AIS、旧r4/r6/57字节待发送、日常凭据、模型、剪贴板、提交/合并/tag/push/发布操作。
