# DEV068 保存失败切模式焦点

依据：M9 R3.4-20261017 / R3.4-P1，需求 R07.8，正式用例 H23。当前授权涵盖范围内缺陷修复及复验，无新业务、设计范围或发布动作。

## 复现与原因

r20 隔离 App 对 Markdown 真正键入修改，再将该测试文件设为只读并点击“查看源码”。保存被真实权限检查拒绝，内容与 document 模式保留，但焦点落到工具按钮。r6 原始失败截图和 failureFocus 显示“查看源码”。该轮先触发的 DOM 文本比较不适用于富 Markdown：标题被组件投影替换，不能只拼 cm-line 当作原始源码；不据此认定文本丢失。独立真实 panel/store/CodeMirror 单测直接断言焦点，修复前 6 通过、1 失败，失败为 editor.hasFocus=false。

## 实现

生产 `workspace-panel.tsx` 的模式按钮在鼠标主键按下且当前焦点属于 CodeMirror 时阻止默认转移；其他工具保持既有行为。键盘可照常聚焦并激活按钮。没有异步强制 focus，因此保存等待期间用户选择别处时不会被抢回。保存、草稿、dirty、模式意图和错误处理沿用现有实现，不建立额外文档模型。

共享原型 `prototypes/m6-codex/src/FileWorkspace.jsx` 的模式按钮同步保持其 textarea/contenteditable/CodeMirror 焦点。未改视觉规格，未增加产品入口或权限弹层。
