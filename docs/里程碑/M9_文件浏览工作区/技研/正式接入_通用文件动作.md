# 通用文件动作正式接入

依据：需求 R3.4 / 工程 R3.4-P1，R05.3–R05.6。2026-10-17 按既有开发授权实施。原有方案与原型保留，以下记录实际生产接口，不替代需求。

- 主界面通过 `FileActionTarget` 传已发行文档引用，或可信根 lease 下的相对路径；不接收外部应用路径或保存目标绝对路径。主进程验证窗口、frame、根来源与代际，关闭/导航后撤销。
- macOS broker 以 `NSWorkspace` 读取实际注册的应用与默认应用；列表最多 80 项，选择使用主进程发行的短期 ID，绑定所有者、文件身份和应用身份。打开使用文件引用 URL 与应用 URL，不经过 shell。普通选择不改偏好，显式记住且系统确认成功后才写 `fileOpener`；只改本 App 的偏好，不改系统关联。
- 工具栏拆为首选打开和打开方式；列表有加载、失败、重试、首选不可用分支。应用图标为系统图标的 32px PNG，以受控 Blob URL 呈现并在卸载时释放，维持现有 CSP。
- 文件树只给文件菜单；面包屑按文件/目录区分，提供受控 Finder 揭示，文件另有另存及可用时复制内容。终端引用及 Git 条件项仍属于后续当前阶段工作，未以空操作替代。
- 原生另存对话框由主进程创建并绑定原窗口，取消不触发复制。目标路径只从系统回执取得；使用明确的绝对建议路径、所有文件类型和副本名称，避免本次实测中的保存按钮禁用。无法将旧参数中的单项认定为唯一系统根因。
- 副本检查源 revision、目标父目录身份/原路径别名及目标版本；禁止覆盖源 inode（包括硬链接）和目标符号链接。新文件以 `RENAME_EXCL` 提交，目标中途出现则拒绝；覆盖复用 `RENAME_SWAP` 事务并保留目标原 inode。源原件的保存状态和 dirty 不由副本回执修改。
- 草稿/日志/配额沿用恢复库；副本日志记录来源根与独立目标根，重启重新核对两者，隐藏已登记事务对象。未确认目标保持阻塞，禁止自动重发。不保证外部程序在确认之后永远不再改目标；遇到检测到的竞争保留版本且报告冲突。

实现：`src/main/core/files/actions.ts`、`native/files/desktop-actions.inc.mm`、`src/main/core/files/controller.ts`、`src/renderer/features/files/file-actions.tsx`。通用原型继续在 `prototypes/m6-codex/`，外部动作保持明确模拟。
