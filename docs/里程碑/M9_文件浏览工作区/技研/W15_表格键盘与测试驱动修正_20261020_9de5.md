## 外部驱动问题

第一次清除保存后界面及磁盘已更新，但驱动在相同版本号中取了较早的 `dirty=true` 编辑回执。已改为同版本取最后回执，保留原红测及原断言。

另一轮捕获 Inspector 原协议 `-32000: Promise was collected`。自有独立 Node 的强制GC实验复现：未持有的待定Promise被收集；全局强引用期间存活，移除引用后再次被收集。这是驱动机制证据，不是App业务成功证据。公共harness现在持有实际异步求值Promise至响应或超时后清理，纯同步只读观察可显式禁用awaitPromise；没有改业务RPC结果。诊断hook在正常退出前恢复，避免App退出后收集失败覆盖已完成结果。相关修改仅在测试脚本中。
