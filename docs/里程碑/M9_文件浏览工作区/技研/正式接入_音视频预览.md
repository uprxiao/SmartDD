# 音视频正式接入

2026-10-17；依据 R3.4/R3.4-P1 R06.12、R05.6、R08、R09。当前为开发验证，未宣称 T18–T31 全部正式通过。

## 实现与预算

- 复用 Chromium 的真实 HTMLMediaElement 解码，音频 hidden audio + 自定义播放/进度/时间卡片；视频 below 常驻控制条、音量/静音、八档倍速、能力条件 PiP/全屏。没有 overlay 专属的自动隐藏或 ±5 秒动作。
- `shared/file-media.ts` 固定扩展名和 MIME，`media-service.ts` 管理源文件版本能力，`media/preview.tsx` 与 `media/resource.ts` 管理解码器及资源生命周期。副本保存复用已经接入的系统保存对话框和原生写入保护，不修改源媒体。
- 本期两条读取路线均冻结为 128 MiB（含等于）。native `resourceLimit` 独立检查 FD 大小，普通 PDF 等资源仍保留各自预算。协议按 1 MiB 分块响应 GET/HEAD/单 Range；每个引用最多4个并发读取，每窗口最多4个引用。二进制退路同样受 main/native 的128 MiB限制，并在 Blob 创建前核对完整 SHA-256。
- URI 中只有256位随机token，不含真实路径或用户来源URL。每次文件预览单独引用，绑定当前owner、root generation、document和revision。协议安装不可用才使用binary退路；codec/权限/文件改变不是自动绕过权限的理由。

## 会话与文件边界

- 协议只注册到主界面的defaultSession；`webRequest.onBeforeRequest` 从 Electron 原生提供的 webContents 与 frame 检查主frame及owner，再进入协议读取。子frame、其他窗口、旧导航owner、未知token均拒绝。Electron42本地类型没有最新文档中的initiatorOrigin，未假定该字段存在。
- 原生路径解析仍使用已有根目录FD、租约与文件身份约束；每个块前后检查版本/路径。源文件变化、根被替换、窗口/文档关闭会拒绝或中止后续读取。无任意路径、远程代理或Git写入入口。
- 本地协议仅启用 standard/secure/stream；未设置bypassCSP或supportFetchAPI。主界面 CSP 只补 `media-src blob: willyou-media:`，不允许远程媒体。现有独立diagram session的网络拒绝规则不受影响。
- 卸载先pause、remove src、load，再取消能力与撤销Blob；退出本播放器的PiP/全屏，解绑事件。加载和缓冲15秒无进展显示超时；新文件/重试使用新能力，不接收旧异步结果。
- 每个seek pointer只恢复一次，依据拖动前播放状态；Space/Enter仅视频画面处理，忽略repeat和IME，不监听全局终端按键。非法duration显示0:00且禁用seek。
