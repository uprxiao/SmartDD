官方四平台资产 URL、大小和发布 digest 已存证；只有 macOS arm64 下载校验并运行。[Temurin 固定发布](https://github.com/adoptium/temurin21-binaries/releases/tag/jdk-21.0.12.1%2B1)、[官方许可说明](https://adoptium.net/docs/faq)

## 3. 离线、权限与预算

TeX 每次明确编译请求使用新的私有快照、输出、home/cache/tmp。源根 lease、源 revision、允许的资源清单由未来主进程 broker 提供；本轮只用合成文件。宏包/字体只读，写入限任务输出目录，禁止网络、其他程序执行、任意项目命令、外部路径读写。隔离策略不可用时失败并保留诊断，不能退回无限制编译。[实际 profile 与预算](../验收/证据/predev-resources/predev-tex-report.json)

TeX 探针的执行阈值在首次编译前固定；其余行明确区分当前生产实现预算、试包实测与尚未执行的构建目标。“冷”指新任务 profile，未清空系统磁盘缓存。

| 项目 | 当前工程阈值 | 实际结果／证据边界 |
| --- | --- | --- |
| TeX 冷／后续请求墙钟 | 30 秒／15 秒 | 4 个正向样本约 0.76／1.92／1.26／1.61 秒；每任务仍生成 format，没有假称已命中共享格式缓存 |
| TeX CPU／内存 | CPU 25／27 秒软硬限制；RSS 768 MiB 采样后杀组 | 正向采样峰值约 237–307 MiB；采样 RSS 不是内核硬内存上限 |
| 产物与快照 | 单输出 40 MiB、PDF ≤2000 页、源码 ≤10 MiB、资源快照 ≤128 MiB、FD 128 | 文件大小／CPU／FD 在探针实施；输入快照总量和 PDF 页数是生产 broker 要落实的预算，本轮正向样本未触顶，不写成边界已验 |
| 取消／超时 | 取消完成 ≤2 秒，整个自有进程组结束；结果失效 | 真无限循环取消 213ms、超时约808ms；不得接受残余半成品 |
| 并发 | 应用级同一时刻 1 个重型 Office／TeX 转换；排队可取消，旧 revision 失效 | 生产调度待实现；不从单进程测量推导多路无上限并发 |
| 独立资源包 | 当前 TeX＋JRE＋POI 试包 | 159,985,045 B 压缩，307,132,951 B 普通文件展开；289 个外层文件／链接逐项核对，TeX 内层 3,685 资源另有清单 |
| M9 原生资源总量 | 构建目标：新增磁盘 ≤1.3 GiB、最终 macOS安装包 ≤800 MiB；超出构建报告列明，不擅自删功能 | 结合既有 LO 占用和新试包预留的工程预算；**不是实测全 App 包结果**，正式整包需测并据实复核 |

PDF／Notebook 的统一预算以 [05 专项 §2、§5](开发前_05_PDF与Notebook.md)及其[生产预算 JSON](../验收/证据/predev-pdf-notebook-production-budgets.json)为维护入口，09 的资源接入必须共同落实：PDF 输入 **≤256 MiB（268,435,456 bytes）** 是本轮新增的统一工程候选，不冒充既有 artifact 已确认能力；每窗口 **1 个活动 session**，换源先销毁；加载／RPC **15 秒**，密码等待暂停。每页画布 ≤16 Mi pixels，总画布目标 **≤32 Mi pixels（128 MiB RGBA）**，包括正文与缩略图；总额与完整 renderer／GPU 内存尚待生产验证。Notebook 输入 **≤40 MiB 实际 UTF-8 bytes**，每窗口 1 个解析 Worker、15 秒 deadline；窗口按 30 cells／100 outputs／1 Mi UTF-16 unit 调度，完整内容保留且可继续取回。HTML／图片、50 轮稳定性及进程内存门槛使用 05 的预先冻结目标，未执行项不能计为通过。05 的合法大文件输入实验只证明入口和有限渲染路径，不能推导任意同尺寸复杂文件的解码成本。

## 4. 许可与来源交付规则

不把“开源”或 npm 的单个 license 字段当作整个分发包的结论。准备阶段的来源已固定，正式构建按下面材料装配与校验：

2. **TeX Live／宏包**：这是按功能选择资源的集合，不是完整 TeX Live。资源未改字节，集合选择、ZIP 格式与新增资源身份文件属于 WillYou 准备过程，必须说明。保留原始文件头、[TeX Live 许可](../验收/证据/predev-resources/licenses/LICENSE.TL.txt)、[LPPL](../验收/证据/predev-resources/licenses/LPPL-1.3c.txt)、逐包/逐文件来源及完整原始工作的取得方式。[官方 TeX Live 说明](https://www.tug.org/texlive/copying.html)明确集合没有单一许可；[LPPL 原文](https://www.latex-project.org/lppl/lppl-1-3c/)应结合包内原文使用。
3. **中文与数学字体**：本轮编译的 Fandol 由离线包供给，字体嵌入 PDF，不借用用户字体目录；[原 README](../验收/证据/predev-resources/licenses/Fandol-README.txt)写明 GPL 加字体例外，[COPYING](../验收/证据/predev-resources/licenses/Fandol-COPYING.txt)保留。Latin Modern／TeX Gyre 及数学字体的 GUST Font License 按各字体内文、包记录和完整上游源包提供，保留名称与版权，不把生成的文档误标为引擎源码。字体包版本和内部 font version 分别记录。
4. **JRE／POI**：Temurin 原 `legal/` 178 个许可文件的路径与哈希已记录，试包保留原目录；GPLv2＋Classpath Exception 与额外组件文本照原样携带。POI JAR 原 notice 和来源沿用 04 清单；没有捆绑本机 Oracle JRE。
5. **PDF.js／watcher／LibreOffice**：分别保留 Apache-2.0、MIT、MPL-2.0 与各自附带组件 notice；PDF.js CMap 另有自己的原始 LICENSE。LibreOffice 使用安装目录内 LICENSE／NOTICE，不能只附一页 MPL。原件已存入本页许可目录。

**分发材料装配是后续构建任务**：每个进入实际安装包的 native／font／macro 文件必须在 lock 中，原始 notice、完整工作／源码取得方式、所需例外条文和集合修改说明一起安装；不能只把本轮试包当作已满足正式发布的最终安装包。增加、删减或升级资源时同步清单和相应验证。

## 5. 本轮发现及修复，保留失败证据

- [attempt1](../验收/证据/predev-resources/attempt1/predev-tex-report.json)：7 通过／3 失败。hyperref 缺 `pdfescape`、ctex 缺 `zhnumber`；补齐对应包族和依赖，不把缺包负测冒充数学或中文正向通过。
- [attempt2](../验收/证据/predev-resources/attempt2/predev-tex-report.json)：仍有 `uniquecounter` 缺失；中文实际已生成，但 pypdf 将 Adobe-GB1 CID 当 Unicode 解码而读错。补齐资源，并使用产品实际 PDF.js＋固定本地 CMap和独立 PDFKit读回；原 pypdf 文本仍存最终 JSON，未改写成正确结果。
- [attempt3](../验收/证据/predev-resources/attempt3/predev-tex-report.json)：合法但没有 `/Contents` 的空 PDF 页面作为图片，被 xdvipdfmx 拒绝。普通真实矢量 PDF 正向通过后，进一步在 **私有快照** 中仅为缺少 Contents 的空页补入无视觉内容的 `q/Q` stream，PRETEX-11 通过，原件 SHA 保持不变。生产需实现这个有边界的兼容处理；不是通用重写／清洗所有 PDF，也不改磁盘原文件。
