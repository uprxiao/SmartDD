# CSV 与 TSV 正式接入

2026-10-17；依据 R3.4/R3.4-P1 R06.7/R07/R08，关联 F17/J11。生产解析与界面已接入并打包，尚未执行真实 App 表格验收。

- 沿用已确认的 Papa Parse 候选，固定5.5.3（MIT）；复用原有文本缓冲与保存保护。当前原型的Office工作簿为合成数据模型，不能用于真实CSV解码或回写。
- 源码路线继续由无损UTF-8文本缓冲提供：10 MiB内可编辑，10–20 MiB只读；BOM和原始换行保留。表格预览只读，不对字符串/数字/日期作类型转换，不求值公式，不将CSV转成XLSX再保存。
- parser处理分隔符、双引号转义及字段内容；独立记录边界扫描识别引号内换行与CR/LF/CRLF混合记录边界。CSV用逗号，TSV用TAB。源码不经unparse重新生成。
- 工程预算：源码最多20 MiB；预览最多1,000,000行、16,384列；Worker最多15秒；单次窗口最多50行×24列；可见单元格片段最多512个UTF-16码元、完整单元格按8192码元分块，并避免拆开代理对。超预算/语法错误明确提示并保留源码入口，不呈现截断数据的成功表格。
- 仅存原始字符串与记录偏移，行解析LRU最多4条；界面采用28px行、112px列的双向可视窗口，单元格内容均按纯文本展示。此处为当前工程设计，界面接入及实际性能仍待本轮验证。
- 已完成4项解析模型测试：引用分隔符/换行/Unicode、空值/前导零/超长数字/公式文本、混合EOL/空行/不等宽行、非法引号、列/窗口上限、末行及长单元格完整分块。结果 `/private/tmp/willyou-m9-csv-model-tests.log`。模型结果不代替真实文件与App验收。

官方资料：[Papa Parse文档](https://www.papaparse.com/docs)，实际使用安装的5.5.3。许可证随 `scripts/files/licenses.mjs` 保存至 `licenses/M9/`。

## 本轮实现与验证

普通树打开CSV/TSV默认源码；工具栏可进入只读表格，再返回源码。模式切换沿用保存/冲突保护，不更换原文权威模型。真实Worker、15秒终止、文件切换取消和迟到结果隔离已接入；表格窗口最多50×24，选择/方向键/Home/End/Page导航、长字段分块完整复制、空态/失败重试已实现。

生产与共享原型复用同一只读表格组件及Worker，原型仅提供合成字符串，无IPC或真实文件访问。对应P12增量、R06.7；原型原有Office模型不再充当CSV解析器。

23项测试通过（4文件）：既有CSV解析边界、百万行上限、Worker超时/取消、React虚拟导航/过期结果、BOM/混合换行/引号的定点源码保存。类型检查、原型build/prepare、Mac arm64打包及原生模块检查通过。[构建、源文件哈希与测试证据](../验收/证据/m9-development-csv-ui-20261017.json)。

真实App未验：电脑工具报告Mac锁屏，已请求用户解锁；不得将模型或组件结果计入F17。后续用合成CSV/TSV检查显示、末端导航、源码编辑/撤销/保存及源文件哈希；J11的DOCX部分单列继续。
