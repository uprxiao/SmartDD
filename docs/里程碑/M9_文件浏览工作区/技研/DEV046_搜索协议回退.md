# DEV046 搜索协议回退

依据 M9 R3.4-P1 / R03.4、C10/C11。2026-10-18 正式接入并复验。此前实际主进程只有 search/cancelSearch，缺少明确协议能力回退；不把旧的一次查询成功当成 C10 全部通过。

生产 startSearchSession 复用现有 FileSearchService 的真实 session ID、root lease、增量事件和取消资源。查询更新先停止旧 ID 再启动新 ID，最终回执仍按 ID/generation 判断；不添加另一套扫描器。旧 search 作为一次查询兼容入口保留相同权限校验。

渲染器仅在 Electron 明确提示 files.startSearchSession 未注册时调用一次 search；不存在该方法的直接适配器也按旧能力处理。能力记录只保存在当前 hook。权限、原生 IO、超时、其它方法缺失或一般 UNSUPPORTED 均不能触发协议重试。能力响应迟到而查询已取消时，禁止启动回退请求。

该变更没有新的页面或视觉状态；既有搜索原型交互不变。真实 controller→FileService→r5 原生 broker 复验旧/新接口、权限/IO及取消；测试传输层只模拟旧宿主未注册方法和延迟回执，不伪造文件结果。r5 App JavaScript 不含此增量，下一统一包补做受影响 App 搜索回归。具体源码、初始回归脚本旧端点断言失败和最终结果见验收证据。
