## 修复与适用边界

G074002 原三条组件检查发现 `open` 忽略已有 `fileViewer` 字段：指定 ID、内置选择和未知 ID 都未按合同处理。原红测保留。

- 指定已启用且适用本机来源的 ID 时执行该选择；不可用 ID 明确拒绝，保留当前文档。
- `default` 使用内置查看器；显式 `null` 回到自动选择；不传该属性保留既有手选。
- 原文件菜单连接同一 `open` 入口；验证等待中发生新导航或开始编辑时保护原文档，不把旧选择应用到新文档。
- 内置选择可结合已实现的行列定位。`endLine`、预览标题及 artifact 目标的原完整分派合同仍独立欠缺，本批不冒充实现。

实际仅修改 `workspace-store.ts`、`workspace-store.test.ts`、`workspace-panel.tsx`、`mcp/viewer.tsx` 及 `office-handoff.ts` 的字段说明。未改布局、菜单文案及原型行为定义；未增加标题或目标字段来替代缺失的原业务来源。
