# 开发前 06：真实文件树与搜索

2026-10-17，依据 R3.4 的 R02、R03、R04、R08。结论：**真实本机磁盘遍历与搜索路线可行，前期接口、过滤、位置和取消规则已收口**。6000 个实际临时文件的 [14 项检查通过](../验收/证据/predev-filesystem-result-2.json)。这补充原型合成 provider 的证据，不代表正式文件服务或 App 已实现。

## 整体方案与当前状态

普通树按层读取；文件名筛选独立枚举合格文件，再复用现有 fuzzy 模型；全文搜索用有界独立 ripgrep 子进程，流式返回匹配行。结果携带任务、根、查询和文档版本，界面只接受当前代际。根与文件读取最终由主进程可信文件服务提供，不能让渲染页提交任意磁盘路径。

当前原型已有虚拟行、粘性目录、取消/乱序与焦点状态；生产 provider 未实现。本轮脚本在独立临时目录操作真实文件，用本机 ripgrep 15.2.0，不增加生产依赖、不读取用户项目。原生资源如何入包由第09专项统一决定，不能假设用户机器必有命令。

## 实现契约（目标设计，非已存在的 RPC）

| 操作 | 请求与身份 | 返回与异常 |
| --- | --- | --- |
| 取得根 | main 从项目登记目录或核实的本机任务 cwd 签发 `leaseId/generation`；记录根真实路径及 dev/ino | 无可信本机根拒绝；根路径被替换不能自动绑定新 inode |
| 读取一级目录 | lease、目录相对引用、requestId；主进程解析路径 | 文件类型、显示名、可信 fileRef；loading/empty/error 分开，失败不冒充空目录；取消不改已确认缓存 |
| 文件名枚举 | lease、query、queryGeneration；分批产出候选，复用 R03.3 已有 fuzzy 排序 | 包括未展开目录；切根/换 query/关闭后旧结果丢弃。候选与文件真实身份分开，点击时重核文件 |
| 全文查询 | 非空 query，最多256个 UTF-16 单位；file mask 为独立 argv 参数；requestId/queryGeneration | 每行包含 fileRef、1起始行号、片段与0起始 UTF-16 范围；状态为部分结果/完成/无结果/取消/错误/达到限制；不将文件字节偏移直接当编辑器位置 |
| 停止查询 | 指定 requestId，宿主停止对应进程，退出确认后释放句柄 | 已缓冲但不属于当前代际的结果直接丢弃；不得以仅隐藏 spinner 代替终止 |
| 打开搜索结果 | fileRef + 当前根代际 + 搜索时版本/行列 | 重读并核对身份/版本；已改变时重定位或明确过期，不把旧 offset 应用到另一文件 |

普通树含隐藏文件以及 node_modules 等目录，目录优先，同类 `localeCompare`，相等时保持原顺序。名称枚举按 R03.2 固定排除路径段：`.git,.hg,.next,.pnpm-store,.svn,.turbo,.yarn,build,coverage,dist,node_modules`；不排除所有点文件。初始全文实现沿用同一固定排除清单，明确使用 `--hidden --no-ignore --no-config`，不隐式读取用户全局 ripgrep 配置或继承 gitignore，防止相同项目在不同机器产生不明缺项。另外按[08生产布局](开发前_08_保存与恢复.md)的可信内部对象登记过滤userData恢复子树与同卷事务对象；用户mask不得重新纳入，不能仅凭名字通配隐藏用户文件。该共享身份过滤是生产实现任务，未在本轮临时目录搜索中冒充已验。没有新增过滤开关或正则/大小写开关。

查询为字面量、区分大小写；mask直接传给 `--glob`，进程 `spawn` 不经过 shell。用户mask先传，强制排除glob最后传，避免ripgrep后写glob覆盖前写排除。名称枚举用 NUL 分隔，全文用 JSON 帧，支持文件名中的空格、引号和换行。控制字符文件名能被列出，不意味着可以拖进终端；R05.14 对这类路径仍整体拒绝。

搜索不递归跟随 symlink，避免循环与根外泄漏；普通树保留 symlink 类型与可解释状态。显式打开根内别名仍须交给生产 broker 解析并验证真实目标，不能从“搜索不跟随”推断整个 App 永久禁止所有根内 symlink。此次没有证明目录替换竞争下的原生安全读取，沿用第08的 fd 锚定路线。

## 预算、边界与失败处理

以下数值在本轮执行前写入脚本，针对本机6000文件的可行性门槛；不是全设备 SLA。后续调整须保留原结果与新理由。

| 项 | 固定判定 | 实测 |
| --- | --- | --- |
| 根层列出 | <1000ms | 0.62ms；只读根层，展开的子层300文件另读 |
| 全根名称枚举 | <5000ms | 9.35ms，6008个合格文件 |
| 全文首条 | <5000ms | 常见匹配约5.01ms |
| 无命中全文结束 | <10000ms | 三轮31.77/28.74/33.13ms；不是冷磁盘缓存 |
| 取消到真实子进程退出 | <1000ms | 约0.74ms；达到上限终止约0.58ms；不响应SIGTERM的自有故障子进程252.41ms强制退出 |
| 结果上限 | 前100匹配行后停止，标记可能还有结果 | 100行后退出；不是100个文件或100个出现位置 |
| 搜索输入文件 | 20MiB初始上限；与10MiB可编辑阈值分开 | 真实20MiB+1文件已验证跳过；超限跳过需在生产摘要中明确，不能声称扫完所有文件 |
| 协议单帧 | 2MiB上限，过长明确 response-too-large | 真实超2MiB JSON行已验证明确失败，停止后无结果追加 |

二进制不当文本打开；无效 UTF-8 的 base64 行不伪造成有效定位，记录跳过原因。UTF-16/BOM等其他编码由后续文本解码适配逐项验证，本轮不宣称全部编码支持。rg退出1是无匹配，退出2/权限失败是错误或有错误的部分结果；不能吞掉stderr后返回空列表。

## 实际验证与剩余

脚本：[predev-filesystem-probe.mjs](实验/predev-filesystem-probe.mjs)。执行：`node <脚本> <新的结果JSON路径>`，拒绝覆盖报告，结束删除自有临时目录。覆盖真实目录、固定排除、忽略文件差异、根外/循环/失效链接、中文/emoji/CRLF、引号及换行文件名、mask、无匹配、二进制/损坏文本、100行限制、取消、根被替换、目录缺失及三轮成本。源码哈希、环境和夹具规则记录在JSON。

交叉审校发现初版把mask追加在固定排除后，`*.ts`会重新纳入11个排除目录。已保留[初版源码](实验/history/predev-filesystem-probe-r1.mjs)和[旧11项结果](../验收/证据/predev-filesystem-result-1.json)，新增同扩展名交叉夹具，旧顺序实测泄漏11项，修复后只返回根内合格文件。取消控制补充250ms SIGTERM宽限后SIGKILL；真实rg与忽略TERM的自有子进程均在1000ms门槛内退出。正式宿主还须在子进程退出失败时记录异常并隔离通道，不能把kill发送当退出确认。

正式开发仍需：fd安全读取服务、受影响文件的版本校验、项目级缓存/持久化、watch健康UI、系统外开、真实大项目/权限/磁盘断开、完整输入法/触屏与滚动恢复；实际UI性能沿用原型检查并在 App 重验，未拿本轮 CLI 耗时冒充滚动帧率。对应用例仍为R02/R03及其原编号，结果不改为正式通过。
