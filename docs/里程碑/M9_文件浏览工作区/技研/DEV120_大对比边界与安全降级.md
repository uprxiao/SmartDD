- [共享policy](../../../../src/shared/file-inline-diff.mjs)按两侧**原始UTF-16长度**和CRLF/CR/LF行数判定，等于允许、任一超过仅关闭diff，不改变文件加载/编辑/保存上限。空磁盘文本与没有磁盘版本分开。
- [对比控制](../../../../src/renderer/features/files/conflict-diff.ts)复用真实CM unified diff，关闭库内chunk版本决策按钮。`originalDocChangeEffect`只更新显示用磁盘原文；宿主三决策、保存revision、本地源码和历史保留。`scanLimit:500/timeout:50`用于算法粗略回退，不是总耗时严格50ms保证。
- [source field](../../../../src/renderer/features/files/editor-source.ts)将原raw/EOL更新复用为preview，不强制读取未来tr.state；transactionExtender在同一输入事务先移除超限diff，防止先计算巨型diff再降级。撤销进入预算内后恢复显示。
- [实际编辑器](../../../../src/renderer/features/files/text-editor.tsx)只有view与buffer状态一致时安装显示effect，避免“使用磁盘版本”换权威state后旧view反写。冲突时以源码显示真实diff，逻辑文件mode沿用；解除后原Markdown体验恢复，已补真实回归。
- [完整只读源码](../../../../src/renderer/features/files/source-view.tsx)替代旧磁盘`pre.slice(0,262144)`。全部原文通过虚拟化CM展示、可选，禁止编辑；没有文件能力或保存/选版本入口。同一核心由[合成原型宿主](../../../../prototypes/m6-codex/src/FileConflictSource.jsx)复用。磁盘预览仅展开后挂载。
