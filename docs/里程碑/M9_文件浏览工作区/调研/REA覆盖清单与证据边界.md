## 4. 历史动态复验分组（执行计划已撤销）

以下八组是早期拟定的参考观察范围，用于保留证据缺口和需求来源，**不再作为下一轮操作Codex的执行计划**。其中适用于WillYou合成原型、隔离技术实验或正式App的内容，按[九项交接](../ClaudeCode_九项问题交接.md)分阶段验证，不能用这些结果补写Codex运行事实：

1. 一个主根、一个嵌套根、一个无关根；同名文件、中文/空格、隐藏文件、空目录、权限拒绝、失效根、symlink边界。
2. 文件名筛选与全文搜索分开；未展开目录、被排除路径、快速输入/取消/切根、mask历史、多字节命中列。
3. 单击→预览替换→双击固定→重排→关闭→恢复→切会话→退出重开；验证预览与固定恢复差异，PTY不受影响。
4. Markdown/Pierre：干净与脏内容外改；保存失败再关闭；等待中切标签；500ms草稿、550ms潜在编辑、3s保存各自验证。
5. 文本10/20MiB、artifact40MiB、媒体128MiB、review256MiB边界；HTML字节/UTF-16长度分别构造。
6. 每类路由至少一个文件，加损坏、unsupported、附件/历史/显式viewer变体；PDF页码、Notebook MIME优先级与禁脚本HTML。
7. PPTX etag冲突、XLSX append/materialize/刷新问题；记录专有解析替代的布局、宏、公式和字体差异。
8. 浅/深色同一尺寸截图，默认/选中/hover/focus/disabled/长路径/菜单边缘/缩放；对应每个图标与token。

具体步骤与可判定预期由[测试用例](../验收/测试用例.md)维护；这里是历史实验分组，不构成已执行证据或新的操作授权。
