# M9 r34：目录、搜索与微交互补齐

2026-10-17，依据需求 **R3.3-20261017**，在用户授权的九项缺口修复范围内更新共享原型。`r34-interaction` 是本轮实现／证据名称，不是新需求修订，不改变 D01 独立终端与文件视图、D07 本机文件范围，不代表生产开发或整体验收获批。

本轮补齐了 [搜索补齐说明](搜索补齐说明.md) 中 T06、T10、T14、T16、T17 的原型缺口，并把候选和全文搜索改为可取消的异步合成适配器。最终 **84/84 模型检查、30/30 浏览器检查通过，原型构建通过**。这些结果证明下述合成原型行为；GAP-02 的完整视觉参考对照、GAP-06 的真实文件服务及设备条件尚未因此关闭。

## 实际变更

| 关联项 | 当前实现与验证 | 证据边界 |
| --- | --- | --- |
| T06 懒加载／虚拟化／粘性目录 | 新增 6,000 文件样本；按展开路径异步获取直接子项，收起时取消未完成子查询；展开目录的错误、重试、空状态分别展示。28px 固定行高、有界窗口、粘性祖先，Home/End 可定位未挂载行。I01–I09 | 文件清单仍在内存中，初始化会建立合成目录索引。证明的是按目录查询及虚拟 DOM 行为，不是磁盘懒枚举或生产性能基准。实测展开时 312 逻辑行、28 个文件树 DOM 行 |
| 异步文件名／全文搜索 | 延迟、失败、重试样本；每个 query/root 有请求标识和 AbortController，旧查询及切根后的迟到结果不覆盖新结果。候选来源仍独立于 basename 重排；全文分批扫描，UTF-16 列定位，超过 100 条才显示截断提示。I10–I13、I24–I26 与模型测试 | 候选源和全文扫描为合成实现；没有原生 nucleo、rg、真实 ignore／symlink 或系统文件监听证据 |
| T10 外开菜单 | 首选应用直接入口、列表加载禁用、失败重试、无能力说明；复制路径仍可用。异步状态与当前菜单／root 绑定，关闭后不更新新菜单。I19–I21 | 只展示模拟应用列表及启动反馈，不探测或启动真实外部应用 |
| T14 路径 tooltip | 500ms 定时，pointer 与 focus-visible 触发；点击、Esc、滚动、失焦、尺寸／模型变化关闭；触屏／按住指针与 Git 装饰区抑制；路径可选择、换行并限制在视口。I14–I18 | 浏览器实测在 300ms 未显示、约 560ms 已显示；500ms 为实现常量，不宣称精确计时仪测量。真实触屏与读屏未验证 |
| T16 generated 条件 | 变化文件上下文才展示过滤开关，过滤已标记生成文件，不改变普通树的隐藏文件行为。I22–I23 | `package.json` 是本轮明确标记的合成生成文件；不推断真实项目的生成文件分类 |
| T17 nearest 定位 | 从未展开子树搜索并打开文件后展开祖先，加载完成后滚入可见区，程序定位不主动抢终端焦点。I06–I07 | 本轮验证树定位；面包屑长路径和目录弹层全部状态仍不是本轮完成项 |
| 可比视觉与回归 | 记录浅色大目录、深色 tooltip；实际 DOM 测得树行 28px、文字 13px、文件图标 16px；保留完整路径拖入终端的 HTML 拖拽回归。I27、I29–I30 | 依据归档静态常量，不等于所有字体／图标／颜色／缩放状态与参考逐像素一致；没有新运行或控制 Codex |

主要文件为 [FileWorkspace.jsx](../../../../prototypes/m6-codex/src/FileWorkspace.jsx)、[FileWorkspaceTree.jsx](../../../../prototypes/m6-codex/src/FileWorkspaceTree.jsx)、[file-interaction-model.mjs](../../../../prototypes/m6-codex/src/file-interaction-model.mjs)、[file-workspace-model.mjs](../../../../prototypes/m6-codex/src/file-workspace-model.mjs) 和 [file-workspace.css](../../../../prototypes/m6-codex/src/file-workspace.css)。`rankedTreeRows` 改为父子索引，避免按每层反复扫描全部候选。既有评分模块及完整路径拖拽模型保持原合同。

配合 PDF 分工，两处 `FileArtifactPreview` 传入 `onInsertContext={sendToTerminal}`，复用当前任务的上下文投递 Promise。它结束于插入结果，不发送 Enter，不跟踪 CLI 完成，不恢复专用 AI 审阅流程；PDF 侧完整联调由对应报告记录。
