## 1. 目标与确认边界

**正式数据来源为 WillYou 本地数据库：导出查询项目与关联资源，导入解密校验后事务插入。Skill 仅用于本轮首份 AIS 样本准备，不是正式功能的数据源。**

将 WillYou 中一个项目的关联配置和使用这些配置所需的凭据打成加密文件，交给另一位 **WillYou 用户**。接收方解锁、确认本机路径后导入为项目，减少重新输入账号、密码和服务器信息。也用于后续版本复用同一份 AIS 测试资料。

| 类别 | 当前决定 | 依据／确认状态 |
| --- | --- | --- |
| 接收方 | 同样使用 WillYou App | 用户明确确认 |
| 迁移内容 | 项目及数据库、服务器、代码目录等关联信息，**包含密码、私钥、令牌** | 用户明确确认；替代旧初稿“默认不含密钥” |
| 代码位置 | 每个目录提供两项单选：默认“选择本机目录”，也可主动选“原代码位置”；最终路径须在接收方可用，至少一个主目录；不覆盖磁盘源码 | 用户本轮明确两种方式及默认项 |
| 历史会话 | 不打包任务、会话、终端输出、CLI 会话记录 | 用户明确排除 |
| 测试数据 | AIS 项目；从本机 DB、SSH Skill 配置中抽取项目范围信息，形成固定测试文件 | 用户明确指定；源配置只读 |
| 导出保护 | 整个文件用口令加密；口令至少 8 个字符，其他规则不变；口令另行交付 | 用户本轮确认最少 8 位 |
| 项目数量与冲突 | 一次一个项目；导入创建副本，不合并或覆盖已有项目 | 本轮方案，用户已批准实施 |
| AI 配置 | 代码位置下方显示“导入文件中的 AI 配置”，默认不勾选；用户勾选后可逐项调整。导出时可显式勾选附带 | 用户本轮明确默认不导入；现有配置为全局对象 |
| 平台 | M8 首轮完整业务验收为 macOS arm64；其他平台维持现有实验性边界 | 本轮方案，用户已批准实施；不因有安装包就声明完整支持 |
| 开发边界 | 按 M8-R4 原型和文档实施真实业务、单元／集成测试、打包应用端到端验收 | 沿用用户确定的 M 阶段流程 |

“导入即可用”指受支持的配置、关联和凭据已恢复，不要求再次输入同一份资源密码。接收方仍须具有相应网络访问能力、本地源码和 CLI；CLI 自身登录会话不打包。连接失败不应丢失已导入配置，也不能把“保存成功”写成“连接测试成功”。

### 包含与排除

包含项目基本信息、目录引用与默认标记、DB/SSH 配置和凭据、三个内置项目能力开关；可选附带显式勾选的 AI 配置及其中已保存的敏感环境变量。服务器私钥须包含**文件内容**，不能只迁移发送方私钥路径；其口令、独立 sudo 密码一并加密。

本轮不打包源码、Git/SVN 工作区、数据库实际数据、业务文档或规则文件内容、历史会话、运行状态、整个用户数据目录、Skill 程序包、第三方 CLI 的 OAuth/登录缓存。规则文件只带路径引用，由接收方调整或清空。任意第三方配置格式批量导入、团队云同步、项目合并覆盖和批量多项目迁移不在 M8。

## 3. 逐页交互

### P01：入口

- 左侧“项目”标题右侧 `＋` 展开“新建项目／导入项目”，保留新建流程。
- 单个项目的更多菜单增加“导出项目”；项目概览也保留相同入口。不会把导出放到会话右键菜单。
- 入口图标、字体、菜单行高、悬停、焦点、Esc 和弹层定位沿用已确认 Codex 原型基线。仅预览工具区使用小型 M8 标识。
- 2026-10-17 用户补充：项目页操作使用清晰的常用图标并保留文字。新建任务使用方框铅笔，添加使用加号，编辑使用铅笔，删除／移除配置使用垃圾桶；数据库和服务器的测试连接使用插头，测试期间显示等待图标。资源列表和编辑弹窗保持一致，窄窗口允许操作区换行；业务与确认规则不变。

### P02：导出项目

显示项目名及目录、数据库、服务器、选中 AI 配置的数量；展开可核对资源及凭据种类，**不显示秘密值**。说明会话历史和源码不包含。可选择附带全局 AI 配置，不改变原项目或全局默认配置。

设置并再次输入导出口令：至少 8 个 Unicode 字符，UTF-8 长度不超过 1024 字节；不新增大小写、数字或特殊符号组合要求，不自动 trim 或改写。两次不一致时就地提示，不进入保存。口令只用于这次文件，不能当成数据库密码。遗忘后重新导出，应用不能找回。

点击“加密并导出”后选择保存位置，默认 `<项目名>-<日期>.willyou`，文件名清理平台不支持字符。取消系统选择器返回表单，不产生文件。保存期间禁止重复提交；成功才显示路径和结果。覆盖已有同名磁盘文件由系统保存对话框确认，不静默覆盖。

读取安全存储、读取私钥、加密或磁盘写入失败，保留非敏感选项，给出可恢复原因。包中某资源所需密码、私钥或独立 sudo 密码缺失时，整次导出停止并列出资源名称；不得暗中省略后宣称“导入即可用”。允许空密码的资源须显式记录“无密码”，与“未提供／丢失”区分。

### P03/P04：选择、检查、解锁

原生选择器仅选择一个 `.willyou` 文件。检查大小、文件标识和格式版本；不按扩展名信任内容。检查失败停留选择页，重新选择可恢复。不支持的格式版本提示升级或重新导出，不当成空项目。

解锁前只显示选中文件名及格式可读性，不显示包内项目名、资源、账号或其他加密内容。导入口令正确且完整性校验成功后才解析、校验业务数据。错误口令与认证失败统一提示“口令不正确，或文件已经损坏”；清空口令、允许重试，不写入任何项目。密码字段不出现在日志与持久化草稿中。

所有操作均在 App 内完成，不需要终端命令。口令方案的顺序是：**输入口令 → 派生解密密钥 → 认证解密与完整性校验 → 展示脱敏预览 → 确认后写库**。不是先得到明文、再和文件里存的口令比对；文件中不保存可读口令，单独解密成功也不等于已经导入。

### P05：确认导入

显示项目名称、资源数量、凭据包含状态和资源详情。名字已有时建议 `AIS（导入）`、`AIS（导入 2）`，用户可编辑；继续重名则阻止导入。最长 100 字符；生成后缀前截短基础名，最终仍满足校验。归档项目的名字不阻止新建，沿用当前业务规则。

每个目录标注名称、默认关系及“必选”，下面提供两种互斥单选：

1. **选择本机目录（默认选中）**：本机路径初始留空，点击“选择目录”打开文件夹选择器。用户主动选择后检查可用性；默认不会使用发送方路径。
2. **原代码位置**：显示导出文件内只读原路径。用户主动选中后，以该路径作为目标，立即在接收方检查是否存在、是否为可用文件夹以及是否被占用。选中此项时本机选择控件禁用，但保留本次已选的本机路径；切回第一项时恢复该选择，之前没选过则仍为空。

两种方式都须有一个可用目标才可导入；原代码位置不存在、不可用或已被其他未归档项目占用时，提示改选本机目录，不自动回退。主目录仍为必选，多目录包逐个选择，保留原默认关系；不接受同包重复或其他未归档项目已占用的实际目录。选中的是默认“选择本机目录”但还没选文件夹时，不能因原路径可用而放行。提交前重新检查存在／所需权限／realpath 占用，Git/SVN 状态单独显示。最终仅保存当前方式对应的路径，不复制或覆盖文件夹源码，不自动 clone 或下载代码。

若源项目没有目录，确认页仍补出一个必选“主目录”行，原代码位置显示“文件未提供”，该单选项禁用。接收方选择本机文件夹后才可导入，该目录作为新项目唯一默认目录。不会因源项目零目录而绕过必选要求。

规则文件路径有值时单独列出，可重新选择或清空。引用不存在时必须处理后才能确认导入，避免后续任务悄悄缺少规则。SSH 的应用路径和日志路径属于**远端路径**，不做本机路径替换；私钥目标路径由应用生成。

代码位置下方始终显示 AI 配置区及“导入文件中的 AI 配置”复选框，**默认不勾选**，仅说明可继续使用接收方自己的配置，不展开明细。文件没有附带 AI 配置时，该框保持未勾选并禁用，说明“文件未附带 AI 配置”；不隐藏整块选项。

用户勾选后展开配置名称、运行器与逐项复选框，初始选中包内全部配置，允许再取消部分；显示“已选 n / 文件内 m”，提供“全选／全部不导入”。取消总勾选会清空所有 AI 选择并收起明细；取消最后一项也恢复不导入状态。顶部 AI 数量与结果页数量均表示**本次实际选中的数量**，不是包内总数；包内总数在选择区显示。

接收方可以只选一部分，也可以全部不选。选中的配置才显示本机命令调整区，并另存副本；同名追加后缀且名称不超过 60 字，本地 ID 全新，不覆盖已有配置或全局默认。不选的 AI 配置及其 token／敏感 env 不写入接收方数据库或安全存储，其本机 CLI 不可用也不阻止项目导入。

选中配置的发送方绝对 CLI 路径需在接收方重新检测或选择；没有安装 CLI 时可保存为待配置，禁止以该配置运行任务。不选或文件未附带 AI 配置时，导入结束后沿用任务创建流程选用接收方自己的配置；接收方还没有可用配置时引导添加。无需把接收方已有 AI 配置绑定成项目字段，也不虚构“项目默认 AI 配置”。

校验通过点击“导入项目”。仅在这一步提交，不在预览时往正式项目／凭据表写入。导入过程中禁止二次提交与关闭；进程异常退出的恢复由技术方案负责。

### P06/P07：结果

导入成功显示新项目名、各资源／AI 配置数量、待调整的本机项，以及“连接尚未测试”。提供“查看项目”和“新建任务”；没有可用目录或 AI 配置时，先引导配置，不能用错误路径启动。

导出成功显示实际文件位置，可在 Finder 中显示。接收方流程仍在 WillYou 内。口令与文件分开交付，不把明文口令写入文件或同一交付压缩包。

导入的新项目没有历史会话，且不自动打开终端、调用模型、连接 DB/SSH 或执行导入内容中的命令。连接测试和实际任务由用户后续主动触发。

### P08：异常与取消

未开始磁盘写入时，Esc、关闭、点击遮罩和取消遵循相同规则。有解锁后的内容或未保存选择时才弹出独立居中的“放弃这次导入／导出？”确认对话框，不将确认内容追加到主表单底部。确认框出现时主表单不可操作，焦点进入确认框；“继续编辑”、确认框关闭、Esc 或点击确认遮罩仅返回原表单，保留目录方式／路径、AI 选择和其他未提交内容，恢复原焦点。只有“放弃并关闭”才清除内存草稿并退出，不修改已有项目。无未保存内容时直接关闭；忙碌时防重复操作；失败后允许重试。

资源校验失败、安全存储不可用、密钥文件写入失败、数据库事务失败等均不留下可见半项目、孤立密码或散落私钥。重试仍须校验接收方当前重名状态。已经提交但响应丢失时，以本次操作 ID 查询结果，不再创建第二份项目。用户主动再次选择同一文件是新的导入，允许生成另一个副本。

## 4. 数据字段与业务校验

| 对象 | 迁移字段 | 导入规则 |
| --- | --- | --- |
| 项目 | name、aliases、description、rulesPath | 新 UUID、configVersion=1、非归档、创建与修改时间为接收时刻；不导出内部存储 ID |
| 目录 | 包内 ref、label、path、isDefault | ref 重映射；导入后至少一项且恰好一个默认；源项目零目录时由接收方新增必选主目录；本机状态重新检测，不沿用发送方状态 |
| 数据库 | ref、env、label、aliases、vendor、host、port、database、schema、username、accessLevel、isDefault、note | 支持现有 8 类；端口 1–65535；最多一个**项目级**默认，允许未设置，并非每环境一个；密码引用绑定新资源 ID |
| 服务器 | ref、env、label、aliases、host、port、username、authType、defaultRoot、sudoPolicy、appRoot、logsPath、note | 密码／私钥二选一；separate sudo 必有独立密码；密钥路径替换为接收方受管路径 |
| 项目能力 | 内置 capabilityId、enabled | 显式带上三个能力有效值；不存在关联行时按当前默认启用计算，导入后仍按包内值；不自动安装未知 Skill |
| AI 配置（可选） | 包内 ref、name、runner、executable、args、env、color | 导出可选、导入再选；仅接收方勾选的项及对应凭据写入；运行器限现有支持值；敏感 env 值由 credentials 引用；全新 ID；命令参数不执行；CLI 状态重新检测 |
| 凭据 | 按 ref 组织的 password、privateKey、passphrase、sudoPassword、AI secret env values | 在整体加密载荷内，解锁后仅主进程持有；显示层只获有无和类型；私钥二进制以 base64 表示，限 1 MiB/项 |
| 包元数据 | 格式／载荷版本、导出时间、来源应用版本与平台 | 版本兼容与大小先检查；内部关联以包内 ref 为准，无依赖原数据库主键 |

复用现有 shared schema 的字段上限：名称 100、项目别名最多 50 项、说明／备注 2000、常规路径 1024、环境 32、主机／账号／库名 255。逐字段差异以技研中的映射为准；不静默截断资源值。格式 v1 上限：单个文件 16 MiB、解密载荷 10 MiB；目录最多 50、数据库和服务器各 100、可选 AI 配置 50；超限整包拒绝。

包内 ref 必须唯一，所有凭据引用均可解析，不接受未知资源种类／能力 ID。导入前展示全部有效内容，不偷偷舍弃不认识的字段。未来新增结构升级格式版本，旧应用给出明确错误。
