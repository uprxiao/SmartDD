## R0.4 增补（2026-11-01，仍无原型修改）

- **会话应用诊断**：邮件由 `foxmail` 与 `smtp` 两个连接槽组成，诊断需按能力显示可用性（读取、草稿、发送各自依赖的槽），只配其一时明确提示另一类能力“未配置”，不显示整体不可用；入口按应用声明显示 MCP 或 CLI。
- **发件地址与 Foxmail 账号不一致**：项目选用与发送前需有明确的错误或提示状态，具体文案与位置待技研确定校验点后补入原型。
- **禅道 Story**：沿用现有禅道面板的对象类型表现，不新增页面；Story 的界面验收随暂缓用例一并补测。
