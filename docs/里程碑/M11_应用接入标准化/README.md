## 目标与依据

建立后续应用可复用的能力声明、调用入口、权限、凭据、结果、审计及适配标准。**应用 SOP／Skill → Agent → 受管 MCP 或 CLI → 统一能力服务 → 三方系统。** 首版标准化两种 Agent 入口，并为官方 MCP／CLI 制定通用上游适配规则；已有 API、本机数据和 SMTP 服务继续复用。优先不修改官方工具，在 WillYou 侧完成必要映射。

Cloud Code 配 DeepSeek、Codex 等是用户期望的使用组合；同一套应用 SOP 与底层模型解耦。不同 Agent 的发现、配置交付和执行能力仍需逐项适配验证，不能把某一组合的成功扩写成全部支持。

首版面向 WillYou 内终端；未来系统终端／iTerm 只预留调用与身份接口。2026-11-01 用户确认互换原 M11／M12：本阶段调整为 M11，定时任务顺延 M12；本阶段承接本次优先讨论，不改写 M10 已验收范围或 Story 后补事项。
