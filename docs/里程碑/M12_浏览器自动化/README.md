## 范围一句话

1. 在 WillYou 右侧工作区增加内置浏览器；
2. 给 Agent 提供 Skill，经 CLI 操作该浏览器中已打开的页面，能力对标 Orca 的浏览器 CLI＋Skill。

不包含的内容见[需求 §2](需求.md)。
