# M6 实施与验收记录

日期：2026-10-16。开发分支：`feature/0.0.1`。应用版本：`0.0.4`。本机：macOS 26.6.1 / Darwin 25.6.0，arm64。

## 1. 授权范围与实现

用户审阅原型后要求直接在现有分支开发，保留所有既有功能，按原型接 UI，完成必要验收后提交、合并 main、打 tag。数据库和 SSH 可以连不通，但保存、重开、测试反馈和页面流程必须正常。

- `src/renderer/m6.css` 复用批准的 `prototypes/m6-codex` 样式，接入现有主题变量。导航、首页、项目侧栏、设置侧栏、分组卡片、浮层、菜单和搜索采用同一套布局。
- 项目保留概览、代码目录、数据库、服务器、Skill 与 MCP、任务六项；完整表单、资源服务、凭据加密、配置注入沿用原实现。
- 检测到 Codex／Claude Code 后可一键添加基础配置；有对应配置则打开现有项。添加前重新查询已保存配置，阻止重复点击；保留用户参数、凭据、名称、默认值。
- 任务中央区继续运行真实 CLI 终端，切换页面不卸载终端；保留标签、停止／恢复、任务信息和能力快照。
- 新增设置搜索、侧栏宽度调节、快捷键和关于页、任务搜索的项目筛选及配置名匹配。定时任务只交付导航与规划页。

## 4. 本轮发现并修复

1. 窗口被覆盖后终端画面停滞：Electron 禁用该窗口的 `backgroundThrottling`，恢复及时绘制；实际终端回复、停止和恢复重新验证。
2. 打包后 Codex 图标不可见：SVG 默认被内联为 data URL，受既有 CSP 限制；改为 `?no-inline` 外部资产，没有放宽 CSP。
3. 从首页打开项目资源可能引用先前终端的项目：资源按钮仅在任务页优先使用当前任务项目，其他页使用当前选择。
4. 项目编辑标题使用不存在的翻译 key：改用已有标题；搜索弹窗增加真实标题、Esc 提示和项目筛选；设置无搜索结果提示中英文均补齐。
