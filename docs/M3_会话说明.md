## 2. AI 配置与密钥

- 环境变量模板中，名称像令牌的（`*_TOKEN`、`*_KEY`、`*_SECRET` 等）自动标为密钥；密钥值存 `app_secrets`，key 为 `ai:<配置ID>:env:<变量名>`，值为 safeStorage 密文（`djEw` 开头）。`ai_profiles.env` 里密钥项的 value 为 `null`。
- 密钥从不发往界面，编辑框只显示“已保存”；日志只记变量名。
- `.zshrc` 导入：先选文件、脱敏预览（令牌显示为 `••••••（N 位）`，覆盖 `sk-`、`github_pat_` 等），勾选后导入；导入后提示原文件仍是明文。已存在的同名配置不重复导入。

## 3. 任务生命周期

- 新建：首条消息作为 argv 传给 CLI（不经 shell）。Claude 带 `--session-id <新UUID>`；Codex 由 session 文件回填 ID。
- 恢复状态：有 session 文件 → resumable（`--resume`）；Claude 未发过消息 → fresh（沿用原 ID `--session-id`）；Codex 未发过消息 → 未开始；无原生 ID → 不可恢复并写明原因。
- **自动 resume**（2026-10-15 用户确认，参照 Yoda）：应用启动不拉起任何任务；打开一个已停止的任务时，自动用任务记录的配置恢复，每打开一次标签只自动尝试一次（关标签后再开会重试）。以下情况仍显示恢复面板：未开始 / 不可恢复、没有记录配置（M3 之前的旧记录，选一次后会记下）或原配置已删除、已归档、自动尝试失败、用户点了“换配置”。
- **任务标签**：侧栏单击、⌘K、项目页打开任务都会进标签（已开则聚焦），新标签插在当前标签后。关闭标签 = 结束会话（运行中的 PTY 直接结束，不再确认）并丢弃该终端；焦点去右邻，否则左邻，没有标签则回首页。标签只在内存，重启不恢复、不批量拉起。
- **终端**：参数、字体栈、按键与 Yoda 一致；PTY 环境补 `TERM=xterm-256color`、`COLORTERM=truecolor`、`TERM_PROGRAM=smartdd`，用户 shell 没设语言时补 `LANG=en_US.UTF-8`（`launch-env.ts` 的 `terminalIdentity`）。新 PTY 按上一次适配出的行列启动，首次按终端区域和字体估算。
- 未接入 Yoda 用的 `@xterm/addon-unicode11`（安装依赖的命令被权限拦截，待用户决定）；xterm 默认按 Unicode 6 计算字宽，个别新 emoji 可能占错格。
- 换配置恢复时显示跨配置提示（接口、模型、账号可能不同，不一定能接上上下文）。
- 运行中的任务不能归档（提示先结束）；删除只删 SmartDD 记录，不动 CLI 的会话文件。

## 4. 调试用临时数据目录

`SMARTDD_USER_DATA=<目录>` 让应用使用指定的 userData（数据库、设置都在里面），用于 GUI 测试，不碰真实数据；该变量不会传给 CLI。

```bash

```

## 7. 任务页改版（2026-10-15，按 Yoda 任务页）

用户看了 Yoda 的任务页后确认“先完全按照 Yoda 的改”。改动：

| 位置 | 改版前 | 改版后 |
| --- | --- | --- |
| 顶栏 | 任务标题文字 | 面包屑“项目 / 任务”（项目可点进项目页）；右侧结束 / 恢复按钮、ⓘ 任务信息弹层 |
| 正文 | 顶部信息块（标题、状态、项目、配置、cwd、注入变量） | 去掉，终端占满主区；信息移入 ⓘ 弹层，“换配置”也在弹层里 |
| 底栏 | 无 | 运行器图标与名称 · 配置颜色点与名称 · 模型名；右侧运行中任务数（Yoda 的通知、同步等图标不做） |
| 侧栏任务行 | 左侧配置颜色条 + 运行中绿点 | 去掉颜色条；行尾运行中绿圈、CLI 已退出灰圈，其余显示距上次启动的相对时间；悬停换成 ⋯ |
| 侧栏底部 | 无 | “SmartDD (V版本号)” |

- 模型名：`profileModel`（`src/shared/ai-profiles.ts`）取 `--model x` / `--model=x`（Codex 还认 `-m x`），没有时取 Claude 配置的 `ANTHROPIC_MODEL`；都没有时底栏不显示、弹层写“CLI 默认”。显示的是配置的当前值，启动后改过配置则与运行中的进程可能不同。
- 相对时间：`compactRelativeTime`（`src/renderer/utils/relative-time.ts`）手写，阈值与 Yoda 所用 date-fns `formatDistanceToNowStrict`（floor）一致，不新增依赖；每分钟刷新。时间取 `lastLaunchedAt`，没有时取 `createdAt`。
- 运行器图标 `src/renderer/assets/runners/` 取自 Yoda。
- GUI 实测：面包屑、底栏（`Claude Code · CC-DS · deepseek-v4-fake`，与假 CLI 读到的模型一致）、侧栏绿圈 → 结束后灰圈 → 换配置后变为相对时间、弹层内容与“换配置”、首页不显示面包屑和底栏，均与预期一致。
- 已知现象：窗口被遮挡（`visibilityState: hidden`）时弹层关闭动画被节流，弹层元素会滞留几秒才移除，状态已是关闭；窗口可见时不出现。

- GUI 实测（2026-10-15）：侧栏单击两个任务 → 两个标签，均自动启动（`--resume` / `--session-id`），未弹配置选择；再点已开的任务只切标签；关当前标签 → 对应 CLI 进程消失、焦点到右邻；重开 → 再次自动 resume；关完 → 回首页且无残留进程；PTY 环境含 `COLORTERM=truecolor`；终端字体栈生效。
