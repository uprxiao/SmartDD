## 2. 规则

- **项目**：活动项目名不区分大小写唯一；别名去重。归档项目不占用名称和目录；取消归档时重新检查，冲突则拒绝。
- **代码目录**：同一路径只能属于一个活动项目，同一项目内只登记一次（软链接和末尾 `/` 视为同一路径）。第一个目录自动设为默认；移除默认目录后由最早的目录接替。
- **配置版本号**：项目及其目录、数据库、服务器的每次修改都会 +1；任务启动时记录所用版本（M3 使用）。
- **默认数据库**：每个项目最多一个。生产环境的资源在列表中排在最前，卡片红色边框，编辑时显示警告。
- **删除**：只删 SmartDD 自己的记录，不动代码目录和远程资源；由用户勾选是否同时删除加密保存的密码（PRD F09）。
- **校验错误**：统一为“输入无效：<中文原因>”，如“项目名称不能为空”“端口必须是 1–65535 的整数”。

## 3. 密钥

- 数据库密码、服务器密码、私钥口令、sudo 密码存在 `app_secrets`，值为 safeStorage 密文（base64 后以 `djEw` 开头）。
- 密码从不发送到界面：视图只带 `hasPassword` 等布尔值，编辑框显示“•••••• 已保存”。
- 修改语义：`undefined` 保留、`null` 清除、字符串替换。服务器的 sudo 策略改为非“单独密码”时，自动删除 sudo 密码。
- 编辑中点“测试连接”不改密码时，使用已保存的密码测试。

## 4. 连接测试

- 超时 8 秒（驱动超时 + 外层兜底计时，超时后主动断开 socket）。
- MySQL：`SELECT VERSION(), DATABASE()`。PG 系（PostgreSQL、openGauss、盘维）：`SELECT version()`、`current_database()`，填了 schema 时检查 `pg_namespace`。
- SSH：只执行 `hostname; whoami`，显示主机名、用户和主机指纹（SHA256，只显示不校验）。
- 失败分类：`network`（拒绝连接、DNS 失败、不可达）、`timeout`、`auth`、`database`（库或 Schema 不存在）、`unsupported_auth`（如 openGauss 的 sha256/sm3）、`config`（私钥无法解析等）、`other`。
- 失败信息保留驱动错误码，如 `[ER_ACCESS_DENIED_ERROR]`、`[28P01]`，避免服务端只返回 “Unknown error 1045” 时看不出原因。
- MySQL 1044：无权限账号即使填错库名，也得到 1044 而不是 1049，所以归为 `auth`，并提示“也可能库名填错”。
- 所有信息经过 `redact` 脱敏：已知密码、URL 中的密码、`password=`/`token:`，以及 `github_pat_`、`ghp_`、`sk-`、`AKIA`、`xox?-` 形式的令牌。
- 卡片上的测试会把结果、分类和时间写入库；弹窗中的测试（草稿测试）不写库。

## 6. 界面验证（2026-10-14）

用本地临时实例（MySQL 5.7、PostgreSQL 14、Node 写的模拟 SSH 服务端、只接受连接不响应的端口），通过远程调试端口驱动真实窗口完成。没有对任何真实数据库或服务器做错误密码测试。

| 场景 | 结果 |
| --- | --- |
| MySQL 密码错误 | 认证失败 `[ER_ACCESS_DENIED_ERROR]` |
| MySQL 普通账号 + 错误库名 | 认证失败（1044，附“也可能库名填错”） |
| MySQL 有全局权限账号 + 错误库名 | 库或 Schema 不存在（1049） |
| MySQL 端口关闭 / `.invalid` 主机 | 网络不可达 |
| 只接受连接不响应的端口 | 超时（约 8000 ms），MySQL 与 SSH 均是 |
| MySQL 正确 | 成功，显示 5.7.24 |
| PG 密码错误 / 库名错误 / schema 错误 | 认证失败 `28P01` / 库不存在 `3D000` / Schema 不存在 `3F000` |
| PG 正确 | 成功，显示 schema 存在 |
| SSH 密码错误 / 正确 | 认证失败 / 成功（主机名、用户、指纹；服务端只收到 `hostname; whoami`） |

其他：

- 项目：空名称提示“输入无效：项目名称不能为空”；创建后别名去重、跳转到项目页、标题栏显示项目名。
- 目录：git/svn 标记、“默认”徽标；同一目录经软链接加末尾 `/` 再次添加被拒；“设为默认”生效；目录改名后显示“不存在”。
- 数据库：切换类型时端口 3306→5432、出现 Schema 字段；生产环境警告、红边框、排在最前。
- 密钥：保存后库文件和 WAL 中无明文；编辑框只显示“已保存”，DOM 中无明文；sudo 改为“不使用”后 sudo 密码被删除。
- 删除：服务器删除时取消勾选，密码保留；项目删除时勾选，项目下的密码全部删除，界面回到首页。
- 归档：显示横幅，侧栏收进“已归档（1）”；取消归档后恢复，配置版本号递增。

## 7. 未验证与已知限制

- openGauss、盘维未连接真实实例，`unsupported_auth` 分类只有单元测试。
- PG 系连接未启用 SSL；SSH 主机指纹只显示、不校验（无 known_hosts）。
- SSH 端口关闭、“移除目录”确认只有单元测试（界面自动化命令被权限分类器拦截）。
- 删除时保留的密码没有对应配置后，界面无法再找到或清理它。
- 窗口在后台（`visibilityState = hidden`）时 Chromium 暂停动画，弹窗退出动画不结束，遮罩会挡住点击；窗口在前台时正常。
- 目录状态在窗口重新获得焦点时刷新。
