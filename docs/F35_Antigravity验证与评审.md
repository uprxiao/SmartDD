# F35 Antigravity 技研验证与评审

2026-11-23 · `feature/0.1.7` · WillYou 源码基线 `e7fc5f57f`。技术对照见 [Antigravity 接入技研](F35_Antigravity接入技研.md)。本轮使用用户指定的 Model Hub 和 `gemini-4-carbon`、`gemini-4-argon`。本机 Google 登录留待具备条件后验证。

## 本轮结论

**WillYou 可以按实际 ACP 能力识别本机 `agy`。** 本机样本是 `1.5.14`，发出 ACP v2 和 v1 初始化时都协商成功，回报 v1，耗时各约 53 ms。它公布了 `gemini-api-key`、会话恢复和模型配置能力。运行时启动、协议和能力的实测结果作为适用依据，CLI 版本号只用于诊断。

**指定地址已是预设的 Model Hub。** 在已有供应商上补 Gemini 原生端点即可沿用现有 Key、模型勾选和智能体绑定。在占位凭据实验里，`GOOGLE_GEMINI_BASE_URL` 确实把 `agy` 的 Gemini 请求指到了指定地址。对照的 `--cloud_code_endpoint` 在此认证方式下仍发往默认的 Google 生成域名。[Model Hub 现有预设](../src/shared/provider-catalog.ts)

**真实生成受上游渠道限制。** Carbon 的最小 `generateContent` 请求有一次返回正确文本，耗时 23.2 秒。真实 `agy` 带会话配置、系统指令与工具声明的请求走到同一个网关后返回 HTTP 400。将同一请求通过隔离转发改走 `generateContent` 仍得到网关的明确错误：`gemini-vertex` 分组里该模型没有可用渠道。Argon 在真实 `agy` 调用中等待上游 75 秒超时。两款模型都能列出和选中，整条真实生成和委派链路仍待验证。

| 模型 | 可复核结果 | 当前结论 |
| --- | --- | --- |
| Carbon | 小文本和 17 个合成工具定义的一次工具调用返回预期。单独把输出上限从 384 提到 65,536 后返回 400，提示 `gemini-vertex` 无渠道。短测试经真实 `agy` 及固定合成桥时，网关明确报当前分组没有配置支持 Carbon 的账户。 | 完整对话与工具回传未达到真实验收条件。网关支持方可按结果中的请求 ID 核对渠道。 |

本机故障探针确认，上游 400 可以在 ACP 中表现为普通消息和 `end_turn`。同一隔离会话的本轮新增原生错误记录能识别这次失败，紧接着正常返回一段含 “Error 400” 的文本时没有新增错误记录。A14 增加正反对照，验收以本轮来源和实际结果为准。A27～A29 保留完整请求、真实工具结果及回到助手回复的判据。[故障与普通文本对照](F35_Antigravity实验/20261123/开发前实验/网关与原生协议结果.json)

本地宿主、目录及失败识别的技术问题已有证据。真实 Model Hub 的完整负载和稳定性需要上游渠道满足后复验。用例复核已把这些发现写入逐条判据，后续产品验收状态按实际执行结果填写。
