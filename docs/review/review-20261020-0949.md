1. **本轮无需再决定的事项：** 架构主方向、邮件来源／发件基数、Foxmail 只读范围及核心页面组织已有依据。按用户本轮安排进入实现，不将可后验事项重新全部前置。

3. **用例库与本轮范围区别：** 72 是稳定编号库，不直接等于本次每条全部子场景都适用。[T12](../里程碑/M10_三方应用接入/验收/测试用例.md)保留禅道后续流转候选，当前需求明确读取交付可先开工；T45 保留旧版历史；T24/T70/T72 中其他平台和未来 Agent 的正向接入按已确认后续边界记录。建立执行账时显式标明适用层级与批准依据，不删历史编号、不把后续或未执行计为通过。
4. **真实外部动作：** 开发授权不等于任意真实发信／禅道变更授权；实际业务测试沿用每例专用对象和具体操作授权范围。已确认的 SMTP 功能仍须实现，禅道未细化写动作不擅自扩入当前读取交付。
5. **审查边界：** 本轮完整核对用例结构、当前七份入口资料的本地文件链接及上述证据清单，并重点抽查最新规则到设计／原型／用例的对应。未逐条执行产品用例、未打开实时原型做新一轮视觉验收，亦未穷尽每个历史实验或每项业务字段的实现细节，问题可能未穷尽。结论限于资料具备开工依据，不是 M10 产品验收通过。
