## R1 Git 工作副本的提交边界

- 父任务排空后，宿主按物理 Git 工作目录协调。子目录与路径别名同属一个范围，独立工作副本和嵌套仓库各自隔离。暂缓新输入、插话和宿主写入，其他任务继续当前回合。回合之外的已知后台工作也纳入等待；Codex 目标仍可自动起回合时，保留原目标，等它自然停止或用户暂停。
- 共享目录可以提交时，重新核对目录与分支。自动提交的说明注明可能包含同目录其他任务的改动。工作副本创建后立即恢复原会话派发，依赖安装期间其他任务可以继续。等待阶段停止父任务或取消子任务时，恢复其他会话且 HEAD 不变。
- 集成测试在真实 Git 临时仓库核对半成品文件、提交内容、同一个 run 恢复、新任务首次输入，以及停止和取消。并行 Git 父任务创建两个同名子任务和 Git、SVN、普通目录的独立并行纳入回归。[Git 工作副本](../../src/main/core/agent/git-workspaces.ts) [委派协调](../../src/main/core/agent/delegation-service.ts) [运行入口](../../src/main/core/agent/agent-run-service.ts) [测试](../../src/main/core/agent/delegation-service.test.ts)

## R2 业务放行后的计时

- 统一在准入函数返回后启动执行时限。SVN／普通目录等槽、Git 父任务排空和依赖安装都处于可撤销的等待阶段。重新核对后执行；等待中停止或撤销均为零执行。继承原有重启后重新确认、浏览器待绑定及在途副作用租约规则。
- Git 反例使用可控的依赖安装等待，超过 250 毫秒的测试预算才放行，随后以接近完整预算执行一次。另测同阶段停止和撤销，以及界面在原批准调用未返回期间可撤销。[宿主计时](../../src/main/core/agent/host-business-requests.ts) [界面回归](../../src/renderer/features/agent-tasks/agent-task-view.test.tsx)
