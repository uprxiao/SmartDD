## 3. 问题

### E1（低）：轮首提示的位置不对，而且和“已工作 N 秒”重复

- 代码：`agent-task-view.tsx:1010-1012` 把“正在停止…”“你在 N 秒后停止了”“本轮失败”三种提示放在 `g.rows` 之前渲染。这一轮的第一行就是用户消息，所以提示出现在用户气泡上方；后面的工作行仍显示“已工作 N 秒”。
- 证据：
  - [失败（本轮新图）](evidence-20261118-m14-d1-d4/side-by-side/light-failed.png)：“本轮失败”在用户消息上方，下面是“已工作 9 秒”。
  - [已停止（上一轮图）](evidence-20261118-claude-phase1-5-s1-s2-followup/side-by-side/light-stopped.png)：“你在 1 分 3 秒后停止了”在用户消息上方，下面是“已工作 1 分 3 秒”。
- 原型：这行提示就是工作组的标题，在用户消息下方，替换“已工作 N 秒”或“工作中 N 秒”。失败时用红字，写成“工作 N 秒后失败”。
- 修改：
  - 把这三种状态作为工作行标题的文字和颜色传给 `WorkRow`，替换原标题。
  - 这一轮没有工作行时（比如还没调用任何工具就失败了），把提示放在用户消息之后。
  - 重拍 stopped、stopping、failed 三个状态的浅色、深色、窄窗并排图，并更新差异清单中 V18、V26、V19 三行。

### E2（低）：草稿冲突的规则没有登记进需求勘误

需求第 19 行新增了“草稿跨窗口发生修订冲突时……”这一段，但末尾的 2026-11-18 R2.0 勘误里没有对应条目，当前只有 ①–⑥ 和 V23、V24 一条。请补一条 ⑦：写明规则内容、来源（原型差异 F14b）和用户确认日期 2026-11-18。
