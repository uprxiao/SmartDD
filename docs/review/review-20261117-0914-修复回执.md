## 2. 验证后已定的两项（验证事实详见[验证记录](../里程碑/M14_统一Agent工作区/技研/实验/20261117_目标切换与完全访问计划验证.md)）

- **AR10 目标与切换执行器**：Codex 目标不暂停会自己在后台继续跑，暂停后可跨进程恢复为 paused；Claude 没有暂停，目标残留在会话中，切回后任何一句话都会让它继续追旧目标。**用户决定**：有目标（进行中、已暂停或等子任务）时不允许切换执行器，清除目标后才可切换；同执行器内换模型不受限；委派子任务不算切换。已改需求 R03、技术方案 §6.1、A14，原型模型选择器置灰其他执行器并提示（CDP：Codex、Claude 目标场景置灰 4 个，清除后 0 个）。
- **AR11 完全访问下计划批准**：带 canUseTool 时，bypass 下 ExitPlanMode 仍经过 canUseTool，可挂起等用户批准（拒绝无写入、批准后同回合实施），PreToolUse 也能拦截。**用户决定**：完全访问与其他档位一致，计划批准都进请求面板；技术方案 §6.1 改为 canUseTool 挂起 ExitPlanMode、PreToolUse 为第二道，宿主必须始终传 canUseTool；A71 同步。首轮未传 canUseTool 的运行没有计划工具，已保留并注明无效。
