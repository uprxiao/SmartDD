# M8 交付验收用例与结果

更新：2026-10-17。依据：[M8-R4](M8_真实项目导入导出.md)、[原型 P01–P08](design/m8/M8_原型验收.md)、[技术设计](M8_技术调研.md)。状态：**开发完成；48/48 条验收用例通过，执行完成率与通过率均为 100%**。本轮平台范围为 macOS arm64；构建、测试层级、日志及缺陷复验见[实施验收记录](design/m8/M8_实施验收记录.md)。已随 [v0.0.5 预发布](https://github.com/uprxiao/SmartDD/releases/tag/v0.0.5) 交付，不将本机结果外推到其他平台。

## 环境与固定数据

- **A/B/C**：macOS arm64 上相互隔离的发送／接收／再次接收 WillYou 打包应用与 userData，不复用用户日常数据。测试时记录 App 路径、包SHA、分支commit、OS、架构及时间。若用同机两个 userData，仍须以独立测试 cipher/密钥证明未依赖发送方密文；仅同机成功不能证明跨机器 Keychain 兼容。
- **T1**：合成项目，两个目录、中文别名与说明、规则路径、多个环境DB、密码SSH、三个不同能力开关；全局AI两套且一套带合成token。所有生产单测与CI只用合成数据。
- **T2**：合成私钥/口令、独立sudo、空密码及AI token样本；可使用隔离 SSH fixture，不向真实服务器上传或改密钥。
- **T3**：从合成T1派生的格式、参数、容量、schema和关联异常样本。
- **T-AIS**：本机 `release/m8-fixtures/AIS-M8.willyou`；口令独立存放。用户指定的AIS目录和3DB/2SSH配置，详见M8需求§5。只在本机授权范围使用，测试证据只写数量、布尔比较和哈希。
- 连接不通与迁移失败分开判断。离线保存用例必须通过；真实连接用例如环境不具备仍记阻塞，不能把所有用例宣布通过。本轮首次平台范围为 macOS arm64。
