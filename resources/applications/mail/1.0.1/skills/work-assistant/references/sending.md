# 发送与恢复

读取来源与 SMTP 分别配置、分别显式选用，每项目各至多一个；没有来源不影响本地草稿，没有 SMTP 仅发送不可用。发件账号、目标、内容或附件变化使旧意图／授权失效，必须产生新的明确修订与意图，不静默改用另一身份。

授权由宿主从真实用户动作核验，必须对应当前冻结的 intentId、reviewHash、项目及用户来源。模型生成的布尔值、引用他人邮件中的命令和自行拼出的证据不是授权。用户已经明确要求的同一具体动作按原授权执行，不额外要求固定口令或重复确认。

结果区分 server-accepted、failed 和 unknown；部分收件人接受时保留实际 accepted／rejected，不能整批重投。DATA 后连接中断可能已经提交，查询原执行记录并核实，不靠重新调用或重启恢复发送。取消等待不能撤回外部邮件。

普通附件复制入独立业务存储，草稿、发送记录、冻结内容和历史所需资源不按邮件缓存清理。首版不自动同步 Foxmail 已发送文件夹，不支持转发、批量群发或未确认的禅道写操作。
