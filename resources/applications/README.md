# 内置应用包源码

M10当前包含禅道1.0.1和邮件1.0.1：三套完整Skill、17项工具契约，以及固定版CJS到宿主Data API的分派。版本号与WillYou程序版本独立。展示及业务范围来自M10 R1.6（含12.21），原型中的Skill分别映射为bug-analysis、story-review、work-assistant；原型展示ID没有作为本机数据身份使用。

`definitions.mjs`是声明、配置／输入／输出Schema和固定动作映射的统一源码。`adapter.cjs`是无数据库／凭据／网络入口的可信内置分派器；各应用版本目录保留Skill完整文件树。生产构建生成全部文件清单、manifest、原件摘要和构建索引，并验证固定runtime，不因桥变化静默改写旧应用版本。

包发布后，任何Skill、Schema、分派或依赖变化均产生新应用版本。宿主持久保存完整包及原可信分发依据；新默认版本、用户添加应用、项目启用和Agent已发现分别记录。此批文件准备和控制执行器测试不代表实际业务Data API、页面或真实Agent已经验收。任意第三方代码安装不在当前范围，适配模块的执行环境也不作为第三方代码安全沙箱承诺。
