# M9 文件类型图标

来源为 SOURCE.json 指定提交的 @pierre/trees（Apache-2.0）。保留 LICENSE.md、NOTICE.md。53 个文件类型 symbol 均为 16×16，使用 `icons.svg#file-tree-builtin-${type}`；另外有上游的 5 个基础 symbol。图标采用 currentColor；类型、文件名、扩展名及浅深色映射见 `../../../src/m9-icon-map.json`。

该资源不包含 Codex 私有的 12px 展开箭头、20px Git 状态徽标或工具栏图标；使用上游箭头属于已记录视觉差异。
